การจำแนกและการอ่านชื่อสารอินทรีย์เบื้องต้น

Organic Classification and Basic IUPAC Naming

เป้าหมายหลัก: แยกประเภทสารได้ อ่านชื่อ IUPAC เป็น และจับจำนวนคาร์บอนจากชื่อได้
Main goal: classify organic compounds, read IUPAC names, and identify carbon numbers from names

Part 1: แผนที่การจำแนกสารอินทรีย์ (Map of Organic Classification)

🇹🇭 เวลาเจอสารอินทรีย์ 1 ตัว เราไม่จำเป็นต้องท่องชื่อก่อนเสมอ ให้เริ่มจากการดู “ลักษณะสำคัญ” ของโครงสร้าง เช่น มีพันธะคู่ไหม เป็นวงไหม หรือมีหมู่ฟังก์ชันอะไร
🇬🇧 When we see an organic compound, we do not always need to memorize its name first. We can start by looking at key structural features, such as double bonds, rings, or functional groups.
🧠 ดูสารอินทรีย์ให้เป็นระบบ / Read organic compounds systematically
$$\text{ดูพันธะ} \Rightarrow \text{ดูโครงคาร์บอน} \Rightarrow \text{ดูหมู่ฟังก์ชัน} \Rightarrow \text{อ่านชื่อ IUPAC}$$ $$\text{Bonding} \Rightarrow \text{Carbon skeleton} \Rightarrow \text{Functional group} \Rightarrow \text{IUPAC name}$$

1.1 จำแนกตามความอิ่มตัว (Classification by Saturation)

Saturated
อิ่มตัว
$$C-C$$
🇹🇭 มีแต่พันธะเดี่ยวระหว่าง C กับ C เช่น แอลเคน มักเกิดปฏิกิริยาแทนที่
🇬🇧 Contains only single C-C bonds, such as alkanes. Often undergoes substitution.
Unsaturated
ไม่อิ่มตัว
$$C=C \quad \text{or} \quad C \equiv C$$
🇹🇭 มีพันธะคู่หรือพันธะสาม เช่น แอลคีน แอลไคน์ มักเกิดปฏิกิริยาเติม
🇬🇧 Contains double or triple bonds, such as alkenes and alkynes. Often undergoes addition.
Aromatic
อะโรมาติก
โครงสร้างเบนซีน \(C_6H_6\) / Structure of benzene \(C_6H_6\)
$$\text{benzene ring}$$
🇹🇭 มีวงเบนซีน แม้ดูเหมือนมีพันธะคู่ แต่เสถียรมาก เพราะอิเล็กตรอน \(\pi\) กระจายตัวทั่ววง จึงมักชอบปฏิกิริยาแทนที่มากกว่าปฏิกิริยาเติม
🇬🇧 Contains a benzene ring. Although it appears to have double bonds, it is very stable because its \(\pi\) electrons are delocalized around the ring. It usually undergoes substitution rather than addition.
🚨 จุดดัก: เบนซีนมีพันธะคู่ในวง แต่ไม่ทำตัวเหมือนแอลคีนทั่วไป เพราะมีเรโซแนนซ์ทำให้เสถียรมาก
🚨 Trap: Benzene has double bonds in the ring, but it does not behave like a normal alkene because resonance makes it highly stable.

1.2 จำแนกตามโครงคาร์บอน (Classification by Carbon Skeleton)

Aliphatic
$$\text{open chain}$$
🇹🇭 โซ่เปิด อาจเป็นโซ่ตรงหรือโซ่กิ่ง เช่น แอลเคน แอลคีน แอลไคน์
🇬🇧 Open-chain compounds, either straight or branched, such as alkanes, alkenes, and alkynes.
Hexane / โซ่ตรง
SMILES: CCCCCC
2-Methylbutane / โซ่กิ่ง
SMILES: CC(C)CC
Alicyclic
$$\text{non-aromatic ring}$$
🇹🇭 เป็นวง แต่ไม่ใช่วงเบนซีน เช่น cyclohexane จึงเป็นวงคาร์บอนธรรมดา ไม่ใช่อะโรมาติก
🇬🇧 Ring compounds that are not benzene-like, such as cyclohexane. They are carbon rings but not aromatic.
Cyclohexane / วงคาร์บอนธรรมดา
SMILES: C1CCCCC1
Aromatic
$$\text{benzene ring}$$
🇹🇭 มีวงเบนซีนเป็นโครงสร้างสำคัญ เช่น benzene, toluene มีความเสถียรสูงจากเรโซแนนซ์
🇬🇧 Contains a benzene ring as an important structural feature, such as benzene and toluene. Aromatic rings are stabilized by resonance.
Benzene / วงเบนซีน
SMILES: c1ccccc1
Toluene / เบนซีนมีกิ่ง methyl
SMILES: Cc1ccccc1
🧠 จำสั้น ๆ: โซ่เปิด = aliphatic, วงธรรมดา = alicyclic, วงเบนซีน = aromatic
🧠 Quick memory: open chain = aliphatic, normal ring = alicyclic, benzene ring = aromatic.

1.3 จำแนกตามหมู่ฟังก์ชัน (Classification by Functional Groups)

🇹🇭 หมู่ฟังก์ชันคือส่วนของโมเลกุลที่บอก “ตระกูล” ของสารอินทรีย์ และมักเป็นบริเวณที่กำหนดสมบัติหรือปฏิกิริยาหลักของสาร
🇬🇧 A functional group is the part of a molecule that identifies the compound family and often controls its main properties or reactions.
ตระกูล / Family ชื่อหมู่ / Group Name รูปแบบทั่วไป / General Pattern จำสั้น / Quick Memory Suffix ที่พบบ่อย / Common Suffix
Alkane Single bond
พันธะเดี่ยว		 \(C-C\) พันธะเดี่ยวหมด / single bonds only -ane
Alkene Carbon-carbon double bond
พันธะคู่ C=C		 \(C=C\) มีพันธะคู่ / has a double bond -ene
Alkyne Carbon-carbon triple bond
พันธะสาม C≡C		 \(C \equiv C\) มีพันธะสาม / has a triple bond -yne
Alcohol Hydroxyl group
หมู่ไฮดรอกซิล		 \(R-OH\) มี OH / has OH -ol
Ether Alkoxy group / Ether linkage
หมู่แอลคอกซี / พันธะอีเทอร์		 \(R-O-R'\) O คั่นกลาง / O in the middle alkoxy- prefix
Aldehyde Formyl group / Aldehyde group
หมู่ฟอร์มิล / หมู่แอลดีไฮด์		 \(R-CHO\) CHO ปลายสาย / CHO at the end -al
Ketone Carbonyl group
หมู่คาร์บอนิล		 \(R-CO-R'\) C=O กลางสาย / C=O in the middle -one
Carboxylic acid Carboxyl group
หมู่คาร์บอกซิล		 \(R-COOH\) กรดอินทรีย์ / organic acid -oic acid
Ester Ester group
หมู่เอสเทอร์		 \(R-COO-R'\) COO คั่นกลาง / has COO linkage -oate
Amine Amino group
หมู่อะมิโน		 \(R-NH_2\) มี N / contains N -amine
Amide Amide group
หมู่เอไมด์		 \(R-CONH_2\) C=O ติด N / C=O attached to N -amide

Part 2: จับจำนวนคาร์บอนจาก Root Name (Carbon Numbers from Root Names)

🇹🇭 การอ่านชื่อ IUPAC ต้องเริ่มจากการจับจำนวนคาร์บอนในโซ่หลักให้ได้ก่อน เช่น meth- คือ C1, eth- คือ C2, prop- คือ C3 และ but- คือ C4
🇬🇧 Reading IUPAC names begins with identifying the number of carbon atoms in the main chain. For example, meth- means C1, eth- means C2, prop- means C3, and but- means C4.
🧠 จำก่อน: C1–C10 เจอบ่อยที่สุด แต่รู้ C11–C20 ไว้จะอ่านชื่อสารยาว ๆ ได้ดีขึ้น
🧠 Remember first: C1–C10 are the most common, but knowing C11–C20 helps with longer organic names.

Prefix บอกจำนวนซ้ำ (Prefixes for Repeated Groups)

จำนวน / Number Prefix ตัวอย่าง / Example ความหมาย / Meaning
1 mono- monochloro มี Cl 1 ตัว / one chlorine
2 di- dimethyl มีกิ่ง methyl 2 กิ่ง / two methyl branches
3 tri- trimethyl มีกิ่ง methyl 3 กิ่ง / three methyl branches
4 tetra- tetrachloro มี Cl 4 ตัว / four chlorines
5 penta- pentane โซ่หลัก C5 / five carbons
6 hexa- hexane โซ่หลัก C6 / six carbons

Part 3: อ่านชื่อ IUPAC แบบจับโครง (Reading IUPAC Names by Parts)

🇹🇭 การอ่านชื่อ IUPAC ไม่ใช่แค่จำ root กับ suffix แต่ต้องมี “ลำดับการตัดสินใจ” ว่าจะเลือกอะไรเป็นโซ่หลัก นับเลขจากด้านไหน และหมู่ใดมีความสำคัญที่สุดในการตั้งชื่อ
🇬🇧 Reading IUPAC names is not only about memorizing roots and suffixes. We also need a decision order: which chain is the parent chain, where numbering starts, and which functional group has the highest priority.
🧭 คู่มือการอ่านชื่อ IUPAC แบบเป็นขั้นตอน / IUPAC Decision Guide
$$\text{เลือกหมู่หลัก} \Rightarrow \text{เลือกโซ่หลัก} \Rightarrow \text{นับเลข} \Rightarrow \text{หากิ่ง/ตำแหน่ง} \Rightarrow \text{ประกอบชื่อ}$$ $$\text{Main group} \Rightarrow \text{Parent chain} \Rightarrow \text{Numbering} \Rightarrow \text{Branches/positions} \Rightarrow \text{Name}$$
Step 1: เลือกหมู่ฟังก์ชันหลัก
Choose the principal functional group
🇹🇭 ถ้ามีหลายหมู่ ให้เลือกหมู่ที่มีลำดับความสำคัญสูงที่สุดเป็น “คำลงท้าย” หรือ suffix
🇬🇧 If there are multiple groups, choose the highest-priority group as the suffix.
$$\text{main functional group} = \text{suffix}$$
Step 2: เลือกโซ่หลัก
Choose the parent chain
🇹🇭 โซ่หลักต้องมีหมู่ฟังก์ชันหลักอยู่ในโซ่ และควรเป็นโซ่ที่ยาวที่สุดเท่าที่ทำได้
🇬🇧 The parent chain must contain the principal functional group and should be as long as possible.
$$\text{parent chain} = \text{longest chain containing the main group}$$
Step 3: ตัดสินใจทิศทางการนับเลข
Decide the numbering direction
🇹🇭 เริ่มนับจากด้านที่ทำให้หมู่ฟังก์ชันหลักได้เลขน้อยที่สุด ถ้าเสมอกันจึงดูพันธะคู่/สาม และกิ่งตามลำดับ
🇬🇧 Number from the end that gives the principal functional group the lowest number. If tied, consider multiple bonds, then branches.
$$\text{lowest number for the main group first}$$
Step 4: ประกอบชื่อ
Build the name
🇹🇭 ใส่ตำแหน่งกิ่ง ชื่อกิ่ง root ของโซ่หลัก และ suffix ของตระกูลสาร
🇬🇧 Add branch positions, branch names, the root of the parent chain, and the suffix of the compound family.
$$\text{position + branch + root + suffix}$$
🏆 ลำดับความสำคัญที่ใช้บ่อยใน A-Level / Common Priority Order
ลำดับ / Priority หมู่ / Group รูปแบบ / Pattern เมื่อเป็นหมู่หลัก / Main suffix จำสั้น / Quick Memory
1 Carboxylic acid \(R-COOH\) -oic acid กรดมาก่อน / acid first
2 Ester \(R-COO-R'\) -oate COO คั่นกลาง / COO linkage
3 Aldehyde \(R-CHO\) -al CHO ปลายสาย / CHO at end
4 Ketone \(R-CO-R'\) -one C=O กลางสาย / carbonyl in chain
5 Alcohol \(R-OH\) -ol OH / hydroxyl
6 Amine \(R-NH_2\) -amine มี N / contains N
7 Alkene / Alkyne \(C=C,\ C \equiv C\) -ene, -yne พันธะคู่/สาม / multiple bonds
8 Branch / Halogen \(-CH_3,\ -Cl,\ -Br\) prefix มักเป็นคำนำหน้า / usually prefix
🔢 กฎการตัดสินใจเรื่องตัวเลข / Numbering Rules
1) ให้หมู่ฟังก์ชันหลักได้เลขน้อยที่สุดก่อน
1) Give the principal functional group the lowest possible number first.
2) ถ้าหมู่หลักเสมอกัน ให้พันธะคู่หรือพันธะสามได้เลขน้อยกว่า
2) If the main group is tied, give the double or triple bond the lower number.
3) ถ้ายังเสมอกัน ให้กิ่งได้ชุดตัวเลขที่น้อยที่สุด
3) If still tied, give substituents the lowest set of numbers.
4) หมู่ \(-COOH\) และ \(-CHO\) อยู่ปลายสาย และ C ของหมู่นั้นเป็นตำแหน่ง 1 เสมอ
4) \(-COOH\) and \(-CHO\) are terminal groups, and the carbon in that group is always position 1.
🚨 จุดดักสำคัญ
🚨 Important Traps
🇹🇭 คาร์บอนในหมู่ \(-COOH\), \(-CHO\), \(-CO-\), และ \(-COO-\) ต้องนับเป็นส่วนหนึ่งของโซ่หลักเสมอ
🇬🇧 The carbon in \(-COOH\), \(-CHO\), \(-CO-\), and \(-COO-\) must be counted as part of the parent structure.
🇹🇭 ถ้ามีทั้ง \(-OH\) และ \(C=C\) ให้เลือก \(-OH\) เป็นหมู่หลักก่อน แล้วค่อยระบุตำแหน่งพันธะคู่
🇬🇧 If both \(-OH\) and \(C=C\) are present, prioritize \(-OH\) as the main group before numbering the double bond.
🇹🇭 ถ้ามีหมู่ที่สำคัญกว่า หมู่ที่สำคัญน้อยกว่าอาจเปลี่ยนไปเป็น prefix เช่น hydroxy-, amino-, oxo-, chloro-, methyl-
🇬🇧 If a higher-priority group is present, lower-priority groups may become prefixes, such as hydroxy-, amino-, oxo-, chloro-, and methyl-.

Suffix บอกตระกูลสาร (Suffix Indicates the Compound Family)

Suffix ตระกูล / Family ตัวอย่าง / Example อ่านเร็ว / Quick Reading
-ane Alkane butane C4 พันธะเดี่ยวหมด / C4 alkane
-ene Alkene but-2-ene C4 มีพันธะคู่ที่ตำแหน่ง 2 / C4 with double bond at 2
-yne Alkyne ethyne C2 มีพันธะสาม / C2 with triple bond
-ol Alcohol propan-1-ol C3 มี OH ที่ C1 / C3 alcohol with OH at C1
-al Aldehyde ethanal C2 มี CHO ที่ปลายสาย / C2 aldehyde
-one Ketone propanone C3 มี C=O กลางสาย / C3 ketone
-oic acid Carboxylic acid ethanoic acid C2 กรดคาร์บอกซิลิก / C2 carboxylic acid
-amide Amide ethanamide C2 amide / C2 amide

ตัวอย่างอ่านชื่อ IUPAC (IUPAC Reading Examples)

🚨 จุดดักในการอ่านชื่อ
🚨 Naming Traps
1) \(COOH\), \(CHO\), \(CO\), \(COO\) มีคาร์บอนอยู่ในหมู่ฟังก์ชัน ต้องนับ C ตัวนั้นด้วย
1) \(COOH\), \(CHO\), \(CO\), and \(COO\) contain carbon atoms that must be counted.
2) หมู่กรด \(-COOH\) และแอลดีไฮด์ \(-CHO\) อยู่ปลายสาย และคาร์บอนของหมู่นั้นเป็น C1 เสมอ
2) \(-COOH\) and \(-CHO\) groups are at the end of the chain, and their carbon is always C1.
3) ถ้ามีหมู่ฟังก์ชันและพันธะคู่ ให้ให้ความสำคัญกับหมู่ฟังก์ชันหลักก่อน
3) If both a functional group and a double bond are present, prioritize the main functional group.

Part 4: เห็นโครงสร้างจริงด้วย SmilesDrawer (Seeing Real Structures with SmilesDrawer)

🇬🇧 This section uses SmilesDrawer to draw real structures from SMILES, helping students see how IUPAC names connect to line-angle structures.
หมายเหตุ: รูปแบบทั่วไปเช่น \(R-OH\) ใช้เป็น “แพตเทิร์นจำหมู่ฟังก์ชัน” แต่ SMILES ใช้กับสารจริง เช่น ethanol = CCO
Note: General patterns such as \(R-OH\) are used to remember functional groups, while SMILES is used for real compounds, such as ethanol = CCO.
📌 สรุปจำสั้น / Short Summary
1) ดูพันธะก่อน: เดี่ยว = alkane, คู่ = alkene, สาม = alkyne, วงเบนซีน = aromatic
1) Look at bonds first: single = alkane, double = alkene, triple = alkyne, benzene ring = aromatic.
2) ดูหมู่ฟังก์ชัน: \(R-OH\) = alcohol, \(R-COOH\) = carboxylic acid, \(R-COO-R'\) = ester
2) Look at functional groups: \(R-OH\) = alcohol, \(R-COOH\) = carboxylic acid, \(R-COO-R'\) = ester.
3) อ่าน IUPAC โดยแยกชื่อเป็นตำแหน่ง กิ่ง root และ suffix
3) Read IUPAC names by separating position, branch, root, and suffix.
4) Root บอกจำนวน C ส่วน suffix บอกตระกูลของสาร
4) The root tells the number of carbons, while the suffix tells the compound family.
