5 คะแนน5 points
ข้อ 1. รับค่ารัศมีและคำนวณพื้นที่วงกลม (5)Input a radius and calculate the area of a circle
จงเขียนโปรแกรมรับค่ารัศมีของวงกลมจากผู้ใช้ โดยรัศมีอาจเป็นจำนวนทศนิยม จากนั้นคำนวณพื้นที่ด้วย พื้นที่วงกลม = 3.1416 × รัศมี × รัศมี แล้วแสดงคำว่า “พื้นที่วงกลม” พร้อมค่าที่คำนวณได้ Write a program that asks the user for the radius of a circle. The radius may be a decimal number. Calculate the area using circle area = 3.1416 × radius × radius, then display the label “Circle area” together with the calculated value.
ข้อมูลและข้อกำหนดGiven Data and Requirements
ขั้นที่ 1: รับค่าStep 1: Inputรับค่ารัศมีด้วย input() และแปลงเป็น floatUse input() to read the radius and convert it to float.
ขั้นที่ 2: คำนวณStep 2: Calculateใช้ area = 3.1416 * r * rUse area = 3.1416 * r * r. The expression r ** 2 is also acceptable.
ขั้นที่ 3: แสดงผลStep 3: Outputใช้ print() แสดงคำอธิบายและค่าพื้นที่Use print() to display a label and the area.
ตัวอย่างExampleถ้า r = 2 จะได้พื้นที่ 12.5664If r = 2, the area is 12.5664.
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์นี้Write Python code to solve this problem.
เฉลย / Solution
r = float(input("ป้อนรัศมี / Enter radius: ")) area = 3.1416 * r * r print("พื้นที่วงกลม / Circle area:", area)
💡 วิธีอื่นที่ยอมรับได้ / Other acceptable approaches:
• ใช้เลขยกกำลัง / Use exponentiation: area = 3.1416 * (r ** 2)
• คำนวณใน print() ได้ แต่การแยกตัวแปร area อ่านง่ายกว่าสำหรับผู้เริ่มต้น The calculation may be written directly inside print(), but using an area variable is clearer for beginners.

ข้อมูลและข้อกำหนดGiven Data and Requirements
ตัวแปรสะสมAccumulatorเริ่มด้วย total_sum = 0Begin with total_sum = 0.

ข้อ 12. จำลองการออมเงินเพิ่มขึ้นเท่าตัวทุกปี (5)Simulate savings that double each year
สมชายออมเงินปีแรก $100$ บาท และเพิ่มจำนวนเงินที่ออมในแต่ละปีเป็น 2 เท่าของปีก่อน ($100,200,400,800,\dots$) จงใช้ while หาว่าต้องใช้เวลาอย่างน้อยกี่ปี ยอดออมสะสมจึงไม่น้อยกว่า $1{,}000$ บาท Somchai saves 100 baht in the first year and doubles the amount saved each following year ($100,200,400,800,\dots$). Use a while loop to determine the minimum number of years required for the accumulated savings to reach at least 1,000 baht.
ข้อมูลและข้อกำหนดGiven Data and Requirements
ปีที่ 1Year 1ออม $100$ บาท ยอดสะสม $100$ บาทSave 100 baht; accumulated total = 100 baht.
ปีถัดไปFollowing years$ ext{Savings}= ext{Previous Savings}\times2$
เงื่อนไขหยุดStopping condition$ ext{Total Savings}\ge1000$
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์นี้Write Python code to solve this problem.
เฉลย / Solution
year = 0 savings_this_year = 100 total_savings = 0 while total_savings < 1000: year += 1 total_savings += savings_this_year savings_this_year *= 2 print("จำนวนปี / Number of years:", year) print("ยอดออมสะสม / Accumulated savings:", total_savings, "บาท / baht")
