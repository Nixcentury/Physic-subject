Python Basics — Circle Area Calculation

5 คะแนน
ข้อ 1. การรับค่ารัศมีและคำนวณพื้นที่วงกลม (5)Input radius and calculate circle area
จงเขียนโปรแกรมรับค่ารัศมีของวงกลมจากผู้ใช้ โดยค่ารัศมีอาจเป็นทศนิยมได้ จากนั้นคำนวณพื้นที่วงกลมตามขั้นตอนง่าย ๆ ดังนี้:
พื้นที่วงกลม = 3.1416 × รัศมี × รัศมี
แล้วแสดงคำว่า “พื้นที่วงกลมคือ” พร้อมค่าที่คำนวณได้ออกทางหน้าจอ
Given Data & Requirements / ข้อมูลและข้อกำหนด
ขั้นที่ 1 รับค่ารับค่ารัศมีด้วย input() และแปลงเป็นทศนิยมด้วย float()
ขั้นที่ 2 คำนวณคำนวณด้วย area = 3.1416 * r * r
จะใช้ r ** 2 แทน r * r ก็ได้
ขั้นที่ 3 แสดงผลใช้ print() แสดงคำอธิบายและค่าพื้นที่
ตัวอย่างถ้ารัศมีเท่ากับ 2 พื้นที่จะเท่ากับ 12.5664
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์ปัญหานี้
เฉลย / Solution
r = float(input("กรุณาป้อนรัศมี: ")) area = 3.1416 * r * r print("พื้นที่วงกลมคือ:", area)
💡 แนวทางการเขียนแบบอื่นที่อาจแตกต่างได้:
- บรรทัดเดียวใน print: print("พื้นที่ =", 3.1416 * float(input()) ** 2)
- ใช้เลขยกกำลังแทนการคูณซ้ำ: area = 3.1416 * (r ** 2)

Python Basics — Exponentiation & Power

5 คะแนน
ข้อ 2. คำนวณเลขยกกำลังสองและสาม (5)Calculate Square and Cube values
จงเขียนโปรแกรมรับค่าจำนวนเต็ม $n$ จากผู้ใช้ จากนั้นคำนวณหาค่า $n^2$ (กำลังสอง) และ $n^3$ (กำลังสาม) โดยใช้ตัวดำเนินการ $\mathtt{**}$ แล้วแสดงผลลัพธ์ทั้งสองค่าออกทางหน้าจอ
Given Data & Requirements / ข้อมูลและข้อกำหนด
การรับค่า inputรับค่าจำนวนเต็ม $n$ (แปลงเป็น $\text{int}$)
ตัวดำเนินการใช้ $\mathtt{** 2}$ และ $\mathtt{** 3}$
ผลลัพธ์พิมพ์ค่า $n^2$ และ $n^3$
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์ปัญหานี้
เฉลย / Solution
n = int(input("ป้อนจำนวนเต็ม n: ")) square = n ** 2 cube = n ** 3 print("กำลังสอง:", square) print("กำลังสาม:", cube)
💡 แนวทางการเขียนแบบอื่นที่อาจแตกต่างได้:
- ใช้ f-string แสดงผล: print(f"{n}^2 = {n**2}, {n}^3 = {n**3}")
- คำนวณโดยใช้การคูณ: square = n * n และ cube = n * n * n

Python Basics — Electricity Bill Calculator

5 คะแนน
ข้อ 3. โปรแกรมคำนวณค่าไฟฟ้าเบื้องต้น (5)Basic Electricity Cost Calculation
จงเขียนโปรแกรมคำนวณค่าไฟฟ้า โดยรับจำนวนหน่วยไฟฟ้าที่ใช้ ($u$) เป็นจำนวนจริง จากนั้นคำนวณราคารวมโดยคิดหน่วยละ $4.50$ บาท และบวกค่าบริการรายเดือนคงที่ $38.22$ บาท แล้วแสดงราคารวมสุทธิ
Given Data & Requirements / ข้อมูลและข้อกำหนด
สูตรคำนวณ$\text{Total} = (u \times 4.50) + 38.22$
การรับค่ารับจำนวนหน่วย $u$ เป็น $\text{float}$
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์ปัญหานี้
เฉลย / Solution
units = float(input("ป้อนจำนวนหน่วยไฟฟ้า: ")) total_price = (units * 4.50) + 38.22 print("ค่าไฟฟ้ารวมทั้งหมด:", total_price, "บาท")
💡 แนวทางการเขียนแบบอื่นที่อาจแตกต่างได้:
- กำหนดค่าบริการเป็นตัวแปรคงที่: SERVICE_FEE = 38.22 เพื่อให้อ่านโค้ดง่ายขึ้น
- ใช้การจัดรูปแบบทศนิยม: print("ราคารวม: {:.2f} บาท".format(total_price))

Control Structure — Grade Calculator (if-elif-else)

5 คะแนน
ข้อ 4. โปรแกรมตัดเกรดด้วยเงื่อนไข (5)Grade evaluation using if-elif-else
จงเขียนโปรแกรมรับคะแนนสอบ ($0 \le \text{score} \le 100$) จากผู้ใช้ แล้วตัดเกรดตามเงื่อนไขดังนี้:
- คะแนน $\ge 80$ ได้เกรด "A"
- คะแนน $\ge 70$ ได้เกรด "B"
- คะแนน $\ge 60$ ได้เกรด "C"
- คะแนน $< 60$ ได้เกรด "F"
Given Data & Requirements / ข้อมูลและข้อกำหนด
โครงสร้างโปรแกรมใช้ $\mathtt{if}$, $\mathtt{elif}$, และ $\mathtt{else}$
การรับค่าคะแนนสอบเป็นจำนวนเต็มหรือจำนวนจริง
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์ปัญหานี้
เฉลย / Solution
score = float(input("ป้อนคะแนนสอบ: ")) if score >= 80: print("เกรด: A") elif score >= 70: print("เกรด: B") elif score >= 60: print("เกรด: C") else: print("เกรด: F")
💡 แนวทางการเขียนแบบอื่นที่อาจแตกต่างได้:
- เก็บเกรดใส่ตัวแปรไว้ก่อนแสดงผล: grade = "A" แล้วค่อย print("เกรด:", grade) ด้านล่างสุด
- ตรวจสอบเงื่อนไขจากน้อยไปมาก (เช่น if score < 60: ... elif score < 70: ...)

Control Structure — Number Sign Checker

5 คะแนน
ข้อ 5. ตรวจสอบจำนวนบวก ลบ หรือศูนย์ (5)Check if number is Positive, Negative, or Zero
จงเขียนโปรแกรมรับค่าตัวเลข $1$ จำนวนจากผู้ใช้ แล้วทำการตรวจสอบว่าตัวเลขนั้นเป็น "จำนวนบวก" ($\text{Positive}$), "จำนวนลบ" ($\text{Negative}$) หรือ "ศูนย์" ($\text{Zero}$) แล้วแสดงผลลัพธ์แจ้งผู้ใช้
Given Data & Requirements / ข้อมูลและข้อกำหนด
เงื่อนไข $x > 0$แสดงผล "Positive"
เงื่อนไข $x < 0$แสดงผล "Negative"
เงื่อนไขอื่น ๆ ($x = 0$)แสดงผล "Zero"
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์ปัญหานี้
เฉลย / Solution
num = float(input("ป้อนตัวเลข: ")) if num > 0: print("เป็นจำนวนบวก (Positive)") elif num < 0: print("เป็นจำนวนลบ (Negative)") else: print("เป็นศูนย์ (Zero)")
💡 แนวทางการเขียนแบบอื่นที่อาจแตกต่างได้:
- เช็กกรณีศูนย์ก่อน: if num == 0: ... elif num > 0: ... else: ...
- ใช้ if ซ้อน if (Nested IF): if num != 0: (if num > 0: ... else: ...) else: ...

Control Structure — Discount Calculator

5 คะแนน
ข้อ 6. คำนวณส่วนลดตามยอดซื้อ (5)Discount calculation based on total purchase
ร้านค้าจัดโปรโมชัน: หากซื้อสินค้าครบ $1,000$ บาทขึ้นไป จะได้รับส่วนลด $10\%$ ของยอดซื้อ หากซื้อไม่ถึง $1,000$ บาทจะไม่ได้รับส่วนลด (ส่วนลด $0\%$) จงเขียนโปรแกรมรับยอดซื้อ และคำนวณหาราคาสุทธิที่ต้องจ่าย
Given Data & Requirements / ข้อมูลและข้อกำหนด
ยอดซื้อ $\ge 1000$$\text{Discount} = \text{Total} \times 0.10$
ยอดซื้อ $< 1000$$\text{Discount} = 0$
ยอดสุทธิ$\text{Net Price} = \text{Total} - \text{Discount}$
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์ปัญหานี้
เฉลย / Solution
total = float(input("ป้อนยอดซื้อสินค้า (บาท): ")) if total >= 1000: discount = total * 0.10 else: discount = 0.0 net_price = total - discount print("ส่วนลดที่ได้:", discount, "บาท") print("ราคาสุทธิที่ต้องจ่าย:", net_price, "บาท")
💡 แนวทางการเขียนแบบอื่นที่อาจแตกต่างได้:
- คำนวณราคาสุทธิโดยตรง: net_price = total * 0.90 เมื่อเข้าเงื่อนไขส่วนลด
- ตั้งค่าเริ่มต้นให้ discount = 0 ก่อน แล้วใช้ if total >= 1000: discount = total * 0.10 โดยไม่ต้องมี else

5 คะแนน
ข้อ 7. โปรแกรมแม่สูตรคูณ (5)Multiplication table generator using for loop
จงเขียนโปรแกรมรับค่าแม่สูตรคูณ (จำนวนเต็ม $N$) จากนั้นใช้คำสั่ง $\mathtt{for}$ loop ร่วมกับ $\mathtt{range()}$ เพื่อแสดงแม่สูตรคูณตั้งแต่คูณ $1$ ถึง $12$ เช่น ถ้าป้อน $2$ ให้แสดง $2 \times 1 = 2$ จนถึง $2 \times 12 = 24$
Given Data & Requirements / ข้อมูลและข้อกำหนด

Loop Control — Sum of 1 to N (for loop)

5 คะแนน
ข้อ 8. หาผลรวมของตัวเลข 1 ถึง N (5)Sum of numbers from 1 to N
จงเขียนโปรแกรมรับค่าจำนวนเต็มบวก $N$ จากผู้ใช้ จากนั้นใช้ $\mathtt{for}$ loop ในการคำนวณหาผลรวมของตัวเลขตั้งแต่ $1$ ถึง $N$ ($1 + 2 + 3 + \dots + N$) แล้วแสดงผลรวมสะสมสุดท้ายออกทางหน้าจอ
Given Data & Requirements / ข้อมูลและข้อกำหนด
ตัวแปรเก็บผลรวมกำหนดตัวแปรเริ่มต้น $\mathtt{total\_sum = 0}$
การใช้ range$\mathtt{range(1, N + 1)}$
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์ปัญหานี้
เฉลย / Solution
n = int(input("ป้อนค่า N: ")) total_sum = 0 for i in range(1, n + 1): total_sum = total_sum + i print("ผลรวมตั้งแต่ 1 ถึง", n, "คือ:", total_sum)
💡 แนวทางการเขียนแบบอื่นที่อาจแตกต่างได้:
- ใช้ตัวดำเนินการสะสม: total_sum += i
- ใช้ฟังก์ชันทางลัดของ Python: print("ผลรวม:", sum(range(1, n + 1)))
- ใช้สูตรอนุกรมคณิตศาสตร์: total_sum = n * (n + 1) // 2

Loop Control — Pattern Printing (for loop)

5 คะแนน
ข้อ 9. โปรแกรมพิมพ์รูปทรงดาว (5)Star Pattern Printing
จงเขียนโปรแกรมรับจำนวนบรรทัด $N$ (จำนวนเต็ม) จากนั้นใช้ $\mathtt{for}$ loop เพื่อพิมพ์เครื่องหมายดาว $\mathtt{*}$ เพิ่มขึ้นทีละ $1$ ดวงในแต่ละบรรทัด จนครบ $N$ บรรทัด (ตัวอย่างถ้า $N=3$ บรรทัดแรกพิมพ์ $\mathtt{*}$, บรรทัดสองพิมพ์ $\mathtt{**}$, บรรทัดสามพิมพ์ $\mathtt{***}$)
Given Data & Requirements / ข้อมูลและข้อกำหนด
คุณสมบัติการคูณสตริง$\mathtt{"*" * i}$ จะได้ดาว $i$ ดวง
จำนวนบรรทัดวนลูป $N$ รอบด้วย $\mathtt{range(1, N + 1)}$
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์ปัญหานี้
เฉลย / Solution
n = int(input("ป้อนจำนวนบรรทัด: ")) for i in range(1, n + 1): print("*" * i)
💡 แนวทางการเขียนแบบอื่นที่อาจแตกต่างได้:
- ใช้ Nested Loop (ลูปซ้อนลูป):
for i in range(1, n + 1):
    for j in range(i):
        print("*", end="")
    print()

Loop Control — Sentinel Loop (while loop)

ข้อ 10. วนรับค่าตัวเลขจนกว่าจะป้อน 0 (5)Sum numbers until 0 is entered
จงเขียนโปรแกรมรับตัวเลขจากผู้ใช้ไปเรื่อย ๆ โดยใช้ $\mathtt{while}$ loop แล้วนำตัวเลขมาบวกสะสมไว้ โปรแกรมจะหยุดทำงานก็ต่อเมื่อผู้ใช้ป้อนเลข $0$ จากนั้นให้แสดงผลรวมทั้งหมดออกทางหน้าจอ
Given Data & Requirements / ข้อมูลและข้อกำหนด
เงื่อนไขการหยุดเมื่อป้อนตัวเลขเป็น $0$
การวนลูปใช้ $\mathtt{while}$ loop ในการรับค่าและบวกสะสม
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์ปัญหานี้
เฉลย / Solution
total = 0 num = float(input("ป้อนตัวเลข (ป้อน 0 เพื่อจบ): ")) while num != 0: total += num num = float(input("ป้อนตัวเลข (ป้อน 0 เพื่อจบ): ")) print("ผลรวมทั้งหมดคือ:", total)
💡 แนวทางการเขียนแบบอื่นที่อาจแตกต่างได้:
- ใช้ while True: ร่วมกับ break:
total = 0
while True:
    num = float(input("ป้อนตัวเลข: "))
    if num == 0: break
    total += num

Loop Control — Number Guessing Game (while loop)

5 คะแนน
ข้อ 11. เกมทายตัวเลขปริศนา (5)Number Guessing Game with while loop
กำหนดให้ตัวเลขลับคือ $\text{secret} = 7$ จงเขียนโปรแกรมวนรับค่าการทายตัวเลขจากผู้ใช้ด้วย $\mathtt{while}$ loop หากผู้ใช้ทายไม่ถูก ให้พิมพ์ว่า "ยังไม่ถูกต้อง ลองใหม่!" แล้วรับค่าใหม่ แต่ถ้าทายถูก ให้พิมพ์ว่า "ยินดีด้วย! ทายถูกต้องแล้ว" แล้วจบการทำงาน
Given Data & Requirements / ข้อมูลและข้อกำหนด
เลขลับ (Secret)$\text{secret} = 7$
เงื่อนไขวนลูปวนลูปจนกว่าตัวเลขที่ทายจะเท่ากับ $\text{secret}$
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์ปัญหานี้
เฉลย / Solution
secret = 7 guess = int(input("ทายตัวเลขปริศนา (1-10): ")) while guess != secret: print("ยังไม่ถูกต้อง ลองใหม่!") guess = int(input("ทายตัวเลขปริศนา (1-10): ")) print("ยินดีด้วย! ทายถูกต้องแล้ว")
💡 แนวทางการเขียนแบบอื่นที่อาจแตกต่างได้:
- ใช้ while True: ร่วมกับ if guess == secret: break
- เพิ่มระบบคำใบ้ (Hint) เช่น บอกว่าเลขที่ทาย "มากไป" หรือ "น้อยไป" เพิ่มเติมได้

Integrated Problem — Compound Savings Simulation

5 คะแนน
ข้อ 12. จำลองการออมเงินเพิ่มขึ้นเท่าตัวทุกปี (5)Simulate doubled annual savings using while loop
นายสมชายเริ่มต้นออมเงินปีแรก $100$ บาท และตั้งใจจะออมเงินเพิ่มขึ้นเป็น $2$ เท่าของปีก่อนหน้าทุกปี ($100, 200, 400, 800, \dots$) จงเขียนโปรแกรมคำนวณว่า ต้องใช้เวลาอย่างน้อยกี่ปี เงินออมสะสมรวมจึงจะมีค่า ไม่ต่ำกว่า $1,000$ บาท
Given Data & Requirements / ข้อมูลและข้อกำหนด
ปีที่ 1ออม $100$, ยอดสะสม $= 100$
ปีถัดไป$\text{Savings} = \text{Previous Savings} \times 2$
เงื่อนไขหยุดวนลูป$\text{Total Savings} \ge 1000$
จงเขียนโค้ดภาษา Python เพื่อแก้โจทย์ปัญหานี้
เฉลย / Solution
year = 0 savings_this_year = 100 total_savings = 0 while total_savings < 1000: year += 1 total_savings += savings_this_year savings_this_year *= 2 print("ต้องใช้เวลาทั้งหมด:", year, "ปี") print("ยอดเงินออมสะสมรวม:", total_savings, "บาท")
💡 แนวทางการเขียนแบบอื่นที่อาจแตกต่างได้:
- คำนวณยอดเงินออมปีถัดไปด้วย 100 * (2 ** (year - 1)) ภายในลูป
- ใช้ for loop ร่วมกับเงื่อนไข if total_savings >= 1000: break
