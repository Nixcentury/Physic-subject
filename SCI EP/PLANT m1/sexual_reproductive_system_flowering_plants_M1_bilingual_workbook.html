1. ดอกคืออวัยวะสืบพันธุ์ / The Flower Is a Reproductive Organ

ดอกเป็นอวัยวะสืบพันธุ์แบบอาศัยเพศของพืชดอก ส่วนต่าง ๆ ของดอกช่วยกัน ป้องกันดอก ดึงดูดสัตว์ที่ช่วยผสมเกสร และสร้างเซลล์สืบพันธุ์เพศผู้และเพศเมีย ดอกติดอยู่บนส่วนปลายที่ขยายของก้านดอก เรียกว่า ฐานรองดอก หรือ receptacle

Flowers are the sexual reproductive organs of flowering plants. Different flower parts protect the flower, attract animal pollinators and produce male and female gametes. The flower sits on the expanded end of a flower stalk called the receptacle.

เกสรเพศผู้และเกสรเพศเมีย

Male and Female Parts of a Flower

2. เกสรเพศผู้ / Male Part

STAMEN — เกสรเพศผู้
Stamen = Anther + Filament
Anther — อับเรณู ผลิตและมีละอองเรณูอยู่ภายใน
Produces and contains pollen grains.
Filament — ก้านชูอับเรณู รองรับอับเรณู
Supports the anther.
เส้นจำเพศผู้ / Male memory line
Anther → Pollen grains → Male gametes
อับเรณู → ละอองเรณู → เซลล์สืบพันธุ์เพศผู้

3. เกสรเพศเมีย / Female Part

PISTIL — เกสรเพศเมีย
Pistil = Stigma + Style + Ovary + Ovule
Stigma — ยอดเกสรเพศเมีย รับละอองเรณู
Receives pollen grains.
Style — ก้านเกสรเพศเมีย เชื่อม stigma กับ ovary
Connects the stigma to the ovary.
Ovary — รังไข่ ป้องกันและมี ovules อยู่ภายใน
Protects and contains the ovules.
Ovule — ออวุล มีเซลล์สืบพันธุ์เพศเมีย
Contains the female gamete.
เส้นจำเพศเมีย / Female memory line
Ovary → Ovules → Female gametes
รังไข่ → ออวุล → เซลล์สืบพันธุ์เพศเมีย

4. แผนผังความสัมพันธ์ / Relationship Map

FLOWER / ดอก │ ├── MALE / เพศผู้ │ └── STAMEN │ ├── ANTHER │ │ └── POLLEN GRAINS │ │ └── MALE GAMETES │ └── FILAMENT │ └── FEMALE / เพศเมีย └── PISTIL ├── STIGMA ├── STYLE └── OVARY └── OVULE └── FEMALE GAMETE
Stamen = male system • Pistil = female system

7. ดอกแยกเพศและดอกสมบูรณ์เพศ / Unisexual and Bisexual Flowers

Male flower
Stamen ✓
Pistil ✗
Female flower
Stamen ✗
Pistil ✓
Bisexual flower
Stamen ✓
Pistil ✓

ดอกแยกเพศ (unisexual flower) มีเกสรเพศผู้หรือเกสรเพศเมีย อย่างใดอย่างหนึ่ง ส่วน ดอกสมบูรณ์เพศ (bisexual flower) มีทั้งเกสรเพศผู้และเกสรเพศเมียในดอกเดียวกัน

A unisexual flower contains either stamens or a pistil. A bisexual flower contains both stamens and a pistil.

การสืบพันธุ์แบบอาศัยเพศเกี่ยวข้องกับเซลล์สืบพันธุ์เพศผู้และเพศเมีย pollen grains มี male gametes ส่วน ovule มี female gamete

Sexual reproduction involves male and female gametes. Pollen grains contain male gametes, while an ovule contains the female gamete.
