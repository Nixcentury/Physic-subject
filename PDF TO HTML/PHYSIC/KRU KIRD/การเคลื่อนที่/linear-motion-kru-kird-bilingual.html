Summary 1 / 10

ตำแหน่งและจุดอ้างอิง / Position and Reference Point

แนวคิด / CONCEPT
ตำแหน่งบอกว่าวัตถุอยู่ที่ใดเมื่อเทียบกับจุดอ้างอิงที่กำหนด ก่อนคำนวณต้องกำหนดทิศบวกให้ชัดเจน เช่น ขวาเป็นบวก หรือขึ้นเป็นบวก
Position tells where an object is relative to a chosen reference point. Before calculating, choose a positive direction, such as rightward or upward.

ระยะทาง / Distance

นิยาม / DEFINITION
ระยะทางคือความยาวของเส้นทางทั้งหมดที่วัตถุเคลื่อนที่ เป็นปริมาณที่ไม่มีทิศทาง
Distance is the total length of the path travelled. It has no direction.
\[\boxed{d=\text{ผลรวมความยาวทุกช่วง / sum of all path lengths}}\]

การกระจัด / Displacement

นิยาม + สูตร / DEFINITION + FORMULA
การกระจัดบอกการเปลี่ยนตำแหน่งจากจุดเริ่มต้นไปยังจุดสุดท้าย จึงขึ้นกับจุดเริ่มและจุดจบ ไม่ขึ้นกับเส้นทางที่ใช้
Displacement is the change from initial to final position. It depends only on the endpoints, not the path.
\[\boxed{\Delta x=x_f-x_i}\qquad\boxed{\Delta y=y_f-y_i}\]

ระยะทางกับขนาดการกระจัด / Distance versus Displacement Magnitude

ภาพ + พิสูจน์ / DIAGRAM + PROOF
\[\boxed{d\ge |\Delta\vec r|}\]
กรณีเคลื่อนที่สองแนวตั้งฉาก / Perpendicular changes
\[\boxed{|\Delta\vec r|=\sqrt{(\Delta x)^2+(\Delta y)^2}}\]
สูตรนี้ใช้หาขนาดการกระจัดจากพีทาโกรัส โดยยังไม่ต้องใช้การแตกเวกเตอร์
This gives displacement magnitude by Pythagoras without requiring vector components.
เมื่อกลับถึงจุดเริ่มต้น \(\Delta r=0\) แต่ระยะทาง \(d\) ไม่เป็นศูนย์
After returning to the start, displacement is zero but distance is not.

Speed and velocity
สรุป 2 / 10
Summary 2 / 10

อัตราเร็วเฉลี่ย / Average Speed

นิยาม + สูตร / DEFINITION + FORMULA
อัตราเร็วเฉลี่ยเปรียบเทียบระยะทางทั้งหมดกับเวลารวมทั้งหมด
Average speed compares total distance with total time.
\[\boxed{v_{\mathrm{speed,avg}}=\frac{d_{\mathrm{total}}}{\Delta t_{\mathrm{total}}}}\]
ใช้ระยะทางทุกช่วง แม้วัตถุจะย้อนกลับ
Include every path segment, even when the object reverses.

ความเร็วเฉลี่ย / Average Velocity

นิยาม + สูตร / DEFINITION + FORMULA
ความเร็วเฉลี่ยเปรียบเทียบการกระจัดกับเวลารวม จึงต้องมีทิศหรือเครื่องหมาย
Average velocity compares displacement with total time, so direction or sign is required.
\[\boxed{v_{\mathrm{avg}}=\frac{\Delta x}{\Delta t}}\qquad\text{หรือ / or}\qquad\boxed{v_{\mathrm{avg}}=\frac{\Delta y}{\Delta t}}\]
ถ้ากลับจุดเดิม ความเร็วเฉลี่ยเป็นศูนย์ แต่อัตราเร็วเฉลี่ยยังเป็นบวก
For a round trip, average velocity is zero but average speed remains positive.

หลายช่วงต้องรวมก่อนหาร / Combine All Segments Before Dividing

วิธีคิด / METHOD
ห้ามนำอัตราเร็วแต่ละช่วงมาเฉลี่ยเลขคณิตทันที เว้นแต่แต่ละช่วงใช้เวลาเท่ากัน ต้องหาผลรวมระยะทางและผลรวมเวลาก่อน
Do not simply average segment speeds unless the time intervals are equal. First add all distances and all times.
ตัวอย่างโครงสร้าง / Structure
\[d_{\mathrm{total}}=d_1+d_2+d_3\]
\[\Delta t_{\mathrm{total}}=t_1+t_2+t_3\]
\[v_{\mathrm{speed,avg}}=\frac{d_1+d_2+d_3}{t_1+t_2+t_3}\]

การแปลงหน่วย / Unit Conversion

หน่วย / UNITS
\[1\,\mathrm{m/s}=3.6\,\mathrm{km/h}\]
\[1\,\mathrm{km/h}=\frac{1}{3.6}\,\mathrm{m/s}\]

การห่างกันของวัตถุ / Separation of Objects

แนวคิด / CONCEPT
เมื่อวัตถุเคลื่อนที่ทิศเดียวกันด้วยอัตราเร็วคงตัว ขนาดของความเร็วสัมพัทธ์เท่ากับผลต่างของอัตราเร็ว
For constant-speed motion in the same direction, the relative speed is the absolute difference between the two speeds.
\[\boxed{v_{\mathrm{rel}}=|v_1-v_2|}\qquad |\Delta d|=v_{\mathrm{rel}}t\]

ตรวจด้วยความหมาย ไม่ใช่จำชื่อ / Check the Meaning

จุดสับสน / MISCONCEPTION
คำถามQuestionตัวตั้งNumeratorสิ่งที่ต้องบอกRequired information

Ticker tape and ticker timer
สรุป 3 / 10
Summary 3 / 10

ความถี่บอกเวลาระหว่างจุด / Frequency Gives the Time Between Dots

ความหมาย + พิสูจน์ / MEANING + PROOF
เครื่องเคาะความถี่ \(f\) ครั้งต่อวินาที หมายถึงในเวลา \(1\,\mathrm s\) เกิดช่วงเวลาเท่า ๆ กันจำนวน \(f\) ช่วง
A timer of frequency \(f\) marks \(f\) equal time intervals in one second.
\[\Delta t_{\mathrm{one\ gap}}=\frac{1\,\mathrm s}{f}\]
\[f=50\,\mathrm{Hz}\Rightarrow \Delta t=\frac1{50}=0.020\,\mathrm s\]
ให้นับ “ช่องว่างระหว่างจุด” ไม่ใช่นับจำนวนจุด เช่น จุดที่ 1 ถึงจุดที่ 6 มี 5 ช่วงเวลา
Count gaps, not dots. Dots 1 to 6 contain five time intervals.

อ่านลักษณะการเคลื่อนที่จากระยะห่าง / Read Motion from Dot Spacing

ภาพ + เหตุผล / DIAGRAM + REASONING
ทุกช่องใช้เวลาเท่ากัน จึงเปรียบเทียบอัตราเร็วได้จากระยะทางในแต่ละช่อง: ช่องเท่ากัน → อัตราเร็วคงตัว, ช่องกว้างขึ้น → เร็วขึ้น, ช่องแคบลง → ช้าลง
All gaps represent equal times. Equal spacing means constant speed; increasing spacing means speeding up; decreasing spacing means slowing down.

อัตราเร็วเฉลี่ยช่วง A-B / Average Speed over A-B

ขั้นตอน / STEPS
  1. วัดระยะจาก A ถึง B
  2. นับจำนวนช่องเวลา
  3. คูณจำนวนช่องด้วย \(1/f\)
  4. ใช้ระยะทางหารเวลา
\[v_{\mathrm{avg},A\to B}=\frac{d_{A\to B}}{N_{\mathrm{gaps}}(1/f)}\]

อัตราเร็วใกล้จุดหนึ่ง / Speed Near One Dot

เหตุผล / REASONING
จุดเดียวไม่มีระยะทางให้หาร จึงเลือกช่วงสั้น ๆ ที่คร่อมจุดเป้าหมายอย่างสมมาตร เช่น ต้องการค่าที่จุด 10 ให้วัดจากจุด 9 ถึง 11
A single dot has no distance. Use a short symmetric interval around the target, such as dots 9 to 11 for the speed near dot 10.
\[v_{10}\approx\frac{d_{9\to11}}{2(0.020\,\mathrm s)}\]

หาความเร่งโดยไม่ท่องสูตรลัด / Find Acceleration Without a Shortcut

วิธีคิด / METHOD
หาอัตราเร็วใกล้ตำแหน่งแรกและตำแหน่งหลัง แล้วใช้ความเร็วที่เปลี่ยนไปหารด้วยเวลาระหว่างตำแหน่งทั้งสอง
Estimate speed near the first and later positions, then divide the change in speed by the elapsed time between those positions.
\[a=\frac{v_{\mathrm{after}}-v_{\mathrm{before}}}{\Delta t}\]

ความเร่งเฉลี่ย / Average Acceleration

นิยาม + สูตร / DEFINITION + FORMULA
ความเร่งบอกว่าความเร็วเปลี่ยนไปเท่าใดในหนึ่งหน่วยเวลา การเปลี่ยนความเร็วอาจเกิดจากเร็วขึ้น ช้าลง หรือเปลี่ยนทิศ
Acceleration measures how much velocity changes per unit time. Velocity can change by speeding up, slowing down, or reversing direction.
\[\Delta v=v_f-v_i\]
\[\boxed{a_{\mathrm{avg}}=\frac{\Delta v}{\Delta t}=\frac{v_f-v_i}{\Delta t}}\]
หน่วย SI คือ \(\mathrm{m/s^2}\) หมายถึงความเร็วเปลี่ยนกี่ \(\mathrm{m/s}\) ในทุก 1 วินาที
The SI unit \(\mathrm{m/s^2}\) tells how many metres per second the velocity changes each second.

ความชัน = แกนตั้งหารแกนนอน / Slope = Vertical Change ÷ Horizontal Change

หลักจำ + พิสูจน์ / MEMORY + PROOF
\[\boxed{\mathrm{slope}=\frac{\Delta Y}{\Delta X}}\]
ให้ดูชื่อแกนก่อนเสมอ แล้วนำ “ปริมาณแกนตั้งที่เปลี่ยนไป” หารด้วย “ปริมาณแกนนอนที่เปลี่ยนไป” หน่วยของผลหารจะช่วยตรวจว่าความชันแทนปริมาณใด

Begin with a constant-value graph, which forms a rectangle. Its area is base × height. Then inspect the units of y-axis × x-axis.

พิสูจน์ว่าความชันคือความเร็ว / Proving that Slope Represents Velocity

พิสูจน์ / PROOF
กราฟนี้มีตำแหน่ง \(x\) อยู่แกนตั้ง และเวลา \(t\) อยู่แกนนอน
Position \(x\) is on the vertical axis and time \(t\) is on the horizontal axis.
\[\text{ความชัน / slope}=\frac{\Delta x}{\Delta t}\]
\[\text{จากนิยาม / by definition: }v_{\mathrm{avg}}=\frac{\Delta x}{\Delta t}\]
\[\boxed{\mathrm{slope}_{\mathrm{secant}}=v_{\mathrm{avg}}}\qquad\boxed{\mathrm{slope}_{\mathrm{tangent}}=v}\]
เส้นเชื่อมสองจุดให้ความเร็วเฉลี่ย ส่วนเส้นสัมผัส ณ จุดหนึ่งให้ความเร็วขณะหนึ่ง หน่วยคือ \(\mathrm{m/s}\)
A secant through two points gives average velocity; a tangent at one point gives instantaneous velocity. The unit is \(\mathrm{m/s}\).

ความชันของกราฟ \(v-t\) คือความเร่ง / Slope of a \(v-t\) Graph Is Acceleration

พิสูจน์ / PROOF
\[\text{ความชัน / slope}=\frac{\Delta v}{\Delta t}\]
\[a=\frac{v_f-v_i}{\Delta t}=\frac{\Delta v}{\Delta t}\]
\[\boxed{\mathrm{slope}_{\mathrm{secant}}=a_{\mathrm{avg}}}\qquad\boxed{\mathrm{slope}_{\mathrm{tangent}}=a}\]
เส้นเชื่อมให้ความเร่งเฉลี่ย ส่วนเส้นสัมผัสให้ความเร่งขณะหนึ่ง หน่วย \((\mathrm{m/s})/\mathrm s=\mathrm{m/s^2}\)
A secant gives average acceleration; a tangent gives instantaneous acceleration. The unit is \(\mathrm{m/s^2}\).

พื้นที่ใต้กราฟ \(v-t\) คือการกระจัด / Area under \(v-t\) Is Displacement

พิสูจน์จากรูป / GEOMETRIC PROOF
\[\text{พื้นที่ / area}=(\text{ฐาน / base})(\text{สูง / height})=tv\]
\[\text{เมื่อ / when }v\text{ คงตัว / is constant: }\Delta x=vt\]
\[\boxed{\text{พื้นที่เชิงเครื่องหมายใต้กราฟ / signed area under }v-t=\Delta x}\]
ตรวจหน่วย: \((\mathrm{m/s})(\mathrm s)=\mathrm m\)

เหนือและใต้แกนเวลา / Above and Below the Time Axis

เครื่องหมาย / SIGNS
พื้นที่เหนือแกนเวลาเป็นการกระจัดบวก ส่วนพื้นที่ใต้แกนเวลาเป็นการกระจัดลบ เมื่อต้องการระยะทางให้แบ่งช่วงที่ \(v=0\) แล้วรวมขนาดพื้นที่ทุกช่วง
Area above the axis gives positive displacement; area below gives negative displacement. For distance, split where \(v=0\) and add the absolute areas.
\[\Delta x=A_{+}-A_{-}\]
\[d=|A_1|+|A_2|+\cdots\]

พื้นที่ใต้กราฟ \(a-t\) / Area under \(a-t\)

พิสูจน์ / PROOF
\[a=\frac{\Delta v}{\Delta t}\]
\[\Delta v=a\Delta t\]
\[\boxed{\text{พื้นที่เชิงเครื่องหมายใต้กราฟ / signed area under }a-t=\Delta v}\]
หน่วย \((\mathrm{m/s^2})(\mathrm s)=\mathrm{m/s}\)
Unit: \((\mathrm{m/s^2})(\mathrm s)=\mathrm{m/s}\).

สมการที่ 1 จากความชันกราฟ \(v-t\) / Equation 1 from Slope

พิสูจน์ / PROOF
\[a=\frac{v_f-v_i}{t}\]
\[at=v_f-v_i\]
\[\boxed{v_f=v_i+at}\]

พิสูจน์ด้วยรูป / GEOMETRIC PROOF

\[v_f-v_i=at\]

เลือกทิศบวกก่อนแทนค่า / Choose the Positive Direction First

หลักสำคัญ / KEY RULE
ความเร่งเนื่องจากแรงโน้มถ่วงชี้ลงเสมอ ถ้ากำหนดขึ้นเป็นบวก จะใช้ \(a=-g\) ถ้ากำหนดลงเป็นบวก จะใช้ \(a=+g\)
Gravitational acceleration always points downward. If upward is positive, use \(a=-g\); if downward is positive, use \(a=+g\).
เลือกแกนหนึ่งครั้ง แล้วรักษาเครื่องหมายให้สม่ำเสมอตลอดข้อ
Choose once and keep the sign convention consistent.

ใช้สมการเดิม โดยแทน \(a\) ด้วย \(\pm g\) / Use the Same Equations with \(a=\pm g\)

สูตร / FORMULAS

ค่าที่โจทย์ชุดนี้ใช้บ่อยคือ \(g=10\,\mathrm{m/s^2}\) แต่ต้องอ่านค่าที่โจทย์กำหนดทุกครั้ง
These exercises often use \(g=10\,\mathrm{m/s^2}\), but always follow the stated value.

โยนลง / Thrown Downward

กรณีพิเศษ / SPECIAL CASE

A downward throw has nonzero initial velocity, in the same direction as gravity when downward is positive.
\[h=v_it+\frac12gt^2\]

โยนขึ้นในแนวดิ่ง / Vertical Projection Upward

พิสูจน์จุดสำคัญ / KEY RESULTS
เมื่อกำหนดขึ้นเป็นบวก ใช้ \(a=-g\) ที่จุดสูงสุดความเร็วเป็นศูนย์ชั่วขณะ แต่ความเร่งยังเท่ากับ \(-g\)
With upward positive, use \(a=-g\). At the highest point, velocity is momentarily zero, but acceleration remains \(-g\).
ที่จุดสูงสุด / At the highest point: \(v_f=0\)
\[0=v_i-gt_{\mathrm{up}}\Rightarrow\boxed{t_{\mathrm{up}}=\frac{v_i}{g}}\]
\[0=v_i^2-2g\Delta y_{\max}\Rightarrow\boxed{\Delta y_{\max}=\frac{v_i^2}{2g}}\]
ถ้ากลับระดับเดิม / If it returns to the launch level: \[\boxed{t_{\mathrm{total}}=\frac{2v_i}{g}}\]
ที่จุดสูงสุด \(v=0\) แต่ \(a\neq0\) วัตถุจึงเปลี่ยนจากขาขึ้นเป็นขาลง
At the top, \(v=0\) but \(a\ne0\), so the object reverses from upward to downward motion.

ปล่อยวัตถุจากบอลลูนที่กำลังเคลื่อนที่ / Releasing an Object from a Moving Balloon

แนวคิด + พิสูจน์ / CONCEPT + PROOF
ทันทีที่ปล่อย วัตถุยังมีความเร็วเท่ากับบอลลูนในขณะนั้น หากบอลลูนเคลื่อนที่ด้วยความเร็วคงตัวและไม่คิดแรงต้านอากาศ บอลลูนจะเคลื่อนที่ต่อ ส่วนวัตถุมีความเร่งลงด้วย \(g\)
At release, the object keeps the balloon’s instantaneous velocity. If the balloon moves at constant velocity and air resistance is neglected, the balloon continues uniformly while the object accelerates downward at \(g\).

ความเร็วกระทบพื้น / Impact Speed

วิธีเลือกสูตร / METHOD
ถ้าโจทย์ถามอัตราเร็วกระทบและไม่ถามเวลา ใช้สมการที่ไม่มี \(t\) แล้วตอบเป็นขนาด \(|v_f|\)
When impact speed is required but time is not, use the equation without \(t\) and report the magnitude \(|v_f|\).
\[v_f^2=v_i^2+2a\Delta y\]
เครื่องหมายของ \(a\) และ \(\Delta y\) ต้องสอดคล้องกับแกนที่เลือก
The signs of \(a\) and \(\Delta y\) must match the chosen axis.

ครึ่งหนึ่งของความสูงสูงสุด / Half the Maximum Height

เหตุผล / REASONING
หาความสูงสูงสุดจาก \(v_f=0\) ก่อน แล้วแทน \(\Delta y\) เป็นครึ่งหนึ่งของค่านั้นในสมการ \(v_f^2=v_i^2+2a\Delta y\)
First find maximum height using \(v_f=0\), then substitute half that displacement into \(v_f^2=v_i^2+2a\Delta y\).
\[\boxed{|v|=\frac{v_i}{\sqrt2}}\]
