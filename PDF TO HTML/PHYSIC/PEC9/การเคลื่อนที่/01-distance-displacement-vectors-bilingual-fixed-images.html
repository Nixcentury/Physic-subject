Distance, Displacement and Vectors • Introduction

ระยะทางและการกระจัด Distance and Displacement

Core Concept 1
ปริมาณความหมายลักษณะสัญลักษณ์
ระยะทางDistanceความยาวทั้งหมดตามเส้นทางที่เคลื่อนที่จริงTotal length of the actual path travelledสเกลาร์ มีเฉพาะขนาดScalar; magnitude only$d$
การกระจัดDisplacementการเปลี่ยนตำแหน่งจากจุดเริ่มต้นไปยังจุดสุดท้ายChange in position from initial to final pointเวกเตอร์ มีขนาดและทิศทางVector; magnitude and direction$\Delta x,\ \Delta y,\ \Delta\vec r$

หนึ่งมิติ / One Dimension

$$\Delta x=x_f-x_i$$

เครื่องหมายของ $\Delta x$ บอกทิศตามแกนที่กำหนด เช่น ขวาเป็นบวกและซ้ายเป็นลบThe sign of $\Delta x$ indicates direction along the chosen axis.

สองมิติ / Two Dimensions

$$\Delta\vec r=\Delta x\,\hat i+\Delta y\,\hat j$$
$$|\Delta\vec r|=\sqrt{(\Delta x)^2+(\Delta y)^2}$$
ข้อสังเกตสำคัญ / Important Observation
สำหรับการเคลื่อนที่ระหว่างสองจุด ระยะทางจะไม่น้อยกว่าขนาดของการกระจัด $$d\ge |\Delta\vec r|$$ และจะเท่ากันเมื่อวัตถุเคลื่อนที่เป็นเส้นตรงไปทางเดียวโดยไม่ย้อนกลับDistance is never less than displacement magnitude. Equality occurs for straight-line motion in one direction without turning back.

เส้นทางมุมฉาก / Right-Angle Path

ถ้า $\Delta x=4\ \mathrm{m}$ และ $\Delta y=3\ \mathrm{m}$

$$|\Delta\vec r|=\sqrt{4^2+3^2}=5\ \mathrm{m}$$

แต่ระยะทางตามเส้นทางคือ $d=4+3=7\ \mathrm{m}$

ส่วนโค้งและวงกลม / Arcs and Circles

ระยะทางวัดตามส่วนโค้ง แต่การกระจัดเป็นเส้นตรงเชื่อมจุดต้นกับจุดปลายDistance follows the arc; displacement is the straight line joining the endpoints.

ครึ่งวงกลม: $d=\pi R$, $|\Delta\vec r|=2R$

ครบหนึ่งรอบ: $d=2\pi R$, $|\Delta\vec r|=0$

เวกเตอร์และเวกเตอร์ลัพธ์ Vectors and Resultants

Core Concept 2

เวกเตอร์แทนด้วยลูกศร A vector is represented by an arrow

  • ความยาวของลูกศรแทนขนาดArrow length represents magnitude.
  • หัวลูกศรแทนทิศทางThe arrowhead represents direction.
  • การเลื่อนเวกเตอร์โดยไม่หมุนไม่เปลี่ยนเวกเตอร์Translating a vector without rotating it does not change the vector.

การลบเวกเตอร์ Vector Subtraction

$$\vec a-\vec b=\vec a+(-\vec b)$$

$-\vec b$ มีขนาดเท่ากับ $\vec b$ แต่ชี้ทิศตรงข้าม$-\vec b$ has the same magnitude as $\vec b$ but points in the opposite direction.

ขั้นตอน / Procedure
  1. วาดเวกเตอร์ตัวแรก
  2. เลื่อนเวกเตอร์ตัวถัดไปให้หางต่อกับหัวของเวกเตอร์ก่อนหน้า โดยไม่หมุนหรือย่อ–ขยาย
  3. ลากเวกเตอร์ลัพธ์จากหางของตัวแรกไปยังหัวของตัวสุดท้าย
Draw the first vector, translate the next vector so its tail meets the previous head, then draw the resultant from the first tail to the final head.

ถ้าเปลี่ยนจาก $\vec a+\vec b$ เป็น $\vec b+\vec a$ เวกเตอร์ลัพธ์เปลี่ยนหรือไม่? แผนภาพอาจต่างกันอย่างไร? Does changing $\vec a+\vec b$ to $\vec b+\vec a$ change the resultant? How might the construction diagram differ?
แนวคิด / Thinking Guide
เวกเตอร์ลัพธ์ไม่เปลี่ยน เพราะการบวกเวกเตอร์มีสมบัติสลับที่ $\vec a+\vec b=\vec b+\vec a$ ตำแหน่งของลูกศรระหว่างการต่อหัว–หางอาจต่างกัน แต่จุดเริ่มและจุดสุดท้ายของผลลัพธ์ให้ขนาดและทิศเดียวกัน

  • $\vec a$ ชี้ไปทางขวา
  • $-\vec b$ ชี้ลงทางซ้าย
  • $-\vec c$ ชี้ลงทางขวา

องค์ประกอบแนวตั้งของ $-\vec b$ และ $-\vec c$ รวมกันชี้ลง ส่วนองค์ประกอบแนวนอนสุทธิชี้ขวา จึงได้เวกเตอร์ลัพธ์เฉียงลงทางขวาThe vertical components combine downward, while the net horizontal component is rightward.

Closed Vector Path
ข้อ 8 — ความสัมพันธ์ของ $\vec A,\vec B,\vec C,\vec D$
ให้เหตุผล / Reasoning
กำหนด $\vec A$, $\vec B$, $\vec C$ และ $\vec D$ มีขนาดและทิศทางดังรูป ข้อความใดถูกต้อง?The magnitudes and directions of $\vec A$, $\vec B$, $\vec C$, and $\vec D$ are shown. Which statement is correct?
รูปข้อ 8 / Question 8 image
ไฟล์ 8.png
1. $\vec A+\vec B+\vec C+\vec D=\vec 0$
2. $\vec A+\vec B+\vec C=\vec D$
3. $\vec A+\vec B+\vec D=\vec C$
4. $\vec A+\vec B=\vec C+\vec D$
เฉลย / Solution

เริ่มจากมุมซ้ายบน แล้วเดินตามเวกเตอร์แบบหัวต่อหาง:

$$\vec D\ \rightarrow\ \vec A\ \rightarrow\ \vec B$$

เส้นทางนี้พาจากมุมซ้ายบนไปยังมุมขวาบน ซึ่งตรงกับเวกเตอร์ $\vec C$ ดังนั้น

$$\vec D+\vec A+\vec B=\vec C$$

ใช้สมบัติสลับที่ของการบวกเวกเตอร์ได้ว่า

$$\boxed{\vec A+\vec B+\vec D=\vec C}$$
ตอบ / Answer: ตัวเลือก 3 / Option 3
