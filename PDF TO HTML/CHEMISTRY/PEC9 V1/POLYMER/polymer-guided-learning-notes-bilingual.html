Polymer Formation: Addition and Condensation Polymerisation
แนวคิดตั้งต้น: พอลิเมอร์เกิดเมื่อมอนอเมอร์จำนวนมากเชื่อมต่อกันด้วยปฏิกิริยาเคมีที่เกิดซ้ำ ๆ จนได้โมเลกุลขนาดใหญ่ Starting idea: A polymer forms when many monomer molecules become linked through repeated chemical reactions to produce a very large molecule.
Think First — จากเคมีอินทรีย์เดิม สู่พอลิเมอร์ / From familiar organic chemistry to polymers

เราเคยเห็นพันธะคู่ C=C เกิดปฏิกิริยาเติม และเคยเห็นหมู่ฟังก์ชันสร้างเอสเทอร์หรือเอไมด์ ถ้าการสร้างพันธะใหม่เหล่านี้เกิดซ้ำกับโมเลกุลจำนวนมาก จะเกิดอะไรขึ้น?

We have seen C=C bonds undergo addition reactions, and we have seen functional groups form esters or amides. What happens if these bond-forming reactions repeat with many molecules?

2) พอลิเมอไรเซชันแบบควบแน่น Condensation polymerisation

สัญญาณที่ควรมองหา: มอนอเมอร์มีหมู่ฟังก์ชันที่ทำปฏิกิริยาได้อย่างน้อย 2 ตำแหน่งKey signal: monomers contain at least two reactive functional-group positions so the chain can keep growing.

หลักการ: หมู่ฟังก์ชันของมอนอเมอร์ทำปฏิกิริยากัน เกิดพันธะเชื่อมใหม่ และมักมีโมเลกุลขนาดเล็ก เช่น H₂O เกิดออกมา Principle: functional groups react to form new linkages, commonly releasing a small molecule such as H₂O.

ก. สร้างพอลิเอสเทอร์ / Forming a polyester ไดออล + กรดไดคาร์บอกซิลิก → พันธะเอสเทอร์ + น้ำ
diol + dicarboxylic acid → ester linkage + water –OH + –COOH → –COO– + H2O
ข. สร้างพอลิเอไมด์ / Forming a polyamide ไดเอมีน + กรดไดคาร์บอกซิลิก → พันธะเอไมด์ + น้ำ
diamine + dicarboxylic acid → amide linkage + water –NH2 + –COOH → –CONH– + H2O
HO–R–OH + HOOC–R′–COOH → …–O–R–O–CO–R′–CO–… + H2O

Common Trap — เอมีน ≠ เอไมด์ / Amine ≠ Amide
–NH₂ เป็นหมู่เอมีนของสารตั้งต้น ส่วน –CONH– เป็นพันธะเอไมด์ที่พบในสายพอลิเอไมด์ –NH₂ is an amine functional group in a reactant, whereas –CONH– is an amide linkage found in a polyamide chain.
Guided Fill — เติมคำสำคัญระหว่างเรียน / Fill in the key ideas during the lesson
1. แบบเติมมักเริ่มจากมอนอเมอร์ที่มีพันธะ C=CAddition polymerisation commonly starts from a monomer containing a C=C bond.
2. แบบเติมไม่มีโมเลกุลเล็ก เช่น H₂O / น้ำ หลุดออกAddition polymerisation does not eliminate a small molecule such as H₂O / water.
3. แบบควบแน่นต้องมีตำแหน่งหมู่ฟังก์ชันที่ทำปฏิกิริยาได้อย่างน้อย 2 ตำแหน่งCondensation polymerisation needs at least 2 reactive functional-group positions.
4. –COO– คือพันธะ เอสเทอร์ / ester ส่วน –CONH– คือพันธะ เอไมด์ / amide–COO– is an ester linkage, whereas –CONH– is an amide linkage.
Stop & Think: CH₂=CHCl ควรนึกถึงพอลิเมอไรเซชันชนิดใด? แล้ว HO–CH₂–CH₂–OH + HOOC–C₆H₄–COOH ควรนึกถึงชนิดใด? เพราะอะไร? Stop & Think: Which polymerisation type should CH₂=CHCl suggest? Which type should HO–CH₂–CH₂–OH + HOOC–C₆H₄–COOH suggest, and why?
เฉลย / Answer: CH₂=CHCl → addition polymerisation เพราะมี C=C; diol + dicarboxylic acid → condensation polymerisation เพราะหมู่ –OH และ –COOH สร้างพันธะเอสเทอร์พร้อมเกิด H₂O.
CH₂=CHCl → addition polymerisation because it contains C=C; diol + dicarboxylic acid → condensation polymerisation because –OH and –COOH form ester linkages with H₂O as a by-product.
