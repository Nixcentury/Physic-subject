Important Polymers You Should Know — Monomer → Reaction → Structure → Uses

HDPE — พอลิเอทิลีนความหนาแน่นสูง High-density polyethylene

มอนอเมอร์ / Monomer: ethene, CH₂=CH₂
ปฏิกิริยา / Polymerisation: addition
จุดเด่น / Key idea: PE ที่มีกิ่งน้อยกว่า จัดเรียงชิดกันได้ดี / less-branched PE; closer packing
ใช้ทำ / Uses: ขวดแข็ง ท่อ ภาชนะ / rigid bottles, pipes, containers

LDPE — พอลิเอทิลีนความหนาแน่นต่ำ Low-density polyethylene

มอนอเมอร์ / Monomer: ethene, CH₂=CH₂
ปฏิกิริยา / Polymerisation: addition
จุดเด่น / Key idea: PE ที่มีกิ่งมากกว่า จัดเรียงไม่แน่น / more-branched PE; poorer packing
ใช้ทำ / Uses: ถุงพลาสติก ฟิล์มห่อ / bags, flexible films

PP — พอลิโพรพิลีน Polypropylene

มอนอเมอร์ / Monomer: propene, CH₂=CHCH₃
ปฏิกิริยา / Polymerisation: addition
หน่วยซ้ำ / Repeat unit: [–CH₂–CH(CH₃)–]ₙ
ใช้ทำ / Uses: กล่องอาหาร ฝาขวด เชือก / food containers, caps, rope

PVC — พอลิไวนิลคลอไรด์ Poly(vinyl chloride)

มอนอเมอร์ / Monomer: chloroethene, CH₂=CHCl
ปฏิกิริยา / Polymerisation: addition
หน่วยซ้ำ / Repeat unit: [–CH₂–CHCl–]ₙ
ใช้ทำ / Uses: ท่อ ฉนวนสายไฟ / pipes, cable insulation

PS — พอลิสไตรีน Polystyrene

มอนอเมอร์ / Monomer: styrene, CH₂=CH–C₆H₅
ปฏิกิริยา / Polymerisation: addition
จุดสังเกต / Structural clue: phenyl side group / หมู่ฟีนิลด้านข้าง
ใช้ทำ / Uses: โฟม บรรจุภัณฑ์ / foams, packaging

PET — พอลิเอทิลีนเทเรฟทาเลต Poly(ethylene terephthalate)

มอนอเมอร์ 1 / Monomer 1: ethylene glycol / ethane-1,2-diol
มอนอเมอร์ 2 / Monomer 2: terephthalic acid
ปฏิกิริยา + linkage: condensation → ester linkage, –COO–
ใช้ทำ / Uses: ขวดเครื่องดื่ม เส้นใย polyester / beverage bottles, polyester fibres
เชื่อมใบความรู้ 3 / Link to Guided Notes 3: HDPE และ LDPE มาจาก มอนอเมอร์เดียวกันคือ ethene และเป็น addition polymerisation เหมือนกัน แต่รูปร่างสายและระดับการแตกกิ่งต่างกัน จึงจัดเรียงตัวและมีสมบัติต่างกัน
HDPE and LDPE come from the same monomer, ethene, and both are formed by addition polymerisation, but their chain architecture and degree of branching differ, leading to different packing and properties.

PTFE — พอลิเตตระฟลูออโรเอทิลีน Polytetrafluoroethylene

มอนอเมอร์ / Monomer: tetrafluoroethene, CF₂=CF₂
ปฏิกิริยา / Polymerisation: addition
หน่วยซ้ำ / Repeat unit: [–CF₂–CF₂–]ₙ
ใช้ทำ / Uses: สารเคลือบผิวไม่ติด / non-stick coatings

Nylon 6,6 — พอลิเอไมด์ Nylon 6,6 — a polyamide

มอนอเมอร์ 1 / Monomer 1: hexane-1,6-diamine
มอนอเมอร์ 2 / Monomer 2: adipic acid / hexanedioic acid
ปฏิกิริยา + linkage: condensation → amide linkage, –CONH–
ใช้ทำ / Uses: เส้นใย เชือก ผ้า / fibres, rope, fabrics

Melamine–formaldehyde — เมลามีนฟอร์มาลดีไฮด์ Thermosetting network polymer

มอนอเมอร์ / Starting molecules: melamine + formaldehyde
การเกิด / Formation: condensation + network formation
โครงสร้าง / Structure: highly cross-linked network
ใช้ทำ / Uses: จานชามเมลามีน ของใช้ทนรูป / melamine tableware, rigid heat-resistant articles

Natural rubber → Vulcanised rubber ยางธรรมชาติ → ยางวัลคาไนซ์

มอนอเมอร์ของยางธรรมชาติ / Natural-rubber monomer: isoprene
พอลิเมอร์เดิม / Original polymer: polyisoprene
ขั้นปรับสมบัติ / Modification: sulfur cross-linking / vulcanisation
ใช้ทำ / Uses: ยางรถยนต์ ผลิตภัณฑ์ยาง / tyres, durable rubber products

PLA — พอลิแลกติกแอซิด Polylactic acid

มอนอเมอร์ในแบบจำลองระดับหลักสูตร / School-level monomer: lactic acid
ปฏิกิริยาในแบบจำลองนี้ / Reaction in this model: condensation
พันธะสำคัญ / Key linkage: ester linkage, –COO–
ใช้ทำ / Uses: บรรจุภัณฑ์และผลิตภัณฑ์ย่อยสลายได้บางชนิด / some biodegradable packaging and products

มี C=C → addition
diol + diacid → polyester + ester linkage
diamine + diacid → polyamide + amide linkage

Your Turn — For a clear drinking-water bottle and a nylon rope, reason backwards to the polymer name, monomer(s), and polymerisation type.
ขวดน้ำใส / Clear bottle: PET → ethylene glycol + terephthalic acid → condensation polymerisation → ester linkages.
เชือกไนลอน / Nylon rope: Nylon 6,6 → hexane-1,6-diamine + adipic acid → condensation polymerisation → amide linkages.
Common Trap — Vulcanisation ไม่ใช่การนำ sulfur มาเป็น monomer เพื่อสร้างพอลิเมอร์ใหม่Vulcanisation modifies an existing rubber polymer by forming sulfur cross-links; sulfur is not treated as a new monomer in this process.
