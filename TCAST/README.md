# TCAS Learning Plan

ต้นแบบเว็บ **แผนการเรียนของฉัน / My Learning Plan** สำหรับ KRU NIX Learning Space

## ความสามารถของรุ่นทดลอง

- เลือกสาขาที่สนใจได้สูงสุด 4 อันดับ
- ค้นหาสาขาภาษาไทยและอังกฤษ โดยจัดตามกลุ่มสาขา
- แสดงมหาวิทยาลัย วิทยาเขต คณะ และหลักสูตรที่ตรงกัน
- ดูรายละเอียดหลักสูตร ค่าเล่าเรียน และจำนวนรับระดับหลักสูตร
- เก็บสาขาและหลักสูตรเป้าหมายไว้ในอุปกรณ์เดิมด้วย Local Storage
- เปิดข้อมูลรอบรับสมัคร จำนวนรับ เกณฑ์ขั้นต่ำ และสัดส่วนคะแนนด้วย `program_id`
- ทำงานเป็นเว็บไซต์แยก โดยอ่านข้อมูลรอบจาก MyTCAS โดยตรง
- ยังรองรับการเปิดภายใน Apps Script LMS เป็นช่องทางสำรอง

## โครงสร้าง

```text
index.html
styles.css
app.js
data/tcas-programs.json
```

## การเปิดในเครื่อง

เว็บต้องเปิดผ่าน HTTP server เพราะหน้าเว็บโหลดฐานข้อมูล JSON ด้วย `fetch()`

ตัวอย่างการเปิดในเครื่องจากโฟลเดอร์ `TCAST`:

```text
python -m http.server 4173
```

จากนั้นเปิด `http://localhost:4173/` ในเว็บเบราว์เซอร์

## แผนระยะถัดไป

1. เชื่อม User ID ของ LMS ผ่าน parent-window bridge
2. บันทึกแผนใน Google Sheets เพื่อเปิดต่อข้ามอุปกรณ์
3. สร้างเช็กลิสต์วิชาสอบและเกณฑ์จากหลักสูตรเป้าหมาย
4. เพิ่มหน้าครูสำหรับดูแผนของนักเรียน

> ข้อมูลใช้เพื่อวางแผนเบื้องต้น ผู้สมัครต้องตรวจสอบประกาศล่าสุดจากมหาวิทยาลัยและ MyTCAS ก่อนสมัครจริง
