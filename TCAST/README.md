# TCAS Learning Plan

ต้นแบบเว็บ **แผนการเรียนของฉัน / My Learning Plan** สำหรับ KRU NIX Learning Space

## ความสามารถของรุ่นทดลอง

- เลือกสาขาที่สนใจได้สูงสุด 4 อันดับ
- ค้นหาสาขาภาษาไทยและอังกฤษ โดยจัดตามกลุ่มสาขา
- แสดงมหาวิทยาลัย วิทยาเขต คณะ และหลักสูตรที่ตรงกัน
- ดูรายละเอียดหลักสูตร ค่าเล่าเรียน และจำนวนรับระดับหลักสูตร
- เก็บสาขาและหลักสูตรเป้าหมายไว้ในอุปกรณ์เดิมด้วย Local Storage
- เตรียมจุดเชื่อมข้อมูลรอบรับสมัครด้วย `program_id`

## โครงสร้าง

```text
index.html
styles.css
app.js
data/tcas-programs.json
```

## การเปิดในเครื่อง

เว็บต้องเปิดผ่าน HTTP server เพราะหน้าเว็บโหลดฐานข้อมูล JSON ด้วย `fetch()`

## แผนระยะถัดไป

1. เพิ่ม Apps Script proxy สำหรับข้อมูล `rounds/{program_id}.json`
2. เชื่อม User ID ของ LMS ผ่าน parent-window bridge
3. บันทึกแผนใน Google Sheets เพื่อเปิดต่อข้ามอุปกรณ์
4. สร้างเช็กลิสต์วิชาสอบและเกณฑ์จากหลักสูตรเป้าหมาย
5. เพิ่มหน้าครูสำหรับดูแผนของนักเรียน

> ข้อมูลใช้เพื่อวางแผนเบื้องต้น ผู้สมัครต้องตรวจสอบประกาศล่าสุดจากมหาวิทยาลัยและ MyTCAS ก่อนสมัครจริง
