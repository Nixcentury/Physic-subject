Naming the Sides of a Right Triangle
เป้าหมาย: เรียกชื่อ Opposite / Adjacent / Hypotenuse ให้คล่อง
Goal: identify O / A / H from a reference angle
TH: ให้สังเกตมุมฉากก่อนเสมอ ด้านที่อยู่ตรงข้ามมุมฉากคือ Hypotenuse จากนั้นเลือกมุมอ้างอิง แล้วจึงพิจารณาว่าด้านใดเป็น Opposite และ Adjacent.
EN: Always find the right angle first. The side opposite the right angle is the hypotenuse. Then choose the reference angle to determine the opposite and adjacent sides.
Hypotenuse ด้านตรงข้ามมุมฉาก
The side opposite the right angle.
Opposite ด้านตรงข้ามมุมอ้างอิง
The side opposite the reference angle.
Adjacent ด้านประชิดมุมอ้างอิง แต่ไม่ใช่ hypotenuse
The side next to the reference angle, but not the hypotenuse.

1. เสาธง / FlagpoleApplication

TH: ยืนห่างจากเสาธงในแนวราบ 10 m และมุมเงยถึงยอดเท่ากับ 45°. จงหาความสูงของเสาธง (ไม่คิดระดับสายตา).

EN: You stand 10 m horizontally from a flagpole. The angle of elevation to the top is 45°. Find the height (ignore eye height).

\(\tan45^\circ=\frac{h}{10}\Rightarrow h=10\text{ m}\)
2. ต้นไม้ / TreeApplication

TH: จุดสังเกตอยู่ห่างจากโคนต้นไม้ 12 m และมุมเงยถึงยอดเป็น 30°. จงหาความสูง.

\(\tan60^\circ=\frac{h}{8}\Rightarrow h=8\sqrt3\text{ m}\approx13.86\text{ m}\)
4. บันได / LadderApplication

TH: บันไดยาว 10 m พาดกำแพงและทำมุม 30° กับพื้น จงหาความสูงที่ปลายบันไดแตะกำแพง.

Final Example — Height Surveyor
import math


def find_height(distance_x, angle):
    height = distance_x * math.tan(math.radians(angle))
    return height


while True:
    print("\n=== Height Surveyor ===")

    distance_x = float(input("Horizontal distance (m): "))
    angle = float(input("Angle of elevation (degree): "))

    if distance_x <= 0:
        print("Distance must be greater than 0.")

    elif angle <= 0 or angle >= 90:
        print("Angle must be between 0 and 90 degrees.")

    else:
        height = find_height(distance_x, angle)
        print("Estimated height =", round(height, 2), "m")

    again = input("Measure another object? (y/n): ")

    if again == "n":
        break
