🇬🇧 English: Before testing nutrients, we must understand that food and nutrients are not exactly the same thing.

PART 3: Loop คืออะไร? (What Is a Loop?)

🇹🇭 ภาษาไทย: Loop คือคำสั่งที่ทำให้คอมพิวเตอร์ทำงานเดิมซ้ำ ๆ หลายรอบ โดยที่เราไม่ต้องเขียนคำสั่งซ้ำเองทุกบรรทัด
🇬🇧 English: A loop is a command that allows a computer to repeat the same task many times without writing the same instruction again and again.

รูปที่ 2: Loop ช่วยให้คอมพิวเตอร์ทำงานซ้ำ ๆ เช่น ทดสอบตัวอย่างอาหารหลายหลอด (A loop helps a computer repeat tasks such as testing many food samples.)

1. for loop (known number of rounds)
ใช้เมื่อเรารู้จำนวนรอบชัดเจน เช่น ทดสอบ 5 หลอด หรือพิมพ์สูตรคูณ 12 บรรทัด
Use when we know exactly how many times to repeat, such as testing 5 tubes or printing 12 multiplication lines.
2. while loop (repeat until condition changes)
ใช้เมื่อยังไม่รู้จำนวนรอบ แต่รู้เงื่อนไขหยุด เช่น ต้มไปเรื่อย ๆ จนกว่าสีจะเปลี่ยน
Use when we do not know the number of repetitions, but we know the stopping condition, such as heating until the color changes.

PART 4: for loop — สายทำตามสั่งเป๊ะ ๆ (Repeating a Known Number of Times)

🇹🇭 ภาษาไทย: for loop เหมาะกับงานที่รู้จำนวนรอบแน่นอน เช่น มีหลอดทดลอง 5 หลอด ก็วนทำงาน 5 รอบ
🇬🇧 English: A for loop is suitable when the number of repetitions is known. For example, if there are 5 test tubes, repeat the task 5 times.
Python Example: Drop iodine into 5 test tubes 
for i in range(1, 6):
print("หยดสารละลายไอโอดีนลงในหลอดที่", i)
ผลลัพธ์ที่คาดหวัง / Expected output: หยดสารละลายไอโอดีนลงในหลอดที่ 1 หยดสารละลายไอโอดีนลงในหลอดที่ 2 หยดสารละลายไอโอดีนลงในหลอดที่ 3 หยดสารละลายไอโอดีนลงในหลอดที่ 4 หยดสารละลายไอโอดีนลงในหลอดที่ 5
🔬 เชื่อมกับวิทยาศาสตร์: ถ้าเราต้องทดสอบแป้งในตัวอย่างอาหาร 5 หลอด เราสามารถให้หุ่นยนต์หรือโปรแกรมจำลองทำงานซ้ำด้วย for loop ได้
🔬 Science connection: If we need to test starch in 5 food samples, a robot or simulation program can repeat the same task using a for loop.
⚠️ จุดที่ต้องจำ: ใน Python คำสั่ง range(1, 6) จะให้ค่า \(1,2,3,4,5\) แต่จะหยุดก่อนถึง 6
⚠️ Remember: In Python, range(1, 6) gives \(1,2,3,4,5\), but stops before 6.

PART 5: while loop — ทำจนกว่าจะบรรลุเป้า (Repeat Until a Condition Is Met)

🇹🇭 ภาษาไทย: while loop เหมาะกับสถานการณ์ที่เราไม่รู้จำนวนรอบล่วงหน้า แต่รู้ว่าเมื่อใดควรหยุด เช่น ต้มสารละลายเบเนดิกต์จนกว่าจะเห็นตะกอนสีแดงอิฐ
🇬🇧 English: A while loop is useful when we do not know the number of repetitions in advance, but we know when to stop, such as heating Benedict's solution until a brick-red precipitate appears.
Python Example: Heat until brick-red color appears 
color = "สีฟ้า"
 

while color != "แดงอิฐ":
print("กำลังต้มสารละลายเบเนดิกต์ต่อไป...")
color = input("ตอนนี้สีอะไร? : ")

print("พบตะกอนสีแดงอิฐ → มีน้ำตาลรีดิวซ์")
ตัวอย่างการทำงาน / Example run: กำลังต้มสารละลายเบเนดิกต์ต่อไป... ตอนนี้สีอะไร? : สีฟ้า กำลังต้มสารละลายเบเนดิกต์ต่อไป... ตอนนี้สีอะไร? : เขียว กำลังต้มสารละลายเบเนดิกต์ต่อไป... ตอนนี้สีอะไร? : แดงอิฐ พบตะกอนสีแดงอิฐ → มีน้ำตาลรีดิวซ์
⚠️ ระวัง Infinite Loop: ถ้าใน while loop ไม่มีคำสั่งที่ทำให้เงื่อนไขเปลี่ยน โปรแกรมอาจวนซ้ำไม่หยุด ดังนั้นในตัวอย่างนี้จึงต้องมี color = input(...) อยู่ใน loop เพื่อให้ผู้ใช้กรอกสีใหม่
⚠️ Beware of an infinite loop: If nothing inside the while loop changes the condition, the program may run forever. That is why this example includes color = input(...) inside the loop.

PART 6: Mini Project 1 — บอทสูตรคูณสั่งได้ (The Multiplication Master)

🇹🇭 โจทย์: รับค่าแม่สูตรคูณจากผู้ใช้ แล้วให้บอทคำนวณสูตรคูณตั้งแต่ \(1\) ถึง \(12\)
🇬🇧 Task: Get a multiplication table number from the user and print the table from \(1\) to \(12\).
Mini Project 1: Multiplication Master 
# รับค่าแม่สูตรคูณจากผู้ใช้
 

n = int(input("อยากได้สูตรคูณแม่ไหน? : "))

print("--- สูตรคูณแม่", n, "---")

# for loop วนรอบที่ 1 ถึง 12

for i in range(1, 13):
result = n * i
print(n, "x", i, "=", result)
สิ่งที่ได้เรียน / What students learn
  • input() รับข้อมูลจากผู้ใช้ / receives input from the user
  • int() แปลงข้อความเป็นจำนวนเต็ม / converts text into an integer
  • range(1, 13) ทำให้ loop วนตั้งแต่ 1 ถึง 12 / loops from 1 to 12
  • for loop ใช้เมื่อต้องการจำนวนรอบแน่นอน / used for a known number of repetitions

PART 7: Mini Project 2 — ระบบผู้ช่วยแล็บอัจฉริยะ (Smart Lab Assistant)

🇹🇭 โจทย์: ให้โปรแกรมวนทดสอบอาหารหลายชนิด แล้วรับผลที่สังเกตได้ เช่น ม่วงดำ แดงอิฐ ม่วง หรือโปร่งแสง จากนั้นให้โปรแกรมวิเคราะห์ว่าสารอาหารคืออะไร
🇬🇧 Task: Let the program test several food samples. It receives the observed result, such as blue-black, brick-red, purple, or translucent, and then identifies the nutrient.

รูปที่ 3: โครงสร้างตรรกะของระบบผู้ช่วยแล็บอัจฉริยะ (Logic structure of the Smart Lab Assistant.)

Mini Project 2: Smart Lab Assistant 
foods = ["ขนมปัง", "น้ำหวาน", "น้ำมันพืช", "เนื้อไก่"]
 

for food in foods:
print("\n--- ทดสอบสารอาหารใน:", food, "---")
result = input("ใส่ผลที่สังเกตได้ (ม่วงดำ/แดงอิฐ/ม่วง/โปร่งแสง): ")

 
if result == "ม่วงดำ":
    print("ผลวิเคราะห์: มีแป้ง (Starch)")
elif result == "แดงอิฐ":
    print("ผลวิเคราะห์: มีน้ำตาลรีดิวซ์ (Reducing sugar)")

    print("ผลวิเคราะห์: มีโปรตีน (Protein)")
elif result == "โปร่งแสง":
    print("ผลวิเคราะห์: มีไขมัน (Lipid)")
else:
    print("ผลวิเคราะห์: ไม่พบผลทดสอบที่รู้จัก")
 

print("\n--- เสร็จสิ้นการทดสอบทุกรายการ ---")
