How to use / วิธีใช้

หลักการช่วยนักเรียนระหว่างทำกิจกรรม

1 · อย่าเฉลยทันที

ให้เด็กชี้ “วัตถุที่กำลังวิเคราะห์” และ “ทิศบวก” ก่อน ถ้ายังผิดจึงถามเรื่องทิศแรง.

2 · ใบ้จากภาพก่อนสูตร

ถามว่าแรงใดกระทำจริง ทิศใดต้านการเคลื่อนที่ แล้วจึงค่อยพาไปสมการ.

3 · คำนวณทีละชั้น

ใช้ลำดับ N → f → ΣF = ma → a → T โดยเฉพาะ Station 2–4.

ประโยคกลางที่ใช้ได้แทบทุกข้อ: “ตอนนี้เรากำลังวิเคราะห์ก้อนไหน? กำหนดทิศบวกไปทางไหน? แล้วมีแรงจริงอะไรชี้ไปตาม/สวนทิศนั้นบ้าง?”
Predictions ในกิจกรรมมีหน้าที่บันทึกความคิดก่อนทดลอง ไม่ควรตัดสินเด็กจากการทำนายผิด ให้ใช้ช่วง Observation เพื่อให้เด็กแก้แบบจำลองความคิดของตนเอง.

Foundation Check

เฉลยและแนวช่วยตอบพื้นฐาน

1. Newton's First Law

ตอบ: 0 N

ความเร็วคงตัว ⇒ a=0 ⇒ ΣF=0.

ถ้าเด็กตอบ “มีแรงไปข้างหน้าเพราะกำลังเคลื่อนที่” ให้ถาม: “ความเร็วกำลังเปลี่ยนไหม?”

2. Newton's Second Law

ΣF=ma ⇒ a=12/3=4.0 m/s²

ตอบ: 4.0 m/s²

3. Newton's Third Law

ตอบ: แรงสองแรงจากปฏิสัมพันธ์เดียวกัน ขนาดเท่ากัน ทิศตรงข้าม และกระทำต่อวัตถุคนละชิ้น.

ถ้าเด็กเลือก “แรงสองแรงบนวัตถุเดียวกัน” ให้ถามว่า “คู่กฎข้อ 3 อยู่บนวัตถุก้อนเดียวกันได้หรือไม่?”

4. Friction type

กล่องถูกดันแต่ไม่ไถล: static friction

กล่องกำลังไถล: kinetic friction

5. Push the Box

แรงดันแรงเสียดทานผล
5, 10, 15, 20 Nfₛ เท่ากับแรงดัน ณ ขณะนั้นยังไม่ไถล, a=0
25 Nfₖ=15 Na=(25−15)/5=2.0 m/s²
30 Nfₖ=15 Na=(30−15)/5=3.0 m/s²

ข้อสรุป: เมื่อแรงดันเกินแรงเสียดทานสถิตสูงสุด 20 N กล่องเริ่มไถลและใช้แรงเสียดทานจลน์.

จุดที่ต้องจับ: อย่าให้เด็กสรุปว่า f=μN เสมอ เพราะในช่วงยังไม่ไถล fₛ ปรับค่าตามแรงดันจนถึงค่าสูงสุด.
Station 1 · Smooth Connected Masses

มวลต่อเชือกบนพื้นลื่น

ข้อมูล: m₁=2.0 kg, m₂=3.0 kg, F=20 N.

Sceneคำตอบ / สิ่งที่ควรได้แนวช่วยครู
1A Predictคำทำนายที่สอดคล้องกับแบบจำลอง: a₁=a₂. แต่ prediction ไม่ควรให้คะแนนถูกผิด.ถาม “เชือกตึงและไม่ยืด ถ้าก้อนหนึ่งเปลี่ยนระยะเร็วกว่ากัน เชือกจะเป็นอย่างไร?”
1B Observesame acceleration magnitude; เชือกคงความยาวและทั้งสองเริ่มเคลื่อนร่วมกัน.ย้ำว่า same a ไม่ได้แปลว่า same net force เพราะมวลต่างกัน.
1C m₁แรงแนวราบ: F ขวา, T ซ้าย.
F−T=m₁a
อย่าให้เอา N,mg ไปใส่สมการแนวราบ.
1C m₂แรงแนวราบ: T ขวา.
T=m₂a
F ไม่ได้กระทำโดยตรงบน m₂.
1Dบวกสมการ เพื่อให้ −T กับ +T หักล้าง.
F=(m₁+m₂)a
T ไม่ได้เป็นศูนย์ แค่หายทางพีชคณิตเมื่อรวมสมการ.

คำนวณ

20=(2+3)a ⇒ a=4.0 m/s²
T=m₂a=(3)(4)=12 N
คำตอบ: a=4.0 m/s², T=12 N.

Station 1 Conclusion

1) same acceleration magnitude · 2) draw forces for each mass separately · 3) find a first, then return to one block to find T.

Station 2 · Add Friction

เพิ่มแรงเสียดทานบนพื้นราบ

2A Rough surface experiment

Prediction ที่เหมาะสม: ความเร่ง น้อยกว่าพื้นลื่น. เมื่อกล่องไถลขวา แรงเสียดทานจลน์ชี้ ซ้าย.

2B Single block

ข้อมูล: m=5.0 kg, F=40 N, μₖ=0.20, g=10.

N−mg=0 ⇒ N=50 N
fₖ=μₖN=(0.20)(50)=10 N
F−fₖ=ma ⇒ 40−10=5a ⇒ a=6.0 m/s²
ตอบ: N=50 N, fₖ=10 N, a=6.0 m/s².

2C Two connected masses on a rough floor

ข้อมูล: m₁=2.0 kg, m₂=3.0 kg, F=30 N, μₖ=0.20 ทั้งสองก้อน, g=10. ทั้งสองไถลขวา.

ทิศแรงเสียดทาน: f₁ ซ้าย และ f₂ ซ้าย.

N₁=20 N
f₁=.20(20)=4 N
F−T−f₁=m₁a
N₂=30 N
f₂=.20(30)=6 N
T−f₂=m₂a

2D Combine

(F−T−f₁)+(T−f₂)=(m₁+m₂)a
30−4−6=5a ⇒ a=4.0 m/s²

2E Tension

T−6=3(4) ⇒ T=18 N
คำตอบ Station 2 pair: N₁=20 N, f₁=4 N, N₂=30 N, f₂=6 N, a=4.0 m/s², T=18 N.

Conclusion

N → f → ΣF=ma · friction direction from relative sliding/tendency · connected masses still share |a|, combine for a then return for T.

Station 3 · Inclined Plane

พื้นเอียงก้อนเดียว

3A Real forces

เลือก mg, N, fₖ เท่านั้น. ไม่เลือก mg sinθ, mg cosθ หรือ ma เป็น “แรงใหม่”.

ถ้าเด็กเลือก mg sinθ + mg cosθ พร้อม mg ให้ถาม: “สองตัวนี้เกิดจาก interaction ใหม่ หรือเป็นเพียงการแตกเวกเตอร์ mg?”

3B Axes and components

แกนที่เหมาะ: x ตามพื้นเอียง, y ตั้งฉากพื้นเอียง.

mg=30 N
mg sin30°=15.0 N
mg cos30°≈25.98≈26.0 N

3C Slide experiment

บล็อกไถลลง ⇒ fₖ ชี้ขึ้นพื้นเอียง. จาก s=2.0 m, u=0, t=1.5 s:

2.0=½a(1.5)² ⇒ a=4/2.25≈1.78≈1.8 m/s²

3D Force balance

ตั้งฉากพื้น
N−mg cosθ=0
N≈26.0 N
ตามพื้นเอียง, ลงเป็นบวก
mg sinθ−fₖ=ma
15−fₖ=3(1.78)
fₖ≈9.67≈9.7 N

3E Coefficient

μₖ=fₖ/N≈9.7/26.0≈0.37
ตอบ: mg sin30=15 N, mg cos30≈26 N, a≈1.8 m/s², N≈26 N, fₖ≈9.7 N, μₖ≈0.37.

Conclusion

N=mg cosθ เมื่อไม่มีแรงตั้งฉากอื่น · sin/cos เป็น components · วัตถุไถลลงแล้ว friction ชี้ขึ้นทางลาด.

Station 4 · Double Incline

สองมวลบนพื้นเอียงสองฝั่ง

ข้อมูล: m₁=2 kg, θ₁=37°, m₂=5 kg, θ₂=53°, g=10; sin37=.60, cos37=.80, sin53=.80, cos53=.60.

4A Smooth slopes

m₁g sin37°=2(10)(.60)=12 N
m₂g sin53°=5(10)(.80)=40 N

ดังนั้น m₂ ลงทางลาด 53° และ m₁ ขึ้นทางลาด 37°.

อย่าให้เด็กใช้ “m₂ หนักกว่าเลยลง” เป็นเหตุผลสุดท้าย ต้องเปรียบเทียบองค์ประกอบตามพื้นเอียง.

4B Add friction

ระบบกำลังไถล: m₁ ขึ้น ⇒ f₁ ลงทางลาด; m₂ ลง ⇒ f₂ ขึ้นทางลาด.

N₁=2(10)(.80)=16 N
f₁=.25(16)=4 N
N₂=5(10)(.60)=30 N
f₂=.10(30)=3 N

4C One equation per mass

m₁ (+ ขึ้นทางลาด): T−m₁g sin37°−f₁=m₁a
m₂ (+ ลงทางลาด): m₂g sin53°−T−f₂=m₂a
T−12−4=2a
40−T−3=5a

4D Combine

40−3−12−4=(2+5)a ⇒ 21=7a ⇒ a=3.0 m/s²
T−12−4=2(3) ⇒ T=22 N
ตอบ: N₁=16 N, f₁=4 N, N₂=30 N, f₂=3 N, a=3.0 m/s², T=22 N.

Conclusion

same |a| from taut rope · friction opposes sliding · after finding a, return to either one-mass equation for T.

Final Challenge · Teacher Solution

เฉลยละเอียดโจทย์ท้ายกิจกรรม

ข้อมูล: m₁=3.0 kg, 37°, μ₁=0.125; m₂=5.0 kg, 53°, μ₂=0.10; g=10. ให้ถือว่ากำลังไถล.

A. Direction

m₁g sin37=3(10)(.60)=18 N
N₁=3(10)(.80)=24 N
f₁=.125(24)=3 N
m₂g sin53=5(10)(.80)=40 N
N₂=5(10)(.60)=30 N
f₂=.10(30)=3 N

ถ้าสมมติ m₂ ลง: ฝั่ง m₂ มีแรงขับสุทธิ 40−3=37 N; ฝั่ง m₁ ต่อต้าน 18+3=21 N. จึงสอดคล้องกับ m₂ ลง, m₁ ขึ้น.

B. N and f

N₁=24 N, f₁=3 N, N₂=30 N, f₂=3 N.

C. Equations, a and T

m₁ (+ ขึ้น): T−18−3=3a
m₂ (+ ลง): 40−T−3=5a
บวกสมการ: 40−3−18−3=8a ⇒ 16=8a ⇒ a=2.0 m/s²
T−21=3(2) ⇒ T=27 N
Final answers: direction m₂ down / m₁ up; N₁=24 N; f₁=3 N; N₂=30 N; f₂=3 N; a=2.0 m/s²; T=27 N.

D. Reasoning

1) ขนาดความเร่งเท่ากันเพราะเชื่อมด้วยเชือกเส้นเดียวที่ตึงและไม่ยืด.

2) T ไม่เป็นศูนย์ เพราะ +T และ −T หักล้างกันทางพีชคณิตเมื่อบวกสมการสองก้อนเท่านั้น.
