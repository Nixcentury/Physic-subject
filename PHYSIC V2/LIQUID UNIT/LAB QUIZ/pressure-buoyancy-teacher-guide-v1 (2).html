Station 1C · Build the pressure equation

CheckpointExpected answerเหตุผล
Force from liquid columnF = mgแรงกดลงมาจากน้ำหนักของคอลัมน์ของเหลว
Mass–density–volumem = ρVจาก ρ = m/V
Column volumeV = Ahปริมาตร = พื้นที่ฐาน × ความสูง

Derivation ที่ควรได้

P = F/A
P = mg/A
P = ρVg/A
P = ρ(Ah)g/A
P = ρgh
แนวอธิบายที่ยอมรับ: สำหรับของเหลวชนิดเดียวและ g เดิม ความดันเนื่องจากของเหลวเพิ่มตามความลึก h; ρ มากขึ้นก็ทำให้ P มากขึ้นตามสมการ

Station 1D · Use the equation

ให้ ρ = 1000 kg/m³, g = 10 N/kg, h = 2.5 m

P = ρgh = (1000)(10)(2.5) = 25,000 Pa

✓ คำตอบ: 25,000 Pa = 25 kPa

Common response issues / จุดที่เด็กมักสับสน

  • ใช้ h เป็น cm โดยไม่แปลงเป็น m
  • เขียน V = A/h แทน Ah
  • สับสน ρ = mV; ให้ย้อนนิยาม ρ = m/V
  • เติม atmospheric pressure ทั้งที่โจทย์ถาม pressure due to water เท่านั้น

Station 2A · U-tube Manometer

Prediction: ถ้า Pgas > Patm ระดับของเหลวฝั่งแก๊ส ต่ำลง / fall และฝั่งเปิดสู่บรรยากาศสูงขึ้น

Observed: Δh = 0.12 m

ΔP = ρgΔh = (1000)(10)(0.12) = 1200 Pa
แนวอธิบาย: เพราะแขนขวาเปิดสู่บรรยากาศ ค่า ΔP นี้คือความดันแก๊สที่มากกว่าบรรยากาศ หรือ gas gauge pressure

Station 2B · Hydraulic Press

Prediction: F₂ greater / มากกว่า 50 N

F₁ = 50 N, A₁ = 5 cm², A₂ = 200 cm²

F₁/A₁ = F₂/A₂
F₂ = 50(200/5) = 2000 N

Explanation: ความดันที่ถ่ายทอดเท่ากันกระทำบนพื้นที่ของลูกสูบใหญ่ที่มากกว่า จึงให้แรงมากกว่า

ยอมรับถ้อยคำ: “same pressure, larger area → larger force”, “P₁ = P₂ และ F = PA”, หรือการอธิบายเทียบเท่า

ในข้อนี้ใช้ area ratio ได้โดยตรง เพราะ A₁ และ A₂ อยู่ในหน่วย cm² เหมือนกัน หากเด็กคำนวณ pressure เป็น Pa ก่อน ต้องแปลง cm² → m² ให้ถูก

ไม่ยอมรับเป็นเหตุผลหลัก

  • “ความดันที่ลูกสูบใหญ่สูงกว่าเอง”
  • “ของเหลวเพิ่มมวลให้ load”

Station 3B · Top and bottom pressure

h₁ = 0.30 m, h₂ = 0.50 m, A = 1.0 × 10−3 m², ρ = 1000 kg/m³, g = 10 N/kg

Ptop = 1000(10)(0.30) = 3000 Pa
Ftop = PA = 3000(1×10−3) = 3.0 N downward
Pbottom = 1000(10)(0.50) = 5000 Pa
Fbottom = 5000(1×10−3) = 5.0 N upward
Net upward = 5.0 − 3.0 = 2.0 N

Compare with 3A: ตรงกันพอดีกับผลต่างจากเครื่องชั่ง 2.0 N

Side forces: แรงด้านข้างหักล้างกันเป็นคู่ในโมเดลวัตถุทรงสี่เหลี่ยมนี้

Station 3C · Derive Archimedes' result

Checkpoint A: Fbottom − Ftop

Checkpoint B: A(h₂ − h₁) = Vdisplaced

FB = Fbottom − Ftop
= PbottomA − PtopA
= ρgh₂A − ρgh₁A
= ρgA(h₂ − h₁)
= ρgVdisplaced
Archimedes' principle: แรงลอยตัวเท่ากับน้ำหนักของของเหลวที่ถูกแทนที่ เพราะ ρVdisplacedg คือน้ำหนักของของเหลวนั้น

Station 4D · Fraction submerged

ρobject = 600 kg/m³, ρfluid = 1000 kg/m³

Prediction: แนวทำนายทางฟิสิกส์ = 60% แต่ prediction อื่นก่อนทดลองไม่ต้องหัก

Observed: 60% submerged

At floating equilibrium: FB = W
ρfluidgVsub = ρobjectgVtotal
Vsub/Vtotal = ρobject/ρfluid = 600/1000 = 0.60
Percent submerged = 60%

Why does it stop moving? FB = W จึงมีแรงลัพธ์เป็นศูนย์

FB = ρfluidgVdisplaced
