1. แม่เหล็กคืออะไร (What is a Magnet?)

แม่เหล็ก คือ วัตถุหรือสารที่สามารถสร้างสนามแม่เหล็กรอบตัว และสามารถดูดหรือผลักกับแม่เหล็กอื่น รวมถึงสามารถดูดสารแม่เหล็กบางชนิดได้
A magnet is an object that produces a magnetic field. It can attract or repel other magnets and attract some magnetic materials.
Key idea / แนวคิดสำคัญ
  • แม่เหล็กออกแรงได้โดยไม่ต้องสัมผัส / Magnetic force can act at a distance.
  • บริเวณรอบแม่เหล็กมีสนามแม่เหล็ก / A magnet has a magnetic field around it.
  • สนามแม่เหล็กใช้เข็มทิศทดสอบทิศทางได้ / A compass can show field direction.

2. ชนิดของแม่เหล็กและสารแม่เหล็ก (Types of Magnets and Magnetic Materials)

แม่เหล็กธรรมชาติ / Natural magnet

เกิดเองตามธรรมชาติ เช่น แร่แมกนีไทต์ \(Fe_3O_4\)

A naturally occurring magnetic mineral, such as magnetite \(Fe_3O_4\).

แม่เหล็กที่มนุษย์สร้าง / Artificial magnet

สร้างขึ้นด้วยวิธีทางวิทยาศาสตร์ เช่น แม่เหล็กถาวรและแม่เหล็กชั่วคราว

A magnet made by humans, such as a permanent magnet or a temporary magnet.

ชนิดของสาร / Material type พฤติกรรมต่อแม่เหล็ก / Behaviour ตัวอย่าง / Examples
Ferromagnetic
สารเฟอโรแมกเนติก		 ถูกแม่เหล็กดูดแรงมาก / Strongly attracted เหล็ก, โคบอลต์, นิกเกิล / Iron, cobalt, nickel
Paramagnetic
สารพาราแมกเนติก		 ถูกแม่เหล็กดูดเล็กน้อย / Weakly attracted อะลูมิเนียม, โครเมียม, แมงกานีส / Aluminium, chromium, manganese
Diamagnetic
สารไดอะแมกเนติก		 ถูกแม่เหล็กผลักเล็กน้อย / Weakly repelled ทอง, ทองแดง, เงิน, สังกะสี / Gold, copper, silver, zinc

3. ขั้วแม่เหล็ก (Magnetic Poles)

ขั้วแม่เหล็กเป็นบริเวณที่อำนาจแม่เหล็กเข้มที่สุด / Magnetic poles are the strongest regions of a magnet.

ขั้วเหมือนกัน / Like poles

N กับ N หรือ S กับ S → ผลักกัน / repel

ขั้วต่างกัน / Unlike poles

N กับ S → ดูดกัน / attract

ขั้วเหมือนกันหันเข้าหากัน → ผลักกัน / Like poles facing each other → repulsion
Source image: Wikimedia Commons — Magnetic_field_of_bar_magnets_repelling.png
ขั้วต่างกันหันเข้าหากัน → ดูดกัน / Unlike poles facing each other → attraction
Source image: Wikimedia Commons — VFPt_cylindrical_magnets_attracting.svg
ข้อควรรู้ / Important: ถ้าหักแท่งแม่เหล็กออกเป็นหลายท่อน จะเกิดขั้วเหนือและขั้วใต้ขึ้นใหม่ทุกท่อนเสมอ จึงไม่สามารถแยกขั้ว N เดี่ยวหรือ S เดี่ยวออกมาได้ง่าย ๆ
If a bar magnet is broken into pieces, each piece becomes a smaller magnet with both N and S poles.

4. สนามแม่เหล็กและเส้นสนามแม่เหล็ก (Magnetic Field and Field Lines)

สนามแม่เหล็ก คือ บริเวณที่มีอำนาจแม่เหล็ก ถ้านำสารแม่เหล็กหรือเข็มทิศมาวางในบริเวณนี้ จะเกิดแรงหรือเกิดการเบี่ยงเบน
A magnetic field is a region where magnetic effects can be detected. A compass placed in this region will align with the field direction.

ทิศของสนามแม่เหล็ก / Direction of \(B\)

กำหนดโดยทิศที่เข็มทิศชี้ ณ ตำแหน่งนั้น

The direction of the magnetic field is the direction in which a compass needle points.

ผงตะไบเหล็กแสดงรูปแบบสนาม / Iron filings show the field pattern

สมบัติของเส้นสนามแม่เหล็ก / Properties of Magnetic Field Lines

  • เส้นสนามแสดงทิศทางของสนามแม่เหล็ก ณ ตำแหน่งนั้น / Field lines show field direction.
  • ภายนอกแท่งแม่เหล็ก เส้นสนามมีทิศจาก N ไป S / Outside a magnet, field lines go from N to S.
  • เส้นสนามไม่ตัดกัน / Field lines never cross.
  • เส้นสนามถี่ → สนามแรง, เส้นสนามห่าง → สนามอ่อน / Closely spaced lines mean a stronger field.
  • ผงตะไบเหล็กใช้ดูรูปแบบการเรียงตัวได้ แต่ถ้าต้องการทิศทางให้ใช้เข็มทิศ / Iron filings show the pattern, but a compass shows direction.

5. สนามแม่เหล็กโลก (Earth’s Magnetic Field)

โลกมีสนามแม่เหล็กคล้ายแท่งแม่เหล็กขนาดใหญ่ เข็มทิศจึงวางตัวในแนวเหนือ–ใต้ และใช้บอกทิศทางได้
Earth has a magnetic field similar to a giant bar magnet, so a compass aligns roughly north–south.
ผลสำคัญ / Important effect

สนามแม่เหล็กโลกช่วยเบี่ยงเบนอนุภาคมีประจุจากลมสุริยะ และเกี่ยวข้องกับแสงเหนือ–แสงใต้

Earth’s magnetic field deflects charged particles from the solar wind and is related to auroras.

6. จุดสะเทิน (Neutral Point)

จุดสะเทิน คือ จุดที่อยู่ในบริเวณที่มีสนามแม่เหล็กหลายแหล่ง แต่สนามแม่เหล็กที่ตำแหน่งนั้นหักล้างกันจนได้สนามลัพธ์เป็นศูนย์
A neutral point is a point where magnetic fields from different sources cancel each other, so the resultant magnetic field is zero.
จุดสะเทินคือจุดที่สนามแม่เหล็กสองแหล่งมีขนาดเท่ากันแต่ทิศตรงข้าม จึงหักล้างกัน / Neutral points occur where equal and opposite magnetic fields cancel.
สังเกตด้วยเข็มทิศ / Compass observation

ถ้าวางเข็มทิศเล็ก ๆ ที่จุดสะเทิน เข็มทิศจะไม่มีทิศบังคับชัดเจน เพราะสนามลัพธ์เป็นศูนย์

สังเกตด้วยผงตะไบเหล็ก / Iron filings observation

บริเวณจุดสะเทิน ผงตะไบเหล็กจะไม่เรียงตัวเป็นแนวชัด เพราะไม่มีสนามลัพธ์กำหนดทิศ

7. ฟลักซ์แม่เหล็กและความเข้มสนามแม่เหล็ก (Magnetic Flux and Magnetic Flux Density)

ฟลักซ์แม่เหล็ก \(\Phi\)

คือ ปริมาณสนามแม่เหล็กที่พุ่งผ่านพื้นที่หนึ่ง

Magnetic flux is the amount of magnetic field passing through a surface.

ความเข้มสนามแม่เหล็ก \(B\)

คือ จำนวนฟลักซ์แม่เหล็กต่อพื้นที่ตั้งฉากหนึ่งหน่วย

Magnetic flux density is magnetic flux per unit perpendicular area.

$$\Phi = BA\cos\theta$$
ข้อควรระวังเรื่องมุม / Angle warning: ในสูตร \(\Phi = BA\cos\theta\), \(\theta\) คือมุมระหว่างสนามแม่เหล็ก \(B\) กับเส้นตั้งฉากต่อพื้นที่ หรือ normal line ไม่ใช่มุมกับระนาบโดยตรง
ฟลักซ์แม่เหล็กผ่านพื้นที่ / Magnetic flux through an area
Source image: Wikimedia Commons — Magnetic_flux_diagram.svg
มุมระหว่างสนามกับเส้น normal / Angle between field and normal
Source image: Wikimedia Commons — General_flux_diagram.svg
ถ้า \(B\) ตั้งฉากกับพื้นที่ ฟลักซ์มากสุด; ถ้า \(B\) ขนานกับพื้นที่ ฟลักซ์เป็นศูนย์ / Flux is maximum when \(B\) is perpendicular to the surface, and zero when \(B\) is parallel to the surface.
กรณี / Case มุมกับ normal / Angle with normal ฟลักซ์ / Flux
\(B\) ตั้งฉากกับพื้นที่ / \(B\) perpendicular to area \(\theta = 0^\circ\) \(\Phi = BA\) มากสุด / maximum
\(B\) ทำมุมกับพื้นที่ / \(B\) at an angle \(0^\circ < \theta < 90^\circ\) \(\Phi = BA\cos\theta\)
\(B\) ขนานกับพื้นที่ / \(B\) parallel to area \(\theta = 90^\circ\) \(\Phi = 0\)
