=================================

Repository: https://github.com/Nixcentury/learning-hub

เพิ่มบท เรื่องย่อย หรือ Quiz ของ Hub ที่โครงการใหม่เท่านั้น
LEARNING HUB ใน repo นี้เป็นต้นฉบับก่อนย้าย เก็บไว้ย้อนกลับ ไม่เผยแพร่เป็น Hub อีก
งาน HTML อื่นยังเก็บและเผยแพร่จาก Physic-subject ตามเดิม
ลิงก์เครื่องมือ/เนื้อหา Hub เก่ายังมีสำเนาฉบับก่อนย้ายรองรับ ไม่ใช่แหล่งแก้ไขใหม่
สำเนารองรับอยู่ใน .github/hub-compat/ (ไม่ต้องแก้ไขสำหรับการเพิ่มบทใหม่)

workflow ของ Physic-subject ไม่ติดตั้งแพ็กเกจหรือ Build Learning Hub แล้ว
แก้ไขเนื้อหา Hub ใน repo เก่าอย่างเดียวจะไม่เปลี่ยนเว็บ Hub ใหม่
ตรวจการอัปเดตแต่ละเว็บจาก Actions ของ repo นั้น และ deployment.json บนเว็บ

ไม่ได้ลบเนื้อหาเดิมหรือเปลี่ยน Firebase/AI Worker ในการย้ายครั้งนี้
