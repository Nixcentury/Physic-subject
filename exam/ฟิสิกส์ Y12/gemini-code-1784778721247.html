ตอนที่ 1 / Part 1: คาบ ความถี่ และอัตราเร็วเชิงมุม / Period, Frequency, and Angular Speed

5 คะแนน
ข้อ 1. ล้อทดลองหมุนครบ $15$ รอบ ในเวลา $5.0\text{ s}$ โดยหมุนด้วยอัตราคงที่ (5 คะแนน) A laboratory wheel completes $15$ revolutions in $5.0\text{ s}$. Assume the wheel rotates at a constant rate.
Given Data / ข้อมูลกำหนด
Number of revolutions / จำนวนรอบ $N$$15\text{ รอบ (rev)}$
Total time / เวลารวม $t$$5.0\text{ s}$
Use / ค่าคงที่$\pi \approx 3.14$
Motion / การเคลื่อนที่constant rate / อัตราคงที่
  1. หาคาบ $T$ ของล้อ Find the period $T$ of the wheel. (1 คะแนน)
  2. หาความถี่ $f$ Find the frequency $f$. (1 คะแนน)
  3. หาอัตราเร็วเชิงมุม $\omega$ Find the angular speed $\omega$. (2 คะแนน)
  4. ในเวลา $4.0\text{ s}$ ล้อหมุนไปได้กี่รอบ In $4.0\text{ s}$, how many revolutions does the wheel complete? (1 คะแนน)
เฉลยอย่างละเอียด / Detailed Solution:
1. หาคาบ ($T$): เวลาในการหมุน $1$ รอบ
$$T = \frac{t}{N} = \frac{5.0\text{ s}}{15\text{ รอบ}} = \frac{1}{3}\text{ s} \approx 0.333\text{ s}$$
2. หาความถี่ ($f$): จำนวนรอบใน $1$ วินาที
$$f = \frac{N}{t} = \frac{15}{5.0} = 3.0\text{ Hz}$$
3. หาอัตราเร็วเชิงมุม ($\omega$):
$$\omega = 2\pi f = 2 \times 3.14 \times 3.0 = 18.84\text{ rad/s}$$
4. หาจำนวนรอบในเวลา $4.0\text{ s}$:
$$N = f \times t = 3.0\text{ รอบ/s} \times 4.0\text{ s} = 12\text{ รอบ}$$

ตอนที่ 1 / Part 1: คาบ ความถี่ และอัตราเร็วเชิงมุม (ต่อ)

ข้อ 2. วัตถุหนึ่งเคลื่อนที่เป็นวงกลมรัศมี $0.40\text{ m}$ ด้วยความถี่ $1.2\text{ Hz}$ ที่ตำแหน่งขวาสุด วัตถุเคลื่อนที่ทวนเข็มนาฬิกา (5 คะแนน) An object moves in a circle of radius $0.40\text{ m}$ with frequency $1.2\text{ Hz}$. At the rightmost point, it moves counterclockwise.
Given Data / ข้อมูลกำหนด
Radius / รัศมี $r$$0.40\text{ m}$
Frequency / ความถี่ $f$$1.2\text{ Hz}$
Position / ตำแหน่งrightmost point / ขวาสุด
Direction / ทิศทางcounterclockwise (CCW) / ทวนเข็มนาฬิกา
  1. หาคาบ $T$ Find the period $T$. (1 คะแนน)
  2. หาอัตราเร็วเชิงมุม $\omega$ Find the angular speed $\omega$. (1 คะแนน)
  3. หาอัตราเร็วเชิงเส้น $v$ Find the linear speed $v$. (2 คะแนน)
  4. ระบุทิศของความเร็วเชิงเส้นที่ตำแหน่งขวาสุด State the direction of linear velocity at the rightmost point. (1 คะแนน)
เฉลยอย่างละเอียด / Detailed Solution:
1. หาคาบ ($T$):
$$T = \frac{1}{f} = \frac{1}{1.2} = 0.833\text{ s}$$
2. หาอัตราเร็วเชิงมุม ($\omega$):
$$\omega = 2\pi f = 2 \times 3.14 \times 1.2 = 7.536\text{ rad/s}$$
3. หาอัตราเร็วเชิงเส้น ($v$):
$$v = \omega r = 7.536 \times 0.40 = 3.014\text{ m/s}$$
4. ทิศทางความเร็วเชิงเส้นที่ตำแหน่งขวาสุด: มีทิศชี้ขึ้นในแนวดิ่ง (ทิศเหนือ) สัมผัสกับส่วนโค้งตามทิศทวนเข็มนาฬิกา

ตอนที่ 2 / Part 2: จลนศาสตร์การหมุน / Rotational Kinematics

5 คะแนน
ข้อ 1. ล้อรัศมี $0.50\text{ m}$ เริ่มหมุนจากหยุดนิ่งด้วยความเร่งเชิงมุมคงที่ $3.0\text{ rad/s}^2$ เป็นเวลา $3.0\text{ s}$ (5 คะแนน) A wheel of radius $0.50\text{ m}$ starts from rest with constant angular acceleration $3.0\text{ rad/s}^2$ for $3.0\text{ s}$.
Given Data / ข้อมูลกำหนด
Radius / รัศมี $R$$0.50\text{ m}$
Initial angular speed / ความเร็วเชิงมุมเริ่มต้น $\omega_0$$0\text{ rad/s}$
Angular acceleration / ความเร่งเชิงมุม $\alpha$$3.0\text{ rad/s}^2$
Time / เวลา $t$$3.0\text{ s}$
  1. หาความเร็วเชิงมุมสุดท้าย $\omega$ Find the final angular speed $\omega$. (1 คะแนน)
  2. หาระยะเชิงมุม $\theta$ Find the angular displacement $\theta$. (1 คะแนน)
  3. ล้อหมุนไปกี่รอบโดยประมาณ Approximately how many revolutions does the wheel complete? (2 คะแนน)
  4. หาอัตราเร็วเชิงเส้นที่ขอบล้อ ณ $t = 3.0\text{ s}$ Find the linear speed at the rim at $t = 3.0\text{ s}$. (1 คะแนน)
เฉลยอย่างละเอียด / Detailed Solution:
1. ความเร็วเชิงมุมสุดท้าย ($\omega$):
$$\omega = \omega_0 + \alpha t = 0 + (3.0 \times 3.0) = 9.0\text{ rad/s}$$
2. ระยะเชิงมุม ($\theta$):
$$\theta = \omega_0 t + \frac{1}{2}\alpha t^2 = 0 + \frac{1}{2}(3.0)(3.0)^2 = 13.5\text{ rad}$$
3. จำนวนรอบ ($N$):
$$N = \frac{\theta}{2\pi} = \frac{13.5}{2 \times 3.14} = \frac{13.5}{6.28} \approx 2.15\text{ รอบ}$$
4. อัตราเร็วเชิงเส้นที่ขอบล้อ ($v$):
$$v = \omega R = 9.0 \times 0.50 = 4.5\text{ m/s}$$

ตอนที่ 2 / Part 2: จลนศาสตร์การหมุน (ต่อ)

5 คะแนน
ข้อ 2. พัดลมมีความเร็วเชิงมุมเริ่มต้น $24\text{ rad/s}$ แล้วถูกเบรกด้วยความเร่งเชิงมุมคงที่ $-6.0\text{ rad/s}^2$ รัศมีใบพัด $0.25\text{ m}$ (5 คะแนน) A fan has initial angular speed $24\text{ rad/s}$ and is braked with constant angular acceleration $-6.0\text{ rad/s}^2$. The blade radius is $0.25\text{ m}$.
Given Data / ข้อมูลกำหนด
Initial angular speed / ความเร็วเชิงมุมเริ่มต้น $\omega_0$$24\text{ rad/s}$
Angular acceleration / ความเร่งเชิงมุม $\alpha$$-6.0\text{ rad/s}^2$
Final angular speed / ความเร็วเชิงมุมสุดท้าย $\omega$$0\text{ rad/s}$ (หยุดหมุน)
Blade radius / รัศมีใบพัด $R$$0.25\text{ m}$
  1. หาเวลาที่พัดลมหยุดหมุน Find the stopping time of the fan. (1 คะแนน)
  2. หาระยะเชิงมุม $\theta$ ระหว่างการชะลอ Find the angular displacement $\theta$ during braking. (1 คะแนน)
  3. คิดเป็นจำนวนรอบประมาณเท่าใด Approximately how many revolutions is this? (2 คะแนน)
  4. หาขนาดความเร่งสัมผัสที่ปลายใบพัด Find the magnitude of tangential acceleration at the blade tip. (1 คะแนน)
เฉลยอย่างละเอียด / Detailed Solution:
1. หาเวลาหยุดหมุน ($t$): จาก $\omega = \omega_0 + \alpha t$
$$0 = 24 + (-6.0)t \implies 6.0t = 24 \implies t = 4.0\text{ s}$$
2. หาระยะเชิงมุม ($\theta$):
$$\theta = \left(\frac{\omega_0 + \omega}{2}\right)t = \left(\frac{24 + 0}{2}\right)(4.0) = 48\text{ rad}$$
3. คิดเป็นจำนวนรอบ ($N$):
$$N = \frac{\theta}{2\pi} = \frac{48}{2 \times 3.14} = \frac{48}{6.28} \approx 7.64\text{ รอบ}$$
4. หาขนาดความเร่งสัมผัส ($a_t$):
$$|a_t| = |\alpha| R = 6.0 \times 0.25 = 1.5\text{ m/s}^2$$

ตอนที่ 3 / Part 3: ทอร์กและสมดุลการหมุน / Torque and Rotational Equilibrium

5 คะแนน
ข้อ 1. ประแจขันน็อต จุดหมุนอยู่ที่ศูนย์กลางน็อต พิจารณา 3 กรณีต่อไปนี้ (5 คะแนน) A mechanic uses a wrench to rotate a bolt. The pivot is at the center of the bolt. Consider the following three cases.
Given Data / ข้อมูลกำหนด
Case A / กรณี A$r=0.40\text{ m}$, $F=50\text{ N}$, ตั้งฉาก / perpendicular
Case B / กรณี B$r=0.25\text{ m}$, $F=60\text{ N}$, ตั้งฉาก / perpendicular
Case C / กรณี C$r=0.60\text{ m}$, $F=30\text{ N}$, ทำมุม $\theta=30^\circ$ กับประแจ
  1. หาทอร์กในกรณี A พร้อมทิศการหมุน Find torque in Case A with direction. (1 คะแนน)
  2. หาทอร์กในกรณี B พร้อมทิศการหมุน Find torque in Case B with direction. (1 คะแนน)
  3. หาทอร์กในกรณี C พร้อมทิศการหมุน Find torque in Case C with direction. (2 คะแนน)
  4. กรณีใดให้ทอร์กมากที่สุด Which case gives the greatest torque? (1 คะแนน)
เฉลยอย่างละเอียด / Detailed Solution:
1. กรณี A: $\tau_A = rF = 0.40 \times 50 = 20\text{ N}\cdot\text{m}$ (ทิศทวนเข็มนาฬิกา)
2. กรณี B: $\tau_B = rF = 0.25 \times 60 = 15\text{ N}\cdot\text{m}$ (ทิศทวนเข็มนาฬิกา)
3. กรณี C: $\tau_C = rF\sin 30^\circ = 0.60 \times 30 \times 0.5 = 9.0\text{ N}\cdot\text{m}$ (ทิศทวนเข็มนาฬิกา)
4. สรุป: กรณีที่ให้ทอร์กมากที่สุดคือ กรณี A ($20\text{ N}\cdot\text{m}$)

ตอนที่ 3 / Part 3: ทอร์กและสมดุลการหมุน (ต่อ)

5 คะแนน
ข้อ 2. ไม้กระดกมีเด็กน้ำหนัก $300\text{ N}$ นั่งทางซ้ายห่างจุดหมุน $1.50\text{ m}$ และผู้ใหญ่น้ำหนัก $450\text{ N}$ นั่งทางขวา (5 คะแนน) A seesaw has a child of weight $300\text{ N}$ sitting $1.50\text{ m}$ to the left of the pivot and an adult of weight $450\text{ N}$ sitting to the right.
Given Data / ข้อมูลกำหนด
Child / เด็ก$W_1 = 300\text{ N}$, ระยะซ้าย $r_1 = 1.50\text{ m}$
Adult / ผู้ใหญ่$W_2 = 450\text{ N}$, ระยะขวา $= x$
Board / ไม้กระดกละเลยน้ำหนักของไม้ / neglect weight
  1. หาโมเมนต์ของแรงจากน้ำหนักเด็กเทียบกับจุดหมุน พร้อมระบุทิศการหมุน Find the torque from the child's weight about the pivot. (1 คะแนน)
  2. ถ้าไม้กระดกสมดุล จงหาระยะ $x$ ของผู้ใหญ่ If the seesaw is balanced, find $x$. (2 คะแนน)
  3. ถ้าผู้ใหญ่นั่งห่างจุดหมุนเพียง $0.80\text{ m}$ จงหาโมเมนต์ลัพธ์รอบจุดหมุน If the adult sits at $0.80\text{ m}$, find the net torque. (1 คะแนน)
  4. สรุปว่าไม้กระดกจะเอียงไปด้านใด State which side moves downward. (1 คะแนน)
เฉลยอย่างละเอียด / Detailed Solution:
1. โมเมนต์จากเด็ก: $\tau_{\text{เด็ก}} = W_1 \times r_1 = 300 \times 1.50 = 450\text{ N}\cdot\text{m}$ (ทิศทวนเข็มนาฬิกา)
2. หา $x$ เมื่อสมดุล ($\sum \tau = 0$):
$$\tau_{\text{ทวน}} = \tau_{\text{ตาม}} \implies 450 = 450 \cdot x \implies x = 1.0\text{ m}$$
3. ถ้าผู้ใหญ่นั่งที่ระยะ $0.80\text{ m}$:
$$\tau_{\text{ผู้ใหญ่}} = 450 \times 0.80 = 360\text{ N}\cdot\text{m}\text{ (ตามเข็ม)}$$ $$\tau_{\text{ลัพธ์}} = 450 - 360 = 90\text{ N}\cdot\text{m}\text{ (ทวนเข็ม)}$$
4. สรุป: ไม้กระดกจะเอียงไปทางด้านซ้าย (ฝั่งเด็กเอียงลง)

ตอนที่ 4 / Part 4: ตรีโกณมิติและ SHM / Trigonometry and SHM

5 คะแนน
ข้อ 1. จงลดมุมให้อยู่ในหนึ่งรอบมาตรฐาน แล้วใช้มุมที่ได้เพื่อหาค่าตรีโกณมิติ (5 คะแนน) Reduce each angle to one standard turn, then use the reduced angle to find the trigonometric value.
Given Data / ข้อมูลกำหนด
Angle / มุมFind / จงหาค่า
$405^\circ$$\sin 405^\circ$
$-240^\circ$$\cos(-240^\circ)$
$\frac{11\pi}{4}$$\tan\frac{11\pi}{4}$
$-\frac{7\pi}{6}$$\sin(-\frac{7\pi}{6})$
  1. ลด $405^\circ$ และ $-240^\circ$ ให้อยู่ในช่วง $0^\circ \le \theta < 360^\circ$ (2 คะแนน)
  2. ลด $\frac{11\pi}{4}$ และ $-\frac{7\pi}{6}$ ให้อยู่ในช่วง $0 \le \theta < 2\pi$ (2 คะแนน)
  3. คำนวณหาค่าตรีโกณมิติทั้ง 4 ค่า (1 คะแนน)
เฉลยอย่างละเอียด / Detailed Solution:
1. ลดมุมองศา:
• $405^\circ = 360^\circ + 45^\circ \implies$ มุมคือ $45^\circ$ (Q I)
• $-240^\circ = -240^\circ + 360^\circ = 120^\circ \implies$ มุมคือ $120^\circ$ (Q II)

2. ลดมุมเรเดียน:
• $\frac{11\pi}{4} = 2\pi + \frac{3\pi}{4} \implies$ มุมคือ $\frac{3\pi}{4}$ ($135^\circ$, Q II)
• $-\frac{7\pi}{6} = -\frac{7\pi}{6} + 2\pi = \frac{5\pi}{6} \implies$ มุมคือ $\frac{5\pi}{6}$ ($150^\circ$, Q II)

3. คำนวณค่าตรีโกณมิติ:
• $\sin 405^\circ = \sin 45^\circ = \frac{\sqrt{2}}{2}$
• $\cos(-240^\circ) = \cos 120^\circ = -\cos 60^\circ = -\frac{1}{2}$
• $\tan \frac{11\pi}{4} = \tan \frac{3\pi}{4} = -1$
• $\sin(-\frac{7\pi}{6}) = \sin \frac{5\pi}{6} = \sin \frac{\pi}{6} = \frac{1}{2}$

ตอนที่ 4 / Part 4: ตรีโกณมิติและ SHM (ต่อ)

5 คะแนน
ข้อ 2. อนุภาคหนึ่งเคลื่อนที่แบบ SHM โดยมีสมการการกระจัด $x = 0.20\cos\theta$ เมตร และสมการความเร็ว $v = -0.40\sin\theta$ เมตรต่อวินาที (5 คะแนน) A particle undergoes SHM with displacement $x = 0.20\cos\theta\text{ m}$ and velocity $v = -0.40\sin\theta\text{ m/s}$.
Given Data / ข้อมูลกำหนด
Displacement / การกระจัด$x = 0.20\cos\theta\text{ m}$
Velocity / ความเร็ว$v = -0.40\sin\theta\text{ m/s}$
Angles for $x$ / มุมหาค่า $x$$\theta = 0, \frac{\pi}{3}, \frac{\pi}{2}, \pi$
Angle for $v$ / มุมหาค่า $v$$\theta = \frac{\pi}{6}$
  1. หาการกระจัด $x$ ที่มุม $\theta = 0, \frac{\pi}{3}, \frac{\pi}{2}, \pi$ (2 คะแนน)
  2. หาความเร็ว $v$ ที่มุม $\theta = \frac{\pi}{6}$ (1 คะแนน)
  3. ระบุเครื่องหมายของ $x$ ที่มุมทั้ง 4 ค่า (1 คะแนน)
  4. อธิบายการเปลี่ยนแปลงของ $x$ เมื่อมุมเพิ่มจาก $0$ ถึง $\pi$ (1 คะแนน)
เฉลยอย่างละเอียด / Detailed Solution:
1. การกระจัด $x$:
• $\theta = 0 \implies x = 0.20 \cos 0 = 0.20\text{ m}$
• $\theta = \frac{\pi}{3} \implies x = 0.20 \cos \frac{\pi}{3} = 0.20(0.5) = 0.10\text{ m}$
• $\theta = \frac{\pi}{2} \implies x = 0.20 \cos \frac{\pi}{2} = 0\text{ m}$
• $\theta = \pi \implies x = 0.20 \cos \pi = -0.20\text{ m}$

2. ความเร็ว $v$ ที่มุม $\theta = \frac{\pi}{6}$:
$$v = -0.40 \sin \frac{\pi}{6} = -0.40 \times 0.5 = -0.20\text{ m/s}$$
3. เครื่องหมายของ $x$: บวก, บวก, ศูนย์, ลบ ตามลำดับ
4. อธิบาย: วัตถุเริ่มเคลื่อนที่จากตำแหน่งสูงสุดด้านบวก ($+0.20\text{ m}$) เคลื่อนกลับเข้าสู่จุดสมดุล ($0\text{ m}$) และเลยไปยังตำแหน่งสูงสุดด้านลบ ($-0.20\text{ m}$)
