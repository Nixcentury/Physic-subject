1
ล้อเริ่มหมุนจากหยุดนิ่ง / A wheel starts rotating from rest
7 pts
ล้อรัศมี \(R=0.80\,m\) เริ่มหมุนจากหยุดนิ่งด้วยความเร่งเชิงมุมคงที่ \(\alpha=2.0\,rad/s^2\) เป็นเวลา \(4.0\,s\).
A wheel of radius \(R=0.80\,m\) starts from rest with constant angular acceleration \(\alpha=2.0\,rad/s^2\) for \(4.0\,s\).
SVG model / รูปจำลอง
เริ่มจากนิ่งจึงใช้ \(\omega_0=0\). / Starting from rest means \(\omega_0=0\).
Given data / ข้อมูลกำหนด
Quantity / ปริมาณValue / ค่า
\(R\)\(0.80\,m\)
\(\omega_0\)\(0\,rad/s\)
\(\alpha\)\(2.0\,rad/s^2\)
\(t\)\(4.0\,s\)
  1. หาความเร็วมุมสุดท้าย \(\omega\)
    Find the final angular speed \(\omega\). (2 pts / 2 คะแนน)
  2. หาระยะเชิงมุม \(\theta\)
    Find the angular displacement \(\theta\). (2 pts / 2 คะแนน)
  3. ล้อหมุนไปกี่รอบโดยประมาณ
    Approximately how many revolutions does the wheel complete? (2 pts / 2 คะแนน)
  4. หาอัตราเร็วเชิงเส้นที่ขอบล้อ ณ \(t=4.0s\)
    Find the linear speed at the rim at \(t=4.0s\). (1 pt / 1 คะแนน)
เฉลย / Solution
\(\omega=\omega_0+\alpha t=0+(2.0)(4.0)=\)\(8.0\,rad/s\)
\(\theta= rac12\alpha t^2= rac12(2.0)(4.0)^2=\)\(16\,rad\)
รอบ \(=\theta/(2\pi)=16/(6.28)=\)\(2.55\) รอบ
\(v=\omega R=(8.0)(0.80)=\)\(6.4\,m/s\)

จุดบนขอบล้อ: ความเร่งสัมผัสและความเร่งสู่ศูนย์กลาง / A point on the rim: tangential and centripetal acceleration
7 pts
จานหมุนรัศมี \(R=0.50\,m\) เริ่มจากหยุดนิ่งและมีความเร่งเชิงมุม \(\alpha=3.0\,rad/s^2\). พิจารณาจุดบนขอบจานเมื่อเวลาผ่านไป \(2.0\,s\).
A rotating disk of radius \(R=0.50\,m\) starts from rest with angular acceleration \(\alpha=3.0\,rad/s^2\). Consider a point on the rim after \(2.0\,s\).
SVG model / รูปจำลอง
ที่ขอบล้อมีทั้ง \(a_t\) ตามแนวสัมผัส และ \(a_c\) เข้าสู่ศูนย์กลาง / At the rim, \(a_t\) is tangential and \(a_c\) points inward.
Given data / ข้อมูลกำหนด
Quantity / ปริมาณValue / ค่า
\(R\)\(0.50\,m\)
\(\omega_0\)\(0\,rad/s\)
\(\alpha\)\(3.0\,rad/s^2\)
\(t\)\(2.0\,s\)
  1. หา \(\omega\) หลัง \(2.0s\)
    Find \(\omega\) after \(2.0s\). (1 pt / 1 คะแนน)
  2. หาความเร่งสัมผัส \(a_t\)
    Find the tangential acceleration \(a_t\). (2 pts / 2 คะแนน)
  3. หาอัตราเร็วเชิงเส้น \(v\)
    Find the linear speed \(v\). (2 pts / 2 คะแนน)
  4. หาความเร่งสู่ศูนย์กลาง \(a_c\) ณ ขณะนั้น
    Find the centripetal acceleration \(a_c\) at that instant. (2 pts / 2 คะแนน)
เฉลย / Solution
\(\omega=\alpha t=(3.0)(2.0)=\)\(6.0\,rad/s\)
\(a_t=\alpha R=(3.0)(0.50)=\)\(1.5\,m/s^2\)
\(v=\omega R=(6.0)(0.50)=\)\(3.0\,m/s\)
\(a_c=\omega^2R=(6.0)^2(0.50)=\)\(18\,m/s^2\)

เชือกถูกดึงออกจากดรัมหมุน / Rope pulled from a rotating drum
7 pts
เชือกพันรอบดรัมรัศมี \(R=0.25\,m\) และไม่ลื่น ดึงเชือกให้มีความเร่งเชิงเส้น \(a=0.75\,m/s^2\) จากหยุดนิ่งเป็นเวลา \(6.0\,s\).
A rope is wrapped around a drum of radius \(R=0.25\,m\) without slipping. The rope has linear acceleration \(a=0.75\,m/s^2\) from rest for \(6.0\,s\).
SVG model / รูปจำลอง
เมื่อไม่ลื่น \(a=\alpha R\) และระยะเชือกที่ถูกดึง \(s=R\theta\). / Without slipping, \(a=\alpha R\) and rope distance \(s=R\theta\).
Given data / ข้อมูลกำหนด
Quantity / ปริมาณValue / ค่า
\(R\)\(0.25\,m\)
linear \(a\)\(0.75\,m/s^2\)
\(\omega_0\)\(0\,rad/s\)
\(t\)\(6.0\,s\)
  1. หาความเร่งเชิงมุม \(\alpha\)
    Find the angular acceleration \(\alpha\). (2 pts / 2 คะแนน)
  2. หาความเร็วมุมสุดท้าย \(\omega\)
    Find the final angular speed \(\omega\). (2 pts / 2 คะแนน)
  3. หาระยะเชิงมุม \(\theta\)
    Find the angular displacement \(\theta\). (2 pts / 2 คะแนน)
  4. เชือกถูกดึงออกไปกี่เมตร
    How many metres of rope are pulled out? (1 pt / 1 คะแนน)
เฉลย / Solution
\(\alpha=a/R=0.75/0.25=\)\(3.0\,rad/s^2\)
\(\omega=\alpha t=(3.0)(6.0)=\)\(18\,rad/s\)
\(\theta= rac12\alpha t^2= rac12(3.0)(6.0)^2=\)\(54\,rad\)
\(s=R\theta=(0.25)(54)=\)\(13.5\,m\)

จุดที่ขอบล้อเคลื่อนที่เป็นระยะตามส่วนโค้ง / A point on the rim moves through an arc distance
7 pts
ล้อรัศมี \(R=0.40\,m\) เริ่มหมุนจากหยุดนิ่งด้วยความเร่งเชิงมุม \(\alpha=1.5\,rad/s^2\) เป็นเวลา \(5.0\,s\). พิจารณาจุดบนขอบล้อ

SVG model / รูปจำลอง
ระยะเชิงเส้นตามส่วนโค้งที่ขอบล้อสัมพันธ์กับระยะเชิงมุมด้วย \(s=R\theta\). / Arc distance at the rim is related by \(s=R\theta\).
Given data / ข้อมูลกำหนด
Quantity / ปริมาณValue / ค่า
\(R\)\(0.40\,m\)
\(\omega_0\)\(0\,rad/s\)
\(\alpha\)\(1.5\,rad/s^2\)
\(t\)\(5.0\,s\)
  1. หาระยะเชิงมุม \(\theta\)
    Find the angular displacement \(\theta\). (2 pts / 2 คะแนน)
  2. หาระยะเชิงเส้นตามส่วนโค้ง \(s\)
    Find the arc distance \(s\). (2 pts / 2 คะแนน)
  3. หา \(\omega\) และ \(a_t\) ที่ \(t=5.0s\)
    Find \(\omega\) and \(a_t\) at \(t=5.0s\). (2 pts / 2 คะแนน)
  4. หา \(a_c\) ณ ขณะนั้น
    Find \(a_c\) at that instant. (1 pt / 1 คะแนน)
เฉลย / Solution

\(s=R\theta=(0.40)(18.75)=\)\(7.50\,m\)
\(\omega=\alpha t=(1.5)(5.0)=7.5\,rad/s\), \(a_t=\alpha R=(1.5)(0.40)=\)\(0.60\,m/s^2\)
\(a_c=\omega^2R=(7.5)^2(0.40)=\)\(22.5\,m/s^2\)

พัดลมชะลอจนหยุด / A fan slows down to rest
7 pts
พัดลมมีความเร็วมุมเริ่มต้น \(\omega_0=20\,rad/s\) แล้วถูกเบรกด้วยความเร่งเชิงมุมคงที่ \(\alpha=-4.0\,rad/s^2\). รัศมีใบพัด \(R=0.30\,m\).
A fan has initial angular speed \(\omega_0=20\,rad/s\) and is braked with constant angular acceleration \(\alpha=-4.0\,rad/s^2\). The blade radius is \(R=0.30\,m\).
SVG model / รูปจำลอง
เครื่องหมายลบของ \(\alpha\) หมายถึงความเร็วมุมลดลง / Negative \(\alpha\) means angular speed decreases.
Given data / ข้อมูลกำหนด
Quantity / ปริมาณValue / ค่า
\(\omega_0\)\(20\,rad/s\)
\(\alpha\)\(-4.0\,rad/s^2\)
final \(\omega\)\(0\,rad/s\)
\(R\)\(0.30\,m\)
  1. ใช้ \(\omega=\omega_0+\alpha t\) หาเวลาที่พัดลมหยุด
    Use \(\omega=\omega_0+\alpha t\) to find the stopping time. (2 pts / 2 คะแนน)
  2. หาระยะเชิงมุม \(\theta\) ระหว่างการชะลอ
    Find the angular displacement \(\theta\) during braking. (2 pts / 2 คะแนน)
  3. คิดเป็นจำนวนรอบประมาณเท่าใด
    Approximately how many revolutions is this? (2 pts / 2 คะแนน)
  4. หาขนาดความเร่งสัมผัสที่ปลายใบพัด
    Find the magnitude of tangential acceleration at the blade tip. (1 pt / 1 คะแนน)
เฉลย / Solution
หยุดเมื่อ \(0=20+(-4.0)t\Rightarrow t=\)\(5.0\,s\)
\(\theta=\omega_0t+ rac12\alpha t^2=(20)(5.0)+ rac12(-4.0)(5.0)^2=100-50=\)\(50\,rad\)
รอบ \(=\theta/(2\pi)=50/6.28=\)\(7.96\) รอบ
\(|a_t|=|\alpha|R=(4.0)(0.30)=\)\(1.2\,m/s^2\)
