ประแจขันน็อต / Using a wrench on a bolt
7 pts
ช่างกำลังใช้ประแจหมุนน็อต โดยจุดหมุนอยู่ที่ศูนย์กลางน็อต ให้ถือว่าทุกแรงกระทำในระนาบเดียวกัน และพิจารณาเฉพาะขนาดและทิศของแรงบิด
A mechanic uses a wrench to rotate a bolt. The pivot is at the center of the bolt. Assume all forces act in the same plane and consider only the magnitude and direction of torque.
SVG model / รูปจำลอง
ในแต่ละกรณี จุดหมุนคือศูนย์กลางน็อตที่ปลายประแจด้านซ้าย / In each case, the pivot is the bolt center at the left end of the wrench.
Given data / ข้อมูลกำหนด
Case / กรณีData / ข้อมูล
A\(r=0.30\,m\), \(F=40\,N\), perpendicular
B\(r=0.20\,m\), \(F=30\,N\), perpendicular
C\(r=0.50\,m\), \(F=20\,N\), \(\theta=60^\circ\)
  1. หาแรงบิดของกรณี A พร้อมทิศ / Find the torque for Case A with direction. (2 pts / 2 คะแนน)
  2. หาแรงบิดของกรณี B พร้อมทิศ / Find the torque for Case B with direction. (1.5 pts / 1.5 คะแนน)
  3. หาแรงบิดของกรณี C พร้อมทิศ / Find the torque for Case C with direction. (2 pts / 2 คะแนน)
  4. กรณีใดให้แรงบิดมากที่สุด และเพราะเหตุใด / Which case gives the largest torque, and why? (1 pt / 1 คะแนน)
  5. ถ้าแรงพาดผ่านจุดหมุนพอดี แรงบิดจะเป็นเท่าใด / If the line of action passes through the pivot, what is the torque? (0.5 pt / 0.5 คะแนน)
เฉลย / Solution
Case A: \(\tau=rF=(0.30)(40)=\)\(12\,N\cdot m\), direction CCW.
Case B: \(\tau=rF=(0.20)(30)=\)\(6\,N\cdot m\), direction CCW.
Case C: \(\tau=rF\sin\theta=(0.50)(20)\sin60^\circ=10(0.866)=\)\(8.66\,N\cdot m\), direction CCW.
Largest torque is Case A because it has the greatest effective product \(rF\sin\theta\).
If the line of action passes through the pivot, the lever arm is zero, so torque is 0.

ไม้กระดกสมดุลหรือไม่ / Is the seesaw balanced?
7 pts
เด็กคนหนึ่งนั่งทางซ้ายของจุดหมุน ส่วนผู้ใหญ่นั่งทางขวา ให้ละเลยน้ำหนักของแผ่นไม้ แล้วพิจารณาเฉพาะแรงน้ำหนักของคนทั้งสอง
A child sits on the left of the pivot and an adult sits on the right. Neglect the weight of the board and consider only the weights of the two people.
SVG model / รูปจำลอง
แรงน้ำหนักทั้งสองกระทำลงในแนวดิ่ง / Both weights act vertically downward.
Given data / ข้อมูลกำหนด
Person / คนWeight / น้ำหนักDistance from pivot / ระยะจากจุดหมุน
Child / เด็ก\(250\,N\)\(1.20\,m\) to the left
Adult / ผู้ใหญ่\(400\,N\)\(x\) to the right
  1. หาแรงบิดของเด็กเกี่ยวกับจุดหมุน / Find the child's torque about the pivot. (1.5 pts / 1.5 คะแนน)
  2. ถ้าไม้กระดกสมดุล จงหา \(x\) / If the seesaw is balanced, find \(x\). (2.5 pts / 2.5 คะแนน)
  3. ถ้าผู้ใหญ่นั่งห่างจุดหมุนเพียง \(0.60\,m\) จงหาแรงบิดลัพธ์ / If the adult sits only \(0.60\,m\) from the pivot, find the net torque. (2 pts / 2 คะแนน)
  4. ไม้กระดกจะหมุนไปทางด้านใด / Which side will move downward? (1 pt / 1 คะแนน)
เฉลย / Solution
Child's torque: \(\tau=(1.20)(250)=\)\(300\,N\cdot m\), direction CCW.
Balance: \((250)(1.20)=(400)x\Rightarrow 300=400x\Rightarrow x=\)\(0.75\,m\).
If adult sits at \(0.60\,m\): adult torque \(=(400)(0.60)=240\,N\cdot m\) clockwise. Net torque \(=300-240=\)\(60\,N\cdot m\) CCW.
The board turns so that the child's side goes downward.

ล้อทดลองถูกดึงให้หมุน / A test wheel is driven by a tangential force
7 pts
ในห้องทดลอง มีการดึงขอบล้อด้วยแรงแนวสัมผัสคงที่ ขณะเดียวกันมีแรงบิดเสียดทานต้านการหมุน ให้ถือว่าล้อเริ่มจากหยุดนิ่ง
In a lab, a wheel is pulled by a constant tangential force at the rim while friction provides an opposing torque. Assume the wheel starts from rest.
SVG model / รูปจำลอง
แรง 15 N ดึงในแนวสัมผัสที่ขอบล้อ / A 15 N force pulls tangentially at the rim.
Given data / ข้อมูลกำหนด
Quantity / ปริมาณValue / ค่า
Force \(F\)\(15\,N\)
Radius \(R\)\(0.20\,m\)
Moment of inertia \(I\)\(0.60\,kg\cdot m^2\)
Opposing torque\(0.8\,N\cdot m\)
Initial \(\omega_0\)\(0\,rad/s\)
Time\(4.0\,s\)
  1. หาแรงบิดจากแรงดึงที่ขอบล้อ / Find the torque due to the pulling force. (1.5 pts / 1.5 คะแนน)
  2. หาแรงบิดลัพธ์ / Find the net torque. (1.5 pts / 1.5 คะแนน)
  3. หาความเร่งเชิงมุม \(\alpha\) / Find the angular acceleration \(\alpha\). (1.5 pts / 1.5 คะแนน)
  4. หา \(\omega\) หลัง \(4.0\,s\) / Find \(\omega\) after \(4.0\,s\). (1.5 pts / 1.5 คะแนน)
  5. หาความเร่งสัมผัสที่ขอบล้อ / Find the tangential acceleration at the rim. (1 pt / 1 คะแนน)
เฉลย / Solution
Applied torque: \(\tau=rF=(0.20)(15)=\)\(3.0\,N\cdot m\).
Net torque: \(\tau_{net}=3.0-0.8=\)\(2.2\,N\cdot m\).
\(\alpha=\tau_{net}/I=2.2/0.60=\)\(3.67\,rad/s^2\).
\(\omega=\omega_0+\alpha t=0+(3.67)(4.0)=\)\(14.7\,rad/s\).
\(a_t=\alpha R=(3.67)(0.20)=\)\(0.73\,m/s^2\).

เชือกคลายจากดรัม / Rope unwinds from a drum
7 pts
ดรัมหมุนได้อย่างอิสระและมีเชือกพันอยู่โดยรอบ เมื่อดรัมมีความเร่งเชิงมุมคงที่ เชือกจึงเคลื่อนที่ลงโดยไม่ลื่น
A freely rotating drum has a rope wound around it. When the drum has constant angular acceleration, the rope moves downward without slipping.
SVG model / รูปจำลอง
เชือกเคลื่อนที่ลงด้วยอัตราเร่งเชิงเส้นที่สอดคล้องกับ \(\alpha\) / The rope moves downward with linear acceleration related to \(\alpha\).
Given data / ข้อมูลกำหนด
Quantity / ปริมาณValue / ค่า
Radius \(R\)\(0.10\,m\)
Moment of inertia \(I\)\(0.050\,kg\cdot m^2\)
Angular acceleration \(\alpha\)\(8.0\,rad/s^2\)
Initial \(\omega_0\)\(0\,rad/s\)
Time\(3.0\,s\)
  1. หาอัตราเร่งเชิงเส้นของเชือก / Find the linear acceleration of the rope. (1.5 pts / 1.5 คะแนน)
  2. หาแรงบิดลัพธ์บนดรัม / Find the net torque on the drum. (1.5 pts / 1.5 คะแนน)
  3. หาแรงตึงเชือก \(T\) / Find the tension \(T\) in the rope. (2 pts / 2 คะแนน)
  4. ในเวลา \(3.0\,s\) เชือกคลายออกยาวเท่าใด / In \(3.0\,s\), how much rope is unwound? (2 pts / 2 คะแนน)
เฉลย / Solution
\(a=\alpha R=(8.0)(0.10)=\)\(0.80\,m/s^2\) downward.
\(\tau_{net}=I\alpha=(0.050)(8.0)=\)\(0.40\,N\cdot m\).
\(\tau=TR\Rightarrow T=\tau/R=0.40/0.10=\)\(4.0\,N\).
\(\theta=\tfrac12\alpha t^2=\tfrac12(8.0)(3.0)^2=36\,rad\). Thus \(s=R\theta=(0.10)(36)=\)\(3.6\,m\).

แท่นหมุนกำลังชะลอ / A rotating platform is slowing down
7 pts
แท่นหมุนในห้องทดลองกำลังหมุนด้วยความเร็วมุมเริ่มต้น แล้วถูกเบรกด้วยแรงบิดคงที่จนหยุด ให้พิจารณาว่าการชะลอเป็นแบบสม่ำเสมอ
A rotating platform in the lab has an initial angular speed and is then braked by a constant torque until it stops. Assume the slowing down is uniform.
SVG model / รูปจำลอง
แรงบิดจากเบรกมีทิศตรงข้ามกับการหมุนเดิม / The brake torque acts opposite to the original rotation.
Given data / ข้อมูลกำหนด
Quantity / ปริมาณValue / ค่า
Moment of inertia \(I\)\(12\,kg\cdot m^2\)
Initial \(\omega_0\)\(6.0\,rad/s\)
Brake torque\(9.0\,N\cdot m\)
Radius \(R\)\(0.50\,m\)
Final \(\omega\)\(0\,rad/s\)
  1. หาความเร่งเชิงมุม \(\alpha\) / Find the angular acceleration \(\alpha\). (1.5 pts / 1.5 คะแนน)
  2. หาเวลาที่แท่นหมุนหยุด / Find the time taken to stop. (1.5 pts / 1.5 คะแนน)
  3. หาระยะเชิงมุมทั้งหมดก่อนหยุด / Find the total angular displacement before stopping. (2 pts / 2 คะแนน)
  4. จุดที่ขอบแท่นหมุนเคลื่อนที่เป็นระยะกี่เมตร / How far does a point on the rim move? (1 pt / 1 คะแนน)
  5. หาอัตราเร็วเชิงมุมเฉลี่ยระหว่างการชะลอ / Find the average angular speed during the slowing down. (1 pt / 1 คะแนน)
เฉลย / Solution
\(\alpha=\Sigma\tau/I=-9.0/12=\)\(-0.75\,rad/s^2\).
\(0=6.0+(-0.75)t\Rightarrow t=\)\(8.0\,s\).
\(\theta=\omega_0t+\tfrac12\alpha t^2=(6.0)(8.0)+\tfrac12(-0.75)(8.0)^2=48-24=\)\(24\,rad\).
\(s=R\theta=(0.50)(24)=\)\(12\,m\).
Average angular speed \(=(\omega_0+\omega)/2=(6.0+0)/2=\)\(3.0\,rad/s\).
