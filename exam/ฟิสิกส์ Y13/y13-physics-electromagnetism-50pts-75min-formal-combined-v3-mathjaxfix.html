ตอนที่ 1 / Part A: ข้อปรนัย เลือกคำตอบที่ถูกต้องที่สุด (ข้อ 1–5)
  1. 1.ข้อใดอธิบาย “แม่เหล็ก” ได้ถูกต้องที่สุด
    Which statement best describes a magnet?ตอบ ข
    1. ก. สารที่ดูดได้เฉพาะโลหะทุกชนิด / attracts all metals
    2. ข. สารที่สามารถดูดหรือผลักแม่เหล็ก และออกแรงต่อสารแม่เหล็กได้ / can attract or repel magnets and act on magnetic materials
    3. ค. สารที่ต้องมีประจุไฟฟ้าเสมอ / must always have electric charge
    4. ง. สารที่เกิดจากกระแสไฟฟ้าเท่านั้น / produced only by electric current
    5. จ. สารที่ดูดได้เฉพาะทองแดง / attracts only copper
    แนวคำตอบ / Solution
    ตอบ B. แม่เหล็กมีสมบัติดูด/ผลักกับแม่เหล็ก และออกแรงต่อสารแม่เหล็กได้
  2. 2.สารใดเป็นตัวอย่างของสารเฟอโรแมกเนติก
    Which material is ferromagnetic?ตอบ ค
    1. ก. ทองแดง / Copper
    2. ข. เงิน / Silver
    3. ค. เหล็ก / Iron
    4. ง. อะลูมิเนียม / Aluminium
    5. จ. สังกะสี / Zinc
    แนวคำตอบ / Solution
    ตอบ C. เหล็กเป็นสารเฟอโรแมกเนติก ถูกแม่เหล็กดูดได้แรงมาก
  3. 3.ถ้าหักแท่งแม่เหล็กออกเป็น 2 ท่อน จะเกิดอะไรขึ้น
    What happens if a bar magnet is broken into two pieces?ตอบ ค
    1. ก. ได้ขั้วเหนือเดี่ยวและขั้วใต้เดี่ยว / isolated N and S poles are formed
    2. ข. แม่เหล็กหมดอำนาจทันที / all magnetism disappears
    3. ค. แต่ละท่อนมีทั้งขั้วเหนือและขั้วใต้ใหม่ / each piece has a new N and S pole
    4. ง. เหลือเฉพาะขั้วเหนือ / only north poles remain
    5. จ. เหลือเฉพาะขั้วใต้ / only south poles remain
    แนวคำตอบ / Solution
    ตอบ C. ไม่สามารถแยกขั้วแม่เหล็กเดี่ยว ๆ ได้ แต่ละท่อนจะมี N และ S ใหม่
  4. 4.ข้อใดถูกต้องเกี่ยวกับแรงระหว่างขั้วแม่เหล็ก
    Which statement about magnetic poles is correct?ตอบ ง
    1. ก. ขั้วเหมือนกันดูดกัน ขั้วต่างกันผลักกัน / like attract, unlike repel
    2. ข. ขั้วเหนือดูดขั้วเหนือเสมอ / N always attracts N
    3. ค. ขั้วใต้ผลักขั้วเหนือเสมอ / S always repels N
    4. ง. ขั้วเหมือนกันผลักกัน ขั้วต่างกันดูดกัน / like repel, unlike attract
    5. จ. แม่เหล็กทุกขั้วดูดกันเสมอ / all poles always attract
    แนวคำตอบ / Solution
    ตอบ D. ขั้วชนิดเดียวกันผลักกัน ขั้วต่างชนิดกันดูดกัน
  5. 5.ทิศของเส้นแรงแม่เหล็กภายนอกแท่งแม่เหล็กเป็นอย่างไร
    What is the direction of magnetic field lines outside a bar magnet?ตอบ ข
    1. ก. จาก S ไป N / S to N
    2. ข. จาก N ไป S / N to S
    3. ค. พุ่งออกจากทั้ง N และ S / outward from both
    4. ง. พุ่งเข้าทั้ง N และ S / inward to both
    5. จ. ไม่มีทิศทางแน่นอน / no definite direction
    แนวคำตอบ / Solution
    ตอบ B. ภายนอกแม่เหล็ก เส้นแรงออกจาก N และเข้าสู่ S

  1. 6.จากภาพ จุดใดมีสนามแม่เหล็กแรงที่สุด
    Where is the magnetic field strongest?ตอบ ก
    1. ก. จุด A เพราะอยู่ใกล้ขั้วและเส้นแรงถี่กว่า / Point A, near a pole with denser lines
    2. ข. จุด B เพราะอยู่เหนือแท่งแม่เหล็ก / Point B
    3. ค. จุด C เพราะอยู่ไกลจากแม่เหล็ก / Point C
    4. ง. ทุกจุดเท่ากัน / all equal
    5. จ. ไม่มีสนามแม่เหล็ก / no field
    แนวคำตอบ / Solution
    ตอบ A. สนามแรงบริเวณที่เส้นแรงถี่ โดยเฉพาะใกล้ขั้วแม่เหล็ก
  2. 7.จากภาพ ขั้วต่างชนิดหันเข้าหากัน เกิดแรงและเส้นแรงแบบใด
    Unlike poles face each other. What happens?ตอบ ก
    1. ก. ดูดกัน และเส้นแรงเชื่อมจาก N ไป S / attract; field lines connect from N to S
    2. ข. ผลักกัน และเส้นแรงเบนหนี / repel; lines bend away
    3. ค. ไม่ออกแรงต่อกัน / no force
    4. ง. ดูดกัน แต่เส้นแรงไปจาก S ไป N / attract; S to N
    5. จ. ผลักกันเพราะขั้วต่างกัน / repel because poles are unlike
    แนวคำตอบ / Solution
    ตอบ A. ขั้วต่างกันดูดกัน เส้นแรงภายนอกมีทิศจาก N ไป S
  3. 8.จากภาพ ขั้วเหมือนกันหันเข้าหากัน เกิดแรงแบบใด
    Like poles face each other. What happens?ตอบ ข
    1. ก. ดูดกัน เพราะขั้วเหมือนกัน / attract because poles are alike
    2. ข. ผลักกัน และเส้นแรงบริเวณกลางเบนออก / repel and lines bend away from the middle
    3. ค. ดูดกัน และเส้นแรงเชื่อมตรงกลาง / attract and lines connect
    4. ง. ไม่มีสนามแม่เหล็ก / no magnetic field
    5. จ. แรงเป็นศูนย์เสมอ / force is always zero
    แนวคำตอบ / Solution
    ตอบ B. ขั้วเหมือนกันผลักกัน เส้นแรงบริเวณกลางไม่เชื่อมตรงแบบขั้วต่างกัน

    1. ก. \(0.025\,Wb\)
    2. ข. \(0.050\,Wb\)
    3. ค. \(0.10\,Wb\)
    4. ง. \(0.25\,Wb\)
    5. จ. \(1.0\,Wb\)
