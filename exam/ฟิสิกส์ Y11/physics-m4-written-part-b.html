Situation 1: Basic Trigonometry for Physics
6 pts / 6 คะแนน
ก่อนเรียนการแตกแรง นักเรียนต้องทบทวนความสัมพันธ์ของสามเหลี่ยมมุมฉาก
Before resolving forces, students review right-triangle trigonometry.
รูปสามเหลี่ยมมุมฉาก / Right triangle

ด้านตรงข้าม hypotenuse = 10 cm
ค่า / Valueกำหนดให้ / Given
\(\sin37^\circ\)0.60
\(\cos37^\circ\)0.80
\(\tan37^\circ\)0.75
\(\sin\theta=\frac{opposite}{hypotenuse}\)
\(\cos\theta=\frac{adjacent}{hypotenuse}\)
\(\tan\theta=\frac{opposite}{adjacent}\)
hypotenuse = 10 cm
  1. หาด้านประชิดมุม \(37^\circ\) / Find the adjacent side. (2 pts)
  2. หาด้านตรงข้ามมุม \(37^\circ\) / Find the opposite side. (2 pts)
  3. ตรวจสอบค่า \(\tan37^\circ\) จากด้านที่หาได้ / Verify \(\tan37^\circ\) from the sides. (2 pts)
เฉลยละเอียด / Detailed solution
ก) adjacent \(=10\cos37^\circ=10(0.80)=\)8.0 cm
ข) opposite \(=10\sin37^\circ=10(0.60)=\)6.0 cm
ค) \(\tan37^\circ=\frac{6.0}{8.0}=0.75\) ตรงกับค่าที่กำหนด / agrees with the given value.

Situation 2: Pulling a Box with an Inclined Force
8 pts / 8 คะแนน
นักเรียนออกแรงดึงกล่องด้วยแรง \(50\,N\) ทำมุม \(37^\circ\) เหนือแนวระดับ
A student pulls a box with a \(50\,N\) force at \(37^\circ\) above the horizontal.
รูปแรงกระทำต่อกล่อง / Force diagram
กำหนดให้ / Givenค่า / Value
\(F\)50 N
\(\sin37^\circ\)0.60
\(\cos37^\circ\)0.80
  1. หาองค์ประกอบแรงในแนวแกน \(x\) / Find the x-component of the force. (2 pts)
  2. หาองค์ประกอบแรงในแนวแกน \(y\) / Find the y-component of the force. (2 pts)
  3. เขียนแรงในรูปเวกเตอร์ \(\vec F = F_x\hat i + F_y\hat j\)
    Write the force in vector form. (2 pts)
  4. อธิบายว่าทำไม \(F_x\) ใช้ \(\cos\theta\) และ \(F_y\) ใช้ \(\sin\theta\)
    Explain why \(F_x\) uses \(\cos\theta\) and \(F_y\) uses \(\sin\theta\). (2 pts)
💡 Hint: มุมวัดจากแกน x ดังนั้นด้านที่ชิดมุมคือแกน x และด้านที่ห่างมุมคือแกน y
เฉลยละเอียด / Detailed solution
ก) \(F_x=F\cos37^\circ=50(0.80)=\)40 N
ข) \(F_y=F\sin37^\circ=50(0.60)=\)30 N
ค) \(\vec F=\)\(40\hat i+30\hat j\;N\)
ง) เพราะมุมวัดจากแกน x ด้านประชิดมุมคือแกน x จึงใช้ cos ส่วนแกน y เป็นด้านตรงข้ามมุมจึงใช้ sin

Situation 4: Three-Vector Wind Forces on a Drone
14 pts / 14 คะแนน
โดรนลำหนึ่งถูกแรงจากลม 3 ทิศทาง โดยมุมทุกมุมวัดเทียบกับแกน \(x\) เหมือนใน Vector Lab
A drone is acted on by three wind forces. Each angle is measured from the x-axis, as in the Vector Lab.
แผนภาพเวกเตอร์ 3 ตัว / Three-vector diagram
เวกเตอร์
Vector		ขนาด
Magnitude		มุม
Angle		จตุภาค
Quadrant
A50 N37°Q1
B40 N53°Q2
C30 N60°Q4
มุม

  1. หา \(A_x\) และ \(A_y\) / Find \(A_x\) and \(A_y\). (2 pts)
  2. หา \(B_x\) และ \(B_y\) / Find \(B_x\) and \(B_y\). (2 pts)
  3. หา \(C_x\) และ \(C_y\) / Find \(C_x\) and \(C_y\). (2 pts)
  4. หา \(\Sigma F_x\) และ \(\Sigma F_y\) / Find \(\Sigma F_x\) and \(\Sigma F_y\). (3 pts)
  5. หาขนาดแรงลัพธ์ \(R\) / Find the magnitude of the resultant force \(R\). (2 pts)
  6. หาทิศทางของแรงลัพธ์ และระบุจตุภาค / Find the direction and quadrant of the resultant force. (3 pts)
💡 Hint: ใช้เครื่องหมายตามจตุภาค — Q1 \(+,+\), Q2 \(-,+\), Q3 \(-,-\), Q4 \(+,-\)
เฉลยละเอียด / Detailed solution
A อยู่ Q1: \(A_x=+50(0.80)=\)+40 N, \(A_y=+50(0.60)=\)+30 N
B อยู่ Q2: \(B_x=-40(0.60)=\)-24 N, \(B_y=+40(0.80)=\)+32 N
C อยู่ Q4: \(C_x=+30(0.50)=\)+15 N, \(C_y=-30(0.87)=\)-26.1 N
\(\Sigma F_x=40-24+15=\)31 N
\(\Sigma F_y=30+32-26.1=\)35.9 N
\(R=\sqrt{31^2+35.9^2}=\)47.4 N
\(\tan\theta=\frac{35.9}{31}\), \(\theta\approx\)49.2° เหนือแกน +x และอยู่ Q1

Situation 5: A Cart Starting from Rest
7 pts / 7 คะแนน
รถทดลองเริ่มจากหยุดนิ่งและเคลื่อนที่ด้วยความเร่งคงที่ \(2.0\,m/s^2\) เป็นเวลา \(5.0\,s\)
A cart starts from rest and moves with a constant acceleration of \(2.0\,m/s^2\) for \(5.0\,s\).
แผนภาพการเคลื่อนที่ / Motion diagram
\(v=u+at\)
\(s=ut+\frac12at^2\)
\(v^2=u^2+2as\)
\(s=\frac{u+v}{2}t\)
ตัวแปร
Variable		ค่า
Value
\(u\)0 m/s
\(a\)2.0 m/s²
\(t\)5.0 s
  1. ระบุ \(u,a,t\) จากสถานการณ์ / Identify \(u,a,t\). (1 pt)
  2. หาความเร็วปลาย \(v\) / Find the final velocity \(v\). (2 pts)
  3. หาการกระจัด \(s\) / Find the displacement \(s\). (2 pts)
  4. กราฟ \(v-t\) ของการเคลื่อนที่นี้ควรมีลักษณะอย่างไร / What should the \(v-t\) graph look like? (2 pts)
เฉลยละเอียด / Detailed solution

ง) กราฟ \(v-t\) เป็นเส้นตรงความชันบวก เพราะความเร่งคงที่และเป็นบวก

Situation 6: Reading a Velocity-Time Graph
7 pts / 7 คะแนน
กราฟ \(v-t\) แสดงการเคลื่อนที่ของวัตถุในช่วงเวลา 0–9 s
The \(v-t\) graph shows the motion of an object from 0 to 9 s.
กราฟ \(v-t\) / Velocity-time graph
  1. ช่วง 0–4 s มีความเร่งเท่าใด / What is the acceleration from 0–4 s? (1.5 pts)
  2. ช่วง 4–7 s มีความเร่งเท่าใด / What is the acceleration from 4–7 s? (1 pt)
  3. ช่วง 7–9 s มีความเร่งเท่าใด / What is the acceleration from 7–9 s? (1.5 pts)
  4. หาการกระจัดรวมจากพื้นที่ใต้กราฟ / Find the total displacement from the area under the graph. (2 pts)
  5. หาอัตราเร็วเฉลี่ยตลอด 9 s / Find the average speed over 9 s. (1 pt)
💡 Hint: ความชันของกราฟ \(v-t\) คือความเร่ง และพื้นที่ใต้กราฟคือการกระจัด
เฉลยละเอียด / Detailed solution
ก) \(a=\frac{8-0}{4-0}=\)+2 m/s²
ข) ความเร็วคงที่ 8 m/s → \(a=\)0 m/s²
ค) \(a=\frac{0-8}{9-7}=\)-4 m/s²
ง) พื้นที่ = \(\frac12(4)(8)+3(8)+\frac12(2)(8)=16+24+8=\)48 m
จ) average speed \(=\frac{48}{9}\approx\)5.3 m/s
