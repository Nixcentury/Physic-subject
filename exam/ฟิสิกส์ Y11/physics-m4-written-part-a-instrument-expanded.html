💡 Hint: ปริมาณฐานเป็นปริมาณที่กำหนดหน่วยเอง ส่วนปริมาณอนุพันธ์เกิดจากการนำปริมาณฐานมาคำนวณร่วมกัน
Base quantities have their own SI base units. Derived quantities are made from combinations of base quantities.

Situation 2: Prefixes and Compound Unit Conversion
8 pts / 8 คะแนน
ในรายงาน Lab นักเรียนต้องแปลงข้อมูลก่อนนำไปคำนวณ โดยเฉพาะหน่วยพื้นที่ ปริมาตร ความหนาแน่น และอัตราเร็ว
In a lab report, students must convert data before calculation, especially area, volume, density, and speed units.
  1. 350 μm = __________ m (1 pt)
  2. 4.0 cm² = __________ m² (1.5 pts)
  3. 8.0 cm³ = __________ m³ (1.5 pts)
  4. 1.2 g/cm³ = __________ kg/m³ (2 pts)
  5. 72 km/h = __________ m/s (1 pt)
  6. อธิบายว่าทำไม \(cm^2\) จึงไม่ใช่แค่คูณ \(10^{-2}\)
    Explain why converting \(cm^2\) is not simply multiplying by \(10^{-2}\). (1 pt)
💡 Hint: \(1\,cm = 10^{-2}\,m\) แต่ \(1\,cm^2 = (10^{-2}\,m)^2\) และ \(1\,cm^3 = (10^{-2}\,m)^3\)
เฉลยละเอียด / Detailed solution
ก) \(350\,\mu m = 350 \times 10^{-6}\,m = \)\(3.50\times10^{-4}\,m\)
ข) \(4.0\,cm^2 = 4.0(10^{-2}\,m)^2 = \)\(4.0\times10^{-4}\,m^2\)
ค) \(8.0\,cm^3 = 8.0(10^{-2}\,m)^3 = \)\(8.0\times10^{-6}\,m^3\)
ง) \(1.2\,g/cm^3 = 1.2\frac{10^{-3}\,kg}{10^{-6}\,m^3}\) = \(1.2\times10^3\,kg/m^3\)
จ) \(72\,km/h = 72\times\frac{1000}{3600}\) = \(20\,m/s\)
ฉ) พื้นที่มีหน่วยยกกำลังสอง จึงต้องยกกำลังสองทั้งหน่วยและตัวคูณ
Area is squared, so the conversion factor must also be squared.

รูปที่ 3: เวอร์เนียคาลิเปอร์ / Figure 3: Vernier caliper
  1. อ่านค่าสเกลหลักได้เท่าใด / What is the main scale reading? (2 pts)
  2. ขีดเวอร์เนียที่ตรงกับสเกลหลักคือขีดที่เท่าใด / Which vernier mark aligns with the main scale? (2 pts)
  3. ค่าสเกลเวอร์เนียมีค่าเท่าใด / What is the vernier scale reading? (2 pts)
  4. ผลการวัดรวมเป็นเท่าใด / What is the total measurement? (2 pts)
  5. ควรรายงานคำตอบเป็นทศนิยมกี่ตำแหน่ง เพราะเหตุใด / How many decimal places should be reported, and why? (1 pt)
เฉลยละเอียด / Detailed solution
สเกลหลัก = 2.30 cm
ขีดเวอร์เนียที่ตรงกัน = ขีดที่ 4
สเกลเวอร์เนีย = \(4\times0.01\) = 0.04 cm
ผลรวม = \(2.30+0.04\) = 2.34 cm
ความละเอียด 0.01 cm จึงรายงานเป็น ทศนิยม 2 ตำแหน่ง
