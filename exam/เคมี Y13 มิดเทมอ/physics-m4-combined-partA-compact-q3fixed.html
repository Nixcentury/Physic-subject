🔬 Lab Result Sheet / ใบบันทึกผลการทดลอง
รายการวัด / Measurement เครื่องมือ / Instrument ค่าที่อ่านได้ / Raw data ต้องแปลงเป็น / Convert to
ความหนาของเส้นใย / Fiber thickness Microscope scale 350 μm m
พื้นที่แผ่นโลหะเล็ก / Small metal sheet area Grid paper 4.0 cm² m²
ปริมาตรก้อนตัวอย่าง / Sample volume Water displacement 8.0 cm³ m³
ความหนาแน่นของชิ้นงาน / Sample density Balance + cylinder 1.2 g/cm³ kg/m³
อัตราเร็วรถทดลอง / Lab cart speed Motion sensor 72 km/h m/s

    \(4.0\,cm^2 =\) __________ \(m^2\) (1.5 pts)
  3. จากการแทนที่น้ำในกระบอกตวง จงแปลงปริมาตร \(8.0\,cm^3\) เป็นหน่วย \(m^3\)

    \(8.0\,cm^3 =\) __________ \(m^3\) (1.5 pts)

    A student wrote \(1\,cm^2 = 10^{-2}\,m^2\) in the lab report. Explain why this is incorrect. (1 pt)
💡 Hint: \(1\,cm = 10^{-2}\,m\) แต่ \(1\,cm^2 = (10^{-2}\,m)^2\) และ \(1\,cm^3 = (10^{-2}\,m)^3\)

เฉลยละเอียด / Detailed solution
ก) ความหนาเส้นใย / Fiber thickness
\(350\,\mu m = 350 \times 10^{-6}\,m\) \(= \)\(3.50\times10^{-4}\,m\)
ข) พื้นที่แผ่นโลหะ / Metal sheet area
\(4.0\,cm^2 = 4.0(10^{-2}\,m)^2\) \(= 4.0\times10^{-4}\,m^2\)
ตอบ \(4.0\times10^{-4}\,m^2\)
ค) ปริมาตรก้อนตัวอย่าง / Sample volume
\(8.0\,cm^3 = 8.0(10^{-2}\,m)^3\) \(= 8.0\times10^{-6}\,m^3\)
ตอบ \(8.0\times10^{-6}\,m^3\)
ง) ความหนาแน่น / Density
\(1.2\,g/cm^3 = 1.2\frac{10^{-3}\,kg}{10^{-6}\,m^3}\) \(= 1.2\times10^3\,kg/m^3\)
ตอบ \(1.2\times10^3\,kg/m^3\)
จ) อัตราเร็วรถทดลอง / Lab cart speed
\(72\,km/h = 72\times\frac{1000\,m}{3600\,s}\) \(= 20\,m/s\)
ตอบ \(20\,m/s\)
ฉ) อธิบาย / Explanation
\(cm^2\) เป็นหน่วยพื้นที่ จึงต้องยกกำลังสองทั้งหน่วยและตัวคูณ: \(1\,cm^2=(10^{-2}\,m)^2=10^{-4}\,m^2\)
ดังนั้น \(1\,cm^2\) ไม่ใช่ \(10^{-2}\,m^2\) แต่เป็น \(10^{-4}\,m^2\)
