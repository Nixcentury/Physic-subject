1. Organic vs Inorganic Compounds / สารอินทรีย์และสารอนินทรีย์

Most organic compounds contain carbon / คาร์บอน as the main element and usually contain C-H bonds / พันธะ C-H. In contrast, some carbon-containing compounds such as CO₂, CO, and carbonate compounds are usually classified as inorganic / อนินทรีย์ compounds.

สารอินทรีย์ส่วนใหญ่มี carbon / คาร์บอน เป็นองค์ประกอบหลัก และมักมี C-H bonds / พันธะ C-H ในทางตรงกันข้าม สารที่มีคาร์บอนบางชนิด เช่น CO₂, CO และสารกลุ่มคาร์บอเนต มักจัดเป็นสาร inorganic / อนินทรีย์

2. Structural Formulas / สูตรโครงสร้างของสารอินทรีย์

In a skeletal structure / สูตรเส้นและมุม, line ends and corners represent carbon atoms, while hydrogen atoms attached to carbon are usually not shown. When reading any organic structure, each carbon atom should have four bonds / พันธะ 4 แขน. Organic compounds are also often classified by their functional group / หมู่ฟังก์ชัน, such as -OH, -CHO, -COOH, and -COO-.

ใน skeletal structure / สูตรเส้นและมุม ปลายเส้นและมุมหักแทนอะตอมคาร์บอน ส่วนไฮโดรเจนที่เกาะกับคาร์บอนมักไม่เขียนให้เห็น เมื่ออ่านโครงสร้างอินทรีย์ ต้องตรวจให้คาร์บอนแต่ละอะตอมมี four bonds / พันธะ 4 แขน สารอินทรีย์ยังมักจำแนกตาม functional group / หมู่ฟังก์ชัน เช่น -OH, -CHO, -COOH และ -COO-

3. Naming and Isomerism / การเรียกชื่อและไอโซเมอร์

Systematic organic naming follows the IUPAC / ระบบไอยูแพก system. In a name, the root name shows the number of carbon atoms, while the suffix / คำลงท้าย shows the compound family or the main functional group. Compounds with the same molecular formula but different structures are called isomer / ไอโซเมอร์.

การเรียกชื่อสารอินทรีย์อย่างเป็นระบบใช้ระบบ IUPAC / ระบบไอยูแพก ในชื่อสาร ชื่อรากบอกจำนวนอะตอมคาร์บอน ส่วน suffix / คำลงท้าย บอกตระกูลของสารหรือหมู่ฟังก์ชันหลัก สารที่มีสูตรโมเลกุลเหมือนกันแต่มีโครงสร้างต่างกันเรียกว่า isomer / ไอโซเมอร์

4. Physical Properties / สมบัติทางกายภาพ

Boiling point, melting point, and solubility depend on molecular size, molecular shape, and intermolecular forces / แรงยึดเหนี่ยวระหว่างโมเลกุล. Molecules that can form hydrogen bonding / พันธะไฮโดรเจน usually have higher boiling points than molecules of similar size. For isomers with the same molecular formula, more branching / การแตกกิ่ง usually lowers the boiling point because the surface area becomes smaller.

จุดเดือด จุดหลอมเหลว และการละลายน้ำ ขึ้นอยู่กับขนาดโมเลกุล รูปร่างโมเลกุล และ intermolecular forces / แรงยึดเหนี่ยวระหว่างโมเลกุล สารที่เกิด hydrogen bonding / พันธะไฮโดรเจน ได้ มักมีจุดเดือดสูงกว่าสารที่มีขนาดใกล้เคียงกัน สำหรับไอโซเมอร์ที่มีสูตรโมเลกุลเหมือนกัน เมื่อมี branching / การแตกกิ่ง มากขึ้น จุดเดือดมักลดลง เพราะพื้นที่ผิวสัมผัสลดลง

5. Hydrocarbon Types / ประเภทของไฮโดรคาร์บอน

An alkane / แอลเคน is a saturated hydrocarbon with only single bonds between carbon atoms. An alkene / แอลคีน is an unsaturated hydrocarbon with at least one carbon-carbon double bond. An alkyne / แอลไคน์ is an unsaturated hydrocarbon with at least one carbon-carbon triple bond.

6. Hydrocarbon Reactions / ปฏิกิริยาของไฮโดรคาร์บอน

Alkanes mainly undergo substitution reaction / ปฏิกิริยาการแทนที่ and usually require UV light when reacting with bromine. Alkenes and alkynes mainly undergo addition reaction / ปฏิกิริยาการเติม with bromine, so the bromine solution is decolorized. Benzene is more stable because of resonance / รีโซแนนซ์, so it does not easily undergo addition under normal conditions.
