1. Sugar vs Salt / น้ำตาลกับเกลือ

Sugar, such as sucrose, is an organic substance. Most organic substances are usually molecular substances or covalent compounds / สารประกอบโคเวเลนต์ and often contain C-H bonds / พันธะ C-H. In contrast, table salt, sodium chloride, is an inorganic substance made of positive and negative ions, so it is classified as ionic compounds / สารประกอบไอออนิก.

น้ำตาล เช่น ซูโครส จัดเป็นสารอินทรีย์ สารอินทรีย์ส่วนใหญ่มักเป็นสารโมเลกุลหรือ covalent compounds / สารประกอบโคเวเลนต์ และมักมี C-H bonds / พันธะ C-H ส่วนเกลือแกงเป็นสารอนินทรีย์ที่ประกอบด้วยไอออนบวกและไอออนลบ จึงจัดเป็น ionic compounds / สารประกอบไอออนิก

2. Hand Sanitizer vs Vinegar / แอลกอฮอล์ล้างมือกับน้ำส้มสายชู

Organic molecules can be represented by a skeletal structure / สูตรเส้นและมุม. Carbon is tetravalent / มีเวเลนซ์ 4, so each carbon atom should form four bonds. A part of a molecule such as -OH or -COOH that strongly affects chemical properties is called a functional group / หมู่ฟังก์ชัน.

โมเลกุลอินทรีย์สามารถเขียนแทนด้วย skeletal structure / สูตรเส้นและมุม คาร์บอนเป็นธาตุที่ tetravalent / มีเวเลนซ์ 4 จึงต้องสร้างพันธะรวม 4 พันธะ ส่วนของโมเลกุล เช่น -OH หรือ -COOH ที่ส่งผลต่อสมบัติทางเคมีอย่างมากเรียกว่า functional group / หมู่ฟังก์ชัน

3. Gas Can and Isomers / กระป๋องแก๊สกับไอโซเมอร์

The longest continuous carbon chain is called the parent chain / โซ่หลัก, while the ending of the name is called the suffix / คำลงท้าย. Butane and isobutane have the same molecular formula but different structures, so they are structural isomers / ไอโซเมอร์โครงสร้าง.

โซ่คาร์บอนต่อเนื่องที่ยาวที่สุดเรียกว่า parent chain / โซ่หลัก ส่วนท้ายของชื่อเรียกว่า suffix / คำลงท้าย บิวเทนและไอโซบิวเทนมีสูตรโมเลกุลเหมือนกันแต่มีโครงสร้างต่างกัน จึงเป็น structural isomers / ไอโซเมอร์โครงสร้าง

4. Oil, Alcohol, and Perfume / น้ำมัน แอลกอฮอล์ และน้ำหอม

These physical properties depend on molecular size, polarity, and intermolecular forces / แรงยึดเหนี่ยวระหว่างโมเลกุล. Alcohol can mix with water because the -OH group can form hydrogen bonding / พันธะไฮโดรเจน with water molecules. Many pleasant smells in fruits and perfumes come from organic compounds in the ester / เอสเทอร์ family.

สมบัติทางกายภาพเหล่านี้ขึ้นอยู่กับขนาดโมเลกุล ความมีขั้ว และ intermolecular forces / แรงยึดเหนี่ยวระหว่างโมเลกุล แอลกอฮอล์สามารถผสมกับน้ำได้ เพราะหมู่ -OH สามารถเกิด hydrogen bonding / พันธะไฮโดรเจน กับโมเลกุลของน้ำ กลิ่นหอมหลายชนิดในผลไม้และน้ำหอมมาจากสารอินทรีย์ในตระกูล ester / เอสเทอร์

5. Hydrocarbon Types in Daily Life / ประเภทของไฮโดรคาร์บอนในชีวิตประจำวัน

LPG contains propane and butane, which are examples of saturated hydrocarbons / ไฮโดรคาร์บอนอิ่มตัว. Ethene contains a carbon-carbon double bond / พันธะคู่. Acetylene contains a carbon-carbon triple bond / พันธะสาม.

LPG มีโพรเพนและบิวเทนเป็นองค์ประกอบ ซึ่งเป็นตัวอย่างของ saturated hydrocarbons / ไฮโดรคาร์บอนอิ่มตัว เอทีนมีพันธะคาร์บอน-คาร์บอนแบบ double bond / พันธะคู่ อะเซทิลีนมีพันธะคาร์บอน-คาร์บอนแบบ triple bond / พันธะสาม

6. Bromine Test and Benzene / การทดสอบด้วยโบรมีนและเบนซีน

Alkanes can react by substitution reaction / ปฏิกิริยาการแทนที่ under UV light. Alkenes and alkynes react with bromine by addition reaction / ปฏิกิริยาการเติม. Benzene is stabilized by resonance / รีโซแนนซ์.

แอลเคนสามารถเกิด substitution reaction / ปฏิกิริยาการแทนที่ ได้เมื่อมีแสง UV แอลคีนและแอลไคน์ทำปฏิกิริยากับโบรมีนโดยเกิด addition reaction / ปฏิกิริยาการเติม ส่วนเบนซีนมีความเสถียรจาก resonance / รีโซแนนซ์
