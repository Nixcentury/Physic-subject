Instructions / คำชี้แจง: Write the equation or product and state the reaction condition, observation, or rule when required.
จงเขียนสมการหรือผลิตภัณฑ์ พร้อมระบุเงื่อนไข สิ่งสังเกต หรือกฎที่ใช้เมื่อโจทย์กำหนด
Scoring / คะแนน: 10 items × 2 points = 20 points. Each item: answer/equation/calculation = 1 point, condition/observation/rule = 1 point.
1. Complete combustion of methane / การเผาไหม้สมบูรณ์ของมีเทน
(2 points / 2 คะแนน)

Write and balance the complete combustion equation of methane, CH₄. Also state the required condition.

จงเขียนและดุลสมการเผาไหม้สมบูรณ์ของมีเทน CH₄ พร้อมระบุเงื่อนไขที่จำเป็น

2. Complete combustion of butane / การเผาไหม้สมบูรณ์ของบิวเทน
(2 points / 2 คะแนน)

Write and balance the complete combustion equation of butane, C₄H₁₀. State the condition.

จงเขียนและดุลสมการเผาไหม้สมบูรณ์ของบิวเทน C₄H₁₀ พร้อมระบุเงื่อนไข

3. Incomplete combustion / การเผาไหม้ไม่สมบูรณ์
(2 points / 2 คะแนน)

Write one possible incomplete combustion equation of methane that produces carbon monoxide, CO. State the condition that causes incomplete combustion.

จงเขียนสมการเผาไหม้ไม่สมบูรณ์ของมีเทนที่เกิดคาร์บอนมอนอกไซด์ CO พร้อมระบุเงื่อนไขที่ทำให้เกิดการเผาไหม้ไม่สมบูรณ์

4. Alkane substitution / ปฏิกิริยาแทนที่ของแอลเคน
(2 points / 2 คะแนน)

Ethane reacts with bromine. Write the main monosubstitution equation and state the required condition.

อีเทนทำปฏิกิริยากับโบรมีน จงเขียนสมการแทนที่แบบโมโนโบรมีเนชัน และระบุเงื่อนไขที่จำเป็น

5. Bromination of propane / การทำปฏิกิริยาของโพรเพนกับโบรมีน
(2 points / 2 คะแนน)

Propane reacts with Br₂ under suitable conditions. Write one possible monosubstitution product and state the condition.

โพรเพนทำปฏิกิริยากับ Br₂ ภายใต้เงื่อนไขที่เหมาะสม จงเขียนผลิตภัณฑ์แทนที่หนึ่งตำแหน่ง 1 แบบ และระบุเงื่อนไข

Answer Key / เฉลยละเอียด ข้อ 1–5
1. Complete combustion of methane

CH₄ + 2O₂ → CO₂ + 2H₂O
Condition: excess oxygen / sufficient O₂

เงื่อนไขคือมีออกซิเจนเพียงพอ ผลิตภัณฑ์ของการเผาไหม้สมบูรณ์คือ CO₂ และ H₂O

2. Complete combustion of butane

2C₄H₁₀ + 13O₂ → 8CO₂ + 10H₂O
Condition: excess oxygen / complete combustion

ต้องมี O₂ เพียงพอ ถ้า O₂ ไม่พอจะเกิดการเผาไหม้ไม่สมบูรณ์

3. Incomplete combustion

2CH₄ + 3O₂ → 2CO + 4H₂O
Condition: limited oxygen / insufficient O₂

เมื่อ O₂ ไม่พอ อาจเกิด CO หรือเขม่า C แทน CO₂

4. Alkane substitution

CH₃CH₃ + Br₂ → CH₃CH₂Br + HBr
Condition: UV light / sunlight

เป็นปฏิกิริยาแทนที่ของแอลเคน ต้องใช้แสง UV และเกิด HBr เป็นผลิตภัณฑ์ร่วม

5. Bromination of propane

Example: CH₃CH₂CH₃ + Br₂ → CH₃CHBrCH₃ + HBr
Condition: UV light / sunlight

ยอมรับผลิตภัณฑ์โมโนโบรมีเนชันได้ เช่น 1-bromopropane หรือ 2-bromopropane แต่ต้องมีเงื่อนไข UV

6. Alkene addition with bromine / ปฏิกิริยาเติมของแอลคีนกับโบรมีน
(2 points / 2 คะแนน)

Propene reacts with bromine solution in the dark. Write the product and state the observation.

โพรพีนทำปฏิกิริยากับสารละลายโบรมีนในที่มืด จงเขียนผลิตภัณฑ์และระบุสิ่งสังเกต

7. But-2-ene with bromine / บิวต์-2-อีนกับโบรมีน
(2 points / 2 คะแนน)

But-2-ene reacts with Br₂. Write the addition product and identify the type of reaction.

บิวต์-2-อีนทำปฏิกิริยากับ Br₂ จงเขียนผลิตภัณฑ์จากการเติม และระบุชนิดของปฏิกิริยา

8. Addition of HBr to propene / การเติม HBr เข้ากับโพรพีน
(2 points / 2 คะแนน)

Propene reacts with HBr. Predict the major product and state the rule used.

โพรพีนทำปฏิกิริยากับ HBr จงทำนายผลิตภัณฑ์หลัก และระบุกฎที่ใช้

9. KMnO₄ test / การทดสอบด้วย KMnO₄
(2 points / 2 คะแนน)

Compare the reaction of an alkene and an alkane with dilute KMnO₄. State the observation.

เปรียบเทียบการเกิดปฏิกิริยาของแอลคีนและแอลเคนกับสารละลาย KMnO₄ เจือจาง พร้อมระบุสิ่งสังเกต

10. Stoichiometry from combustion / ปริมาณสารสัมพันธ์จากการเผาไหม้
(2 points / 2 คะแนน)

When 4.4 g of propane, C₃H₈, is completely burned, calculate the number of moles of CO₂ produced. Given: C = 12, H = 1.

เมื่อเผาไหม้โพรเพน C₃H₈ จำนวน 4.4 g อย่างสมบูรณ์ จงคำนวณจำนวนโมลของ CO₂ ที่เกิดขึ้น กำหนดให้ C = 12, H = 1

Answer Key / เฉลยละเอียด ข้อ 6–10
6. Propene + Br₂

CH₃CH=CH₂ + Br₂ → CH₃CHBrCH₂Br
Observation: bromine solution is decolorized
Condition: occurs even in the dark

เป็นปฏิกิริยาเติมของแอลคีน ทำให้สีของ Br₂ จางหายหรือถูกฟอกสี

7. But-2-ene + Br₂

CH₃CH=CHCH₃ + Br₂ → CH₃CHBrCHBrCH₃
Reaction type: addition reaction

Br เติมเข้าที่พันธะคู่ ได้สารไดโบรโม

8. Propene + HBr

CH₃CH=CH₂ + HBr → CH₃CHBrCH₃
Major product: 2-bromopropane
Rule: Markovnikov’s rule

H ไปเกาะคาร์บอนที่มี H มากกว่า ส่วน Br ไปเกาะคาร์บอนที่มี H น้อยกว่า

9. KMnO₄ test

Alkene: purple KMnO₄ fades and brown MnO₂ forms.
Alkane: no reaction under normal conditions.

แอลคีนทำให้สีม่วงของ KMnO₄ จางลงและเกิดตะกอน MnO₂ สีน้ำตาล ส่วนแอลเคนโดยทั่วไปไม่เกิดปฏิกิริยา

10. Stoichiometry from propane combustion

Balanced equation: C₃H₈ + 5O₂ → 3CO₂ + 4H₂O
Molar mass of C₃H₈ = 44 g/mol
n(C₃H₈) = 4.4 ÷ 44 = 0.10 mol
Mole ratio C₃H₈ : CO₂ = 1 : 3
n(CO₂) = 0.10 × 3 = 0.30 mol

คำตอบคือ 0.30 mol CO₂
