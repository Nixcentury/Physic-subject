เอทานอลและไดเมทิลอีเทอร์มีสูตรโมเลกุลเหมือนกัน C₂H₆O ข้อใดถูกต้อง
Ethanol and dimethyl ether have the same molecular formula, C₂H₆O. Which statement is correct?
  1. Dimethyl ether has a higher boiling point because it has oxygen.
    ไดเมทิลอีเทอร์มีจุดเดือดสูงกว่า เพราะมีอะตอมออกซิเจน
  2. Ethanol has a higher boiling point because it can form hydrogen bonds.
    เอทานอลมีจุดเดือดสูงกว่า เพราะสามารถเกิดพันธะไฮโดรเจนได้
  3. Both have the same boiling point because they have the same molecular formula.
    ทั้งสองมีจุดเดือดเท่ากัน เพราะมีสูตรโมเลกุลเหมือนกัน
  4. Dimethyl ether has a higher boiling point because it has no O-H bond.
    ไดเมทิลอีเทอร์มีจุดเดือดสูงกว่า เพราะไม่มีพันธะ O-H
  5. Ethanol has a lower boiling point because it is more polar.
    เอทานอลมีจุดเดือดต่ำกว่า เพราะมีขั้วมากกว่า
  6. Both are nonpolar substances.
    ทั้งสองเป็นสารไม่มีขั้ว
💡 คำใบ้ / Hint: ดูว่าสารใดมีพันธะ O-H ซึ่งทำให้เกิดพันธะไฮโดรเจนระหว่างโมเลกุลได้
Check which molecule has an O-H bond that allows intermolecular hydrogen bonding.
เฉลย / Solution: B.
เอทานอลมีหมู่ O-H จึงสามารถเกิดพันธะไฮโดรเจนระหว่างโมเลกุลได้ ทำให้แรงยึดเหนี่ยวระหว่างโมเลกุลมากขึ้น และมีจุดเดือดสูงกว่าไดเมทิลอีเทอร์
Ethanol has an O-H group, so it can form intermolecular hydrogen bonds. This increases the intermolecular forces and gives ethanol a higher boiling point than dimethyl ether.

ไดเมทิลอีเทอร์มีอะตอม O จริง แต่ไม่มีพันธะ O-H จึงไม่สามารถเกิดพันธะไฮโดรเจนระหว่างโมเลกุลของตัวเองได้เด่นชัด
Dimethyl ether contains an oxygen atom, but it has no O-H bond, so it cannot strongly form hydrogen bonds between its own molecules.

    สารทั้งสามควรมีจุดเดือดเท่ากัน เพราะมีมวลโมเลกุลใกล้เคียงกัน
  6. Chloroethane has the highest boiling point because it contains a chlorine atom.
    คลอโรอีเทนมีจุดเดือดสูงที่สุด เพราะมีอะตอมคลอรีน
💡 คำใบ้ / Hint: จุดเดือดไม่ได้ขึ้นกับมวลโมเลกุลอย่างเดียว ต้องพิจารณาแรงยึดเหนี่ยวระหว่างโมเลกุลด้วย โดยเฉพาะพันธะไฮโดรเจน
Boiling point does not depend only on molecular mass. Intermolecular forces, especially hydrogen bonding, must also be considered.
เฉลย / Solution: B.
โพรพานอลมีหมู่ O-H จึงเกิดพันธะไฮโดรเจนระหว่างโมเลกุลได้แรง ทำให้แรงยึดเหนี่ยวระหว่างโมเลกุลสูงและมีจุดเดือดสูงที่สุด
Propanol has an O-H group, so it can form strong intermolecular hydrogen bonds. This gives it stronger intermolecular forces and the highest boiling point.

อีเทนไทออลมีหมู่ S-H ซึ่งเกิดพันธะไฮโดรเจนได้ไม่เด่นชัดเท่า O-H ส่วนคลอโรอีเทนไม่มีหมู่ O-H หรือ N-H จึงไม่เกิดพันธะไฮโดรเจนที่แรง
Ethanethiol has an S-H group, which does not form hydrogen bonds as strongly as O-H. Chloroethane has no O-H or N-H group, so it does not form strong hydrogen bonds.
11
ข้อใดจับคู่ “ชนิดสาร + รีเอเจนต์/เงื่อนไข + ผลที่สังเกตได้” ถูกต้องที่สุด
Which matching of compound type, reagent/condition, and observation is the most correct?
  1. Alkane + Br₂ in the dark → Br₂ decolorized immediately
  2. Alkene + Br₂ in the dark → no reaction
  3. Alkane + KMnO₄ → purple color fades rapidly
  4. Benzene + Br₂ in the dark → addition occurs easily
  5. Alkene + Br₂ in the dark → addition occurs and Br₂ is decolorized
  6. Alkane + HBr → Markovnikov addition occurs
💡 คำใบ้: แอลคีนมีพันธะคู่ จึงเกิด addition กับ Br₂ ได้ง่ายในที่มืด
เฉลย: E.
แอลคีนเกิดปฏิกิริยาเติมกับ Br₂ ได้ในที่มืด ทำให้สี Br₂ จางลง ส่วนแอลเคนต้องใช้ UV เมื่อต้องการทำปฏิกิริยากับ Br₂

เมื่อแอลคีนทำปฏิกิริยากับสารละลาย KMnO₄ เจือจาง ควรสังเกตเห็นอะไร
Which observation is expected when an alkene reacts with dilute KMnO₄ solution?
  1. The purple color becomes darker and no precipitate forms.
    สีม่วงเข้มขึ้น และไม่เกิดตะกอน
  2. The purple color fades and brown MnO₂ forms.
    สีม่วงจางลง และเกิดตะกอน MnO₂ สีน้ำตาล
  3. A white precipitate of AgBr forms immediately.
    เกิดตะกอนสีขาวของ AgBr ทันที
  4. CO₂ gas is produced immediately.
    เกิดแก๊ส CO₂ ทันที
  5. The solution turns red because HBr is formed.
    สารละลายเปลี่ยนเป็นสีแดง เพราะเกิด HBr
  6. No reaction occurs because alkenes are saturated hydrocarbons.
    ไม่เกิดปฏิกิริยา เพราะแอลคีนเป็นไฮโดรคาร์บอนอิ่มตัว
💡 คำใบ้ / Hint: KMnO₄ ใช้ทดสอบความไม่อิ่มตัวของสาร เช่น สารที่มีพันธะคู่ C=C
KMnO₄ can be used to test unsaturation, such as compounds containing a C=C double bond.
เฉลย / Solution: B.
แอลคีนมีพันธะคู่ C=C จึงทำปฏิกิริยากับสารละลาย KMnO₄ เจือจางได้ ทำให้สีม่วงของ KMnO₄ จางลง และเกิดตะกอน MnO₂ สีน้ำตาล
Alkenes contain a C=C double bond, so they react with dilute KMnO₄ solution. The purple color of KMnO₄ fades, and brown MnO₂ precipitate forms.

ส่วนแอลเคนเป็นไฮโดรคาร์บอนอิ่มตัว โดยทั่วไปไม่ทำให้ KMnO₄ เปลี่ยนสีภายใต้เงื่อนไขนี้
Alkanes are saturated hydrocarbons and generally do not decolorize KMnO₄ under these conditions.
