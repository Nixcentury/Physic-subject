🎯 แบบทดสอบนิยามปริมาณการเคลื่อนที่แนวตรง (Motion Concepts Quiz)

ทบทวนและวัดความเข้าใจเกี่ยวกับระยะทาง, การกระจัด, อัตราเร็ว, ความเร็ว และความเร่ง

1) [นิยาม] "ระยะทาง (Distance)" มีนิยามและลักษณะทางกายภาพตรงกับข้อใด?

[Concept] Which of the following correctly defines "Distance"?

💡 คำใบ้ (Hint):

TH: คิดถึงสายวัดที่ลากยาวไปตามเส้นทางที่เราเดินจริง ไม่สนว่าคดเคี้ยวแค่ไหน และไม่มีทิศทางเข้ามาเกี่ยวข้องครับ
EN: Think of the total length of the path actually traveled, regardless of direction.
เฉลย (Answer): ตอบข้อ A


📌 เฉลยละเอียด:
ระยะทาง ($s$) เป็น ปริมาณสเกลาร์ (มีแต่ขนาด ไม่มีทิศทาง) วัดจากความยาวจริงทั้งหมดตามเส้นทางที่วัตถุเคลื่อนที่ไปได้ มีหน่วยเป็นเมตร ($\text{m}$)

2) [นิยาม] "การกระจัด (Displacement)" มีนิยามและลักษณะทางกายภาพตรงกับข้อใด?

[Concept] Which of the following correctly defines "Displacement"?

💡 คำใบ้ (Hint):

TH: ลากเส้นตรงลัดจาก "จุดเริ่มต้น" พุ่งตรงไปหา "จุดสุดท้าย" เท่านั้น มีทิศทางชี้กำกับเสมอ
EN: The shortest straight line directed from the initial position to the final position.
เฉลย (Answer): ตอบข้อ B


📌 เฉลยละเอียด:
การกระจัด ($\vec{s}$) เป็น ปริมาณเวกเตอร์ ต้องระบุทั้งขนาดและทิศทาง โดยคิดจากเส้นตรงที่ลากจากจุดเริ่มต้นไปยังจุดสุดท้าย มีหน่วยเป็นเมตร ($\text{m}$)

3) [นิยาม] "อัตราเร็ว (Speed)" มีนิยามตรงกับข้อใด?

[Concept] Which of the following correctly defines "Speed"?

💡 คำใบ้ (Hint):

TH: สัมพันธ์กับ "ระยะทาง" คิดจากระยะทางที่ได้ในหนึ่งหน่วยเวลา ($v = \frac{s}{t}$)
EN: Related to distance; defined as the rate at which distance is covered over time.
เฉลย (Answer): ตอบข้อ C


📌 เฉลยละเอียด:
อัตราเร็ว ($v$) เป็น ปริมาณสเกลาร์ คำนวณจาก ระยะทาง หารด้วย เวลา ($v = \frac{s}{t}$) มีหน่วยเป็นเมตรต่อวินาที ($\text{m/s}$)

4) [นิยาม] "ความเร็ว (Velocity)" มีนิยามตรงกับข้อใด?

[Concept] Which of the following correctly defines "Velocity"?

💡 คำใบ้ (Hint):

TH: สัมพันธ์กับ "การกระจัด" คิดจากการกระจัดที่เปลี่ยนไปในหนึ่งหน่วยเวลา ($\vec{v} = \frac{\vec{s}}{t}$)
EN: Related to displacement; defined as the rate of change of displacement over time.
เฉลย (Answer): ตอบข้อ D


📌 เฉลยละเอียด:
ความเร็ว ($\vec{v}$) เป็น ปริมาณเวกเตอร์ คำนวณจาก การกระจัด หารด้วย เวลา ($\vec{v} = \frac{\vec{s}}{t}$) มีทิศทางเดียวกับการกระจัดเสมอ มีหน่วยเป็นเมตรต่อวินาที ($\text{m/s}$)

5) [นิยาม] "ความเร่ง (Acceleration)" มีนิยามตรงกับข้อใด?

[Concept] Which of the following correctly defines "Acceleration"?

💡 คำใบ้ (Hint):

TH: เมื่อไหร่ก็ตามที่วัตถุ "เร็วขึ้น", "ช้าลง" หรือ "เปลี่ยนทิศทาง" แสดงว่ามีความเร่ง เกิดจากความเร็วที่เปลี่ยนไปในหนึ่งหน่วยเวลา ($\vec{a} = \frac{\Delta\vec{v}}{t}$)
EN: Occurs when an object speeds up, slows down, or changes direction; rate of change of velocity over time.
เฉลย (Answer): ตอบข้อ A


📌 เฉลยละเอียด:
ความเร่ง ($\vec{a}$) เป็น ปริมาณเวกเตอร์ คำนวณจาก ความเร็วที่เปลี่ยนไป หารด้วย เวลา ($\vec{a} = \frac{\vec{v} - \vec{u}}{t}$) มีหน่วยเป็นเมตรต่อวินาทีกำลังสอง ($\text{m/s}^2$)

6) [วิเคราะห์] หากนักวิ่ง วิ่งไปตามลู่วิ่งวงกลมจนครบรอบกลับมาหยุดที่จุดเริ่มต้นพอดี ข้อใดสรุปได้ถูกต้อง?

[Analysis] If a runner completes one full circular lap and stops at the starting point, which statement is correct?

💡 คำใบ้ (Hint):

TH: "จุดเริ่มต้น" กับ "จุดสุดท้าย" เป็นจุดเดียวกัน! ทบทวนดูว่าปริมาณไหนคิดจากเส้นทางจริง และปริมาณไหนคิดจากระยะห่างจุดเริ่มถึงจุดจบ
EN: The initial and final positions are identical. Recall how distance vs. displacement is measured.
เฉลย (Answer): ตอบข้อ B


📌 เฉลยละเอียด:
- ระยะทาง ($s$): คิดตามลู่วิ่งจริงที่วิ่งได้ทั้งหมด จึงเท่ากับความยาวเส้นรอบวงวงกลม ($2\pi r$)
- การกระจัด ($\vec{s}$): คิดจากจุดเริ่มต้นไปจุดสุดท้าย เนื่องจากกลับมาอยู่ที่จุดเดิม ระยะห่างเส้นตรงจึงเป็น $0$ เมตรครับ
