สายไฟ จุดเชื่อม และวงจรเปิด–ปิด
Wires, Junctions, and Open/Closed Circuits

เส้นสองเส้นที่ตัดกันไม่ได้เชื่อมกันเสมอ ต้องดูจุด junction หรือสัญลักษณ์สะพานข้าม Two crossing lines are not necessarily connected. Look for a junction dot or a bridge crossing.
เชื่อมกัน / ConnectedThe dot shows that the two wires form one electrical junction.
ไม่เชื่อมกัน / Not connectedA simple crossing without a dot does not create a junction.
สะพานข้าม / Bridge crossingOne wire passes over the other, so they still do not connect.
จุดร่วมหลายสาขา / Multi-branch junctionSeveral branches may meet at one node.
ภาพชุดนี้อ่านอย่างไร / How to read these diagrams
ดู “จุดเชื่อม” ก่อนดูทิศทางเส้น ถ้าไม่มีจุดดำ วงจรอาจยังแยกกันอยู่ แม้เส้นบนกระดาษจะตัดกัน Look for a junction marker before following the line directions. Without a junction dot, the wires may still belong to separate parts of the circuit even if they cross on the page.
Open switch
หน้าสัมผัสแยก เส้นทางไม่ครบ จึงไม่มีกระแสในวงจรง่ายSeparated contacts break the path.
Closed switch
หน้าสัมผัสเชื่อม เส้นทางครบ กระแสไหลได้Touching contacts complete the path.
Conventional current / กระแสแบบดั้งเดิม:
ภายนอกเซลล์กำหนดให้ไหลจากขั้วบวกไปขั้วลบ ส่วนอิเล็กตรอนในโลหะเคลื่อนตรงข้าม Outside a cell, conventional current is defined from positive to negative; electrons drift in the opposite direction.

Node, Branch และ Loop

Node / จุดร่วม:
บริเวณสายตัวนำที่เชื่อมต่อถึงกันโดยไม่มีอุปกรณ์คั่น A conducting region connected without a component in between.
Branch / สาขา:
เส้นทางระหว่าง node สองจุดที่มีกระแสสาขาเดียวกัน A path between two nodes carrying one branch current.
Loop / วงรอบ:
เส้นทางปิดที่เริ่มและกลับมายังจุดเดิม A closed path that returns to its starting point.
วงจรนี้มี 2 nodes, 3 branches และมีวงรอบอิสระ 2 วงThis circuit has two nodes, three branches, and two independent loops.
กฎสำคัญ / Key rule:
ตัวต้านทานสองตัวขนานกันเมื่อปลายทั้งสองต่อกับ node คู่เดียวกัน ไม่ใช่เพราะวาดอยู่ข้างกัน Two resistors are parallel when both terminals connect to the same pair of nodes—not merely because they are drawn side by side.
Mini Check
$R_1$ และ $R_2$ ต่อขนานกันหรือไม่ อธิบายด้วยคำว่า node Are $R_1$ and $R_2$ in parallel? Explain using the word node.
ใช่ เพราะปลายซ้ายของทั้งสองต่อกับ node A และปลายขวาของทั้งสองต่อกับ node B Yes. Both left terminals connect to node A and both right terminals connect to node B.

Part 6

วงจรเดียวกันที่วาดต่างรูป
The Same Circuit Drawn in Different Ways

ตำแหน่งบนกระดาษไม่ใช่สิ่งกำหนดวงจร สิ่งสำคัญคือปลายอุปกรณ์แต่ละชิ้นเชื่อมกับ node ใด Position on the page does not define a circuit. What matters is which node is connected to each component terminal.
วงจรอนุกรมหนึ่งเส้นทาง / One series path
รูปร่างต่าง แต่จุดต่อเหมือน A / Different shape, same connections as A
มีสายเพิ่มคร่อมหลอด ทำให้ปลายหลอดเป็น node เดียวกัน / An added wire bypasses the lamp
วิเคราะห์ / Analysis:
Circuit A และ B มี cell, resistor และ lamp อยู่ในเส้นทางเดียวกัน และปลายของอุปกรณ์ทุกชิ้นยังต่อกับ node คู่เดิม จึงเป็นวงจรเดียวกัน Circuits A and B contain the cell, resistor, and lamp in one path, and every component terminal remains connected to the same pair of nodes. They are equivalent.

Circuit C ต่างออกไป เพราะมีสายตัวนำต่อคร่อมหลอดโดยตรง สายใหม่นี้รวมปลายทั้งสองของหลอดให้เป็น node เดียวกัน จึงเกิดการ bypass หลอด Circuit C is different because a conducting wire is connected directly across the lamp. The added wire merges the two lamp terminals into the same node, so the lamp is bypassed.
หลักจำ / Memory rule:
เปลี่ยนรูปร่างได้ แต่ห้ามเปลี่ยนจุดต่อ The shape may change, but the connections must remain unchanged.
Mini Check
อธิบายโดยใช้คำว่า node ว่าทำไม A และ B เหมือนกัน แต่ C แตกต่าง Use the word node to explain why A and B are equivalent but C is different.
ใน A และ B ปลายของ cell, resistor และ lamp ต่อกับ node คู่เดิม แม้ว่ารูปร่างของสายต่างกัน ส่วน C มีสายใหม่เชื่อมปลายทั้งสองของหลอดเข้าด้วยกัน ทำให้สองจุดนั้นกลายเป็น node เดียวกันและหลอดถูก bypass In A and B, the terminals of the cell, resistor, and lamp connect to the same pairs of nodes even though the wire shapes differ. In C, an added wire joins the two lamp terminals, making them part of the same node and bypassing the lamp.
